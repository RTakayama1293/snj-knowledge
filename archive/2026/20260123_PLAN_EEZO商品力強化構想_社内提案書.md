# EEZO商品力強化構想

## 1. 背景・課題認識

### 現状の課題

EEZOは現在860商品を取り扱っているが、以下の課題を抱えている。

- **転換率の低迷**: クリック→カートの転換率が業界平均（2〜3%）を下回る0.04〜0.09%
- **差別化の欠如**: 「何でもある」は「何もない」と同義。EEZOで買う理由が不明確
- **価格競争への巻き込まれ**: 同じ商品が他でも買える状態では価格勝負になる

### 12月月次報告より

- Meta広告：配信5,711→クリック419→商品詳細155→カート4→**購入0**
- 旅客メルマガ：配信66,282→開封26,736→クリック909→商品詳細212→カート4→**購入2**
- 商品は見ているが魅力不足。ブランド信頼が後押しになっている可能性

### 方針転換

「商品を並べる」から「価値を創る」へ。EEZOでしか買えない理由を作る。

## 2. 独自性のレベル定義

商品の独自性を4段階で定義し、段階的に投資を拡大する。

| レベル | 内容 | 投資規模 | リードタイム |
|--------|------|----------|--------------|
| **①同梱カード** | 既存商品＋話のネタを同梱 | 小（5,000〜8,000円/100部） | 1〜2ヶ月 |
| **②パッケージ** | オリジナルラベル・化粧箱 | 中（10〜50万円/SKU） | 2〜3ヶ月 |
| **③委託加工** | 加工品メーカーにオリジナル商品を依頼 | 中〜大（50〜200万円/SKU） | 3〜6ヶ月 |
| **④自社加工** | 素材を仕入れて自社で加工 | 大（設備・人員投資） | 6ヶ月〜 |

**基本戦略**: レベル①で顧客反応を見ながら、売れる商品から順にレベルを上げていく。

**判断基準**: オリジナル商品の年商が1,000万円を超えた時点で本格検討

## 4. 個別施策の詳細

### 4.1 同梱カード（レベル①）

**コンセプト**: 「商品説明」ではなく「話のネタを渡す」

**対象商品と選定理由**:

| 商品 | 仕入先 | 選定理由 | ネタの方向性 |
|------|--------|----------|--------------|
| エゾシカ | あぷかの森（恵庭） | 協業候補・関係構築中 | 要ヒアリング |
| 塩水ウニ | カネシン水産 | 看板商品候補 | 時価リスク分かち合い |
| 熟成干し芋/雪うなぎ | 利雪（美唄） | 北海道テロワール | 「雪で熟成する」 |
| 上川大雪 | 上川大雪酒造 | 入手困難銘柄 | 「休眠免許移転の離れ業」 |

**フォーマット**: 十字折りパンフレット（閉：A6 → 開：A4）
- ①表紙（フック）：キャッチーな一言
- ②へぇ：「知らなかった」を引き出す事実
- ③深掘り：生産者の顔・背景
- ④行動誘発：楽しみ方・SNSハッシュタグ

### 4.2 ウニの時価リスク分かち合いモデル

**従来の課題**:
- 時価商品のためtoC価格設定が困難
- 買い手が「高すぎたかも」と不安になる

**解決策**:
1. 高めに販売（バッファ込み）
2. 購入後1週間、セリ価格を見届ける
3. 基準より安くなったら差額分をクーポンで返金

**EEZOらしさ**:
- 「信用」を売るプラットフォームの具現化
- 時価リスクを顧客と分かち合う誠実さ
- 話のネタになる（「こんな売り方する店ある？」）

**代替案**: オークション方式、予約エントリー制も検討中

### 4.3 料理長監修レトルト（レベル③）

**ターゲット**:
- 子供が大きくなって外出できない富裕層
- 結婚記念日など「ハレの日」を自宅で過ごしたい層
- 料理店に足を運べないが、クオリティは妥協したくない層

**参考事例**:
- 菊水堂（マツコの知らない世界→EC爆売れ）
- アーリーアダプターとしてのインフルエンサー活用

**開発の流れ**:
1. 料理長（泊谷 or 菅原）に企画相談
2. レシピ開発・試作
3. 委託加工先の選定
4. パッケージデザイン
5. テスト販売→本格展開

### 4.4 蝦夷アワビ×レシピコンテンツ

**課題**: 蝦夷アワビは「おいしくない」という評価がある

**逆転の発想**:
1. 課題を正直に認める
2. 料理長に「これを一番おいしく食べられるレシピ」を依頼
3. 試行錯誤のプロセスをコンテンツ化（探偵ナイトスクープ方式）
4. 「こうすれば化ける」というストーリーで販売

**期待効果**:
- 課題をネタに変える、EEZOらしいアプローチ
- コンテンツとしての拡散性
- 料理長との協業関係強化

### 4.5 富裕層→旅行導線（将来構想）

**アイデア**:
- シュトーレン販売→お菓子作りツアー
- 北海道スタンプラリー（小樽起点で拡大）
- テレ東「バス旅vs鉄道の旅」的なコンテンツ連動

**位置づけ**: フェリー事業（親会社）との連携。Phase 4以降の検討事項。

## 5. 投資対効果の見通し

### コスト構造

| Phase | 期間 | 投資規模 | 主な内訳 |
|-------|------|----------|----------|
| Phase 1 | 1〜4月 | 3〜5万円 | 同梱カード印刷 |
| Phase 2 | 5〜9月 | 20〜50万円 | パッケージデザイン・試作 |
| Phase 3 | 10〜3月 | 100〜300万円 | 商品開発・委託加工 |
| Phase 4 | 4月〜 | 要検討 | 設備投資・人員 |

### 期待効果

| 指標 | 現状 | Phase 1後 | Phase 3後 |
|------|------|-----------|-----------|
| 転換率 | 0.04〜0.09% | 0.5%目標 | 1.0%目標 |
| リピート率 | 未計測 | 計測開始 | 20%目標 |
| オリジナル商品売上 | 0 | ─ | 月50万円目標 |

### 撤退基準

- Phase 1完了後、同梱カード効果が測定不能な場合 → Phase 2見送り
- Phase 2完了後、パッケージ変更で売上増なしの場合 → Phase 3縮小
- Phase 3完了後、オリジナル商品が月10万円未満の場合 → Phase 4見送り

## 6. リスクと対策

| リスク | 影響 | 対策 |
|--------|------|------|
| 仕入先との関係構築遅延 | 対象商品変更 | 代替商品を常に2〜3候補確保 |
| 加工品の品質問題 | ブランド毀損 | 小ロットテスト販売から開始 |
| Shopifyローンチ遅延 | Phase 1延期 | 同梱カードは現行ECでも使用可 |
| 料理長の協力得られず | レベル③遅延 | 外部シェフへの委託を検討 |
