# エゾシカ一頭P/L：部位別収支フレームワーク

**作成日**: 2026年2月9日  
**最終更新**: 2026年2月9日（v2.0 ファクトチェック反映）  
**目的**: エゾシカ一頭（生体100kg）を起点に、捕獲→加工→販売の全プロセスにおけるコスト構造と収益構造を可視化する  
**背景**: 蜂巣さんの問題提起「ax+by+cz、x:y:z一定、aを吊り上げるのは限界があり、捌けないzは売上原価に跳ね返ってくる」に対する構造的回答

---

## 1. 問題の構造

エゾシカも牛も、部位の比率は不変でいじれない。人気部位だけ売って残りを安く叩き売ると収支が合わない。

数式化すると：

```
一頭あたりの収益 = aA + bB + cC + dD

A: 人気部位（ロース・モモ・フィレ）  → 単価高、量は固定
B: その他部位                        → 加工次第で単価が変わる
C: ペット用端材                      → 最も安い、量で捌く
D: 副産物（角・骨・トライプ・革）    → 原価ほぼゼロ、売上＝純利益

A:B:C:Dの比率は固定。動かせるのは単価（a, b, c, d）と出口の質。
```

---

## 2. 歩留まりフロー

```
生体 100kg（※オス120-150kg、メス70-90kgの混合平均）
  │
  ├→ 一次加工（内臓除去・放血・剥皮・枝肉化）
  │    枝肉 50kg（歩留50%）  ※日本ジビエ振興協会調査と一致
  │    内臓・血液等 50kg → 廃棄 or D区分へ
  │
  ├→ 二次加工（脱骨・整形・カット・製品化）
  │    A: 人気部位精肉   12kg  ※フィレ0.3kg＋ロース3kg＋モモ系8kg
  │    B: その他部位     18kg → 加工品化（ハンバーグ・カレー等）
  │    C: ペット用端材   10kg → ミンチ・乾燥等のPF原料化
  │    骨・トリミング等  10kg → D区分へ
  │
  └→ D: 副産物
       角 1対、革 1枚、骨、グリーントライプ（胃内容物）等
```

**歩留まりの根拠**：生体→枝肉50%は業界標準値。牛60-65%、豚約70%に対し鹿は皮下脂肪が少なく頭部・角比率が大きいため低い。精肉合計30kg（生体の30%）は日本ジビエ振興協会の「精肉歩留まり約30%」と一致。A区分12kgは大型個体で最大14kg、小型メスで8kg程度の中央値。

## 6. 比較：生体仕入 vs 枝肉仕入

| | 生体から | 枝肉から |
|---|---|---|
| 枝肉・生体購入費 | 10,000円 | 67,500円（45kg×1,500円） |
| 一次加工費 | 8,000円 | —（枝肉購入のため不要） |
| 二次加工費 | 14,900円 | 14,900円（同額） |
| **仕入原価/頭** | **32,900円** | **82,400円** |
| 売上/頭 | 109,000円 | 109,000円 |
| **売上総利益** | **76,100円** | **26,600円** |
| **売上総利益率** | **69.8%** | **24.4%** |
| 前提条件 | 一次加工場の確保が必須 | 既存の精肉業者から仕入可 |

川上から入ることで一頭あたり約49,500円の粗利差が生まれる。これが「あぷかの森との協業」「胆振地区への加工場設置」の経済合理性。ただし加工場の固定費（家賃・人件費・設備償却）を稼働率で吸収できるかが条件。

**枝肉単価の根拠**：精肉卸売相場2,000〜3,000円/kgに対し、枝肉は骨を含む（枝肉→精肉歩留まり60-70%）ため単価が低い。HACCP認証施設の高品質枝肉で1,200〜1,800円/kg、中央値1,500円/kgを採用。ただしエゾシカには牛・豚のような確立された市場相場がなく、取引先・品質・時期で変動する。

## 7. 感度分析

### 一頭あたり粗利への影響

| 変数 | ベース | 変更後 | 粗利変動 |
|---|---|---|---|
| 生体仕入 | 10,000円 | 5,000円（駆除個体） | **+5,000** |
| 一次加工費 | 8,000円 | 12,000円（小規模施設） | **▲4,000** |
| A人気部位kg | 12kg | 14kg（大型オス偏重） | **+2,000**（A+7,000・B▲5,000の差引。A単価＞B単価のためプラス） |
| B販売単価 | 2,500円/kg | 3,000円/kg（高付加価値化） | **+9,000** |
| C販売単価 | 1,000円/kg | 1,500円/kg（PB供給） | **+5,000** |
| D売上 | 12,000円 | 0円（副産物未活用） | **▲12,000** |

### 最も効くレバー

1. **D（副産物）の有無**：12,000円の振れ幅。ゼロか収益かで事業性が変わる
2. **B（加工品）の単価**：500円/kgの改善で9,000円/頭の改善。加工品の商品力が直結
3. **C（ペット用）の出口の質**：原料卸→PB供給で5,000円/頭の改善
4. **A/B比率の変動**：捕獲個体のサイズ差（オスメス比）で±2kgの振れ幅。A単価＞B単価のため大型オスが多いほど有利

| 年間頭数 | 売上 | 売上原価 | 売上総利益 | 備考 |
|---|---|---|---|---|
| 100頭 | 10.9M | 3.29M | 7.61M | 初期検証規模 |
| 300頭 | 32.7M | 9.87M | 22.83M | ホテル10軒＋フレンチ20軒程度 |
| 667頭 | 72.7M | 21.95M | 50.78M | A+C=50Mライン相当 |

**スケールの現実感**：全国772施設の平均処理頭数は約237頭/年（日本ジビエ振興協会）、200頭以下の施設が全体の80%を占める。300頭は上位施設、1,000頭は大規模施設に該当する。北海道のエゾシカ捕獲頭数は年間約157,000頭（2023年度過去最多）、全国のジビエ利用量は2,729トン（同年度過去最大）と市場は拡大中。

## 9. 構造的結論

蜂巣さんの「ax+by+cz、比率固定でどうするか」への回答：

**単一チャネルでは成立しない。一頭の中で複数チャネルを組み合わせ、各区分の出口を最適化する必要がある。**

具体的には：

- **Aで稼ぐ**：人気部位はレストランBtoBで確実に捌く。ここが売上の柱
- **Bで利益を上乗せする**：その他部位を加工品にしてEEZO BtoCで付加価値を乗せる。精肉のまま出すと赤字、加工品化で利益源に変わる。B区分が18kgとA区分より多い＝加工品の商品力が事業の太さを決める
- **Cは量を安定的に流す**：ペット用は単価が低くても「計画的に量を流すチャネル」を確保する。叩き売りではなくOEM/PBで安定出口を作る
- **Dが事業成立の分水嶺**：副産物の収益化は「おまけ」ではない。Dゼロなら薄利、D有りなら事業が成立する
