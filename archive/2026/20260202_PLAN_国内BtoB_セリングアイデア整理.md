## 2. DENBA セリングアイデア（25百万円）

### 概要

DENBA鮮度保持装置の販売。買い切り70万円/台。横展開で売上を伸ばすが、リピートがないため継続的な新規開拓が必要。

**実績**: オーセントホテル小樽 3台設置完了

### SI-D1：シティホテル型（オーセントモデル）

```
誰が：中規模シティホテルの料飲部門長/設備担当
何を：DENBA冷蔵室 2台（和食+洋食）
どれくらい：1施設あたり2台

単価：140万円/施設
目標：8施設
小計：1,120万円

導入決裁：設備投資稟議 → リードタイム長め
訴求ポイント：食材ロス削減、品質向上によるコスト削減効果
```

### SI-D2：小規模旅館型（楽水山モデル）

```
誰が：小規模高級旅館のオーナー/料理長
何を：DENBA冷蔵室 1台（料亭用）
どれくらい：1施設あたり1台

単価：70万円/施設
目標：8施設
小計：560万円

導入決裁：オーナー即決の可能性あり、リードタイム短め
訴求ポイント：高級食材の鮮度保持、少量多品種対応
```

### SI-D3a：大手ブライダル企業型

```
誰が：大手ブライダル企業（T&G、IKK、ノバレーゼ等）の装花部門責任者/CX推進室
何を：DENBA冷蔵室（フラワー保管庫用）
どれくらい：試験導入1台 → 全国20カ所展開

単価：70万円（試験）→ 1,400万円（全国展開時）
目標：1社（初年度は試験導入）
小計：700万円（初年度）

導入決裁：本部稟議→試験→検証→展開決定（リードタイム長い）
訴求ポイント：装花ロス削減、婚礼件数が多く安定するほど内製化メリット大
```

### SI-D3b：大手フローリスト型

```
誰が：大手フローリスト（第一園芸、日比谷花壇、ユー花園等）のウェディング部門責任者
何を：DENBA冷蔵室 5台（複数拠点）
どれくらい：試験導入5台 → 10カ所展開

単価：350万円（試験）→ 3,500万円（全国展開時）
目標：1社（初年度は試験導入）
小計：350万円（初年度）

導入決裁：フローリスト側の意思決定（リードタイム中程度）
訴求ポイント：ホテルウェディング提携先への差別化、品質保証
```

### DENBA 売上サマリー

| ID | 型 | 単価 | 目標数 | 小計 |
|----|-----|------|--------|------|
| D1 | シティホテル型 | 140万円 | 8施設 | 1,120万円 |
| D2 | 小規模旅館型 | 70万円 | 8施設 | 560万円 |
| D3a | 大手ブライダル型 | 70万円* | 1社 | 700万円 |
| D3b | 大手フローリスト型 | 350万円* | 1社 | 350万円 |
| | | | **合計** | **2,730万円** |

*初年度は試験導入ベースで控えめ計上

### ウェディング市場の業界構造（参考）

**内製化 vs 外注**
- 大手ブライダル企業：内製化傾向（T&G CX推進室、IKKフラワー部門内製化拡大）
- ホテルウェディング：大手フローリストと提携（帝国→第一園芸、オークラ→日比谷花壇等）

**導入判断の目安**
- 婚礼件数が多く安定するほど内製化（固定費化）が合理的
- 椿山荘クラス（三大結婚式場）なら年間300件と仮定

## 3. エゾシカ セリングアイデア（15百万円）

### 概要

エゾシカ（ジビエ）の継続販売。関係構築に時間がかかるが、一度入ればリピートが見込める。中長期の収益基盤として育成。

**実績**:
- オーセントホテル小樽：年間174kg（ソーセージ・ミンチ含む）※うち経由ではない
- ホロニック：月5kg（冬メニュー、11-2月）

**仕入先候補**:
- あぷかの森（恵庭）：年800頭、協業候補
- 食美楽（新冠）：年5,500頭、競走馬牧草=高栄養価

### SI-E1：ホテル型（オーセントモデル）

```
誰が：ホテルの料飲部門（宴会・レストラン両方持つ規模）
何を：複数部位（ロース/モモ/ソーセージ/ミンチ）
どれくらい：月15kg × 12ヶ月 = 年180kg

単価想定：平均3,000円/kg（加工品込みで低め設定）
年間売上：54万円/軒
目標：10軒
小計：540万円

特徴：通年メニュー、複数レストランで使用、安定消費
```

### SI-E2：フレンチ型（ホロニックモデル）

```
誰が：独立系フレンチの料理長（20-30席）
何を：ロース/モモ中心（高級部位）
どれくらい：月5kg × 4ヶ月（冬季11-2月）= 年20kg

単価想定：平均4,000円/kg（高級部位中心）
年間売上：8万円/軒
目標：30軒
小計：240万円

特徴：季節メニュー限定、単価は高いが消費量少ない
課題：冬季限定のため年間売上が伸びにくい
```

### SI-E3：イタリアン型（新規仮説）

```
誰が：独立系イタリアンのオーナーシェフ
何を：モモ/ミンチ中心（ラグーソース、カルパッチョ、タリアータ用）
どれくらい：月5kg × 12ヶ月（通年）= 年60kg

単価想定：平均3,000円/kg（モモ・ミンチ中心）
年間売上：18万円/軒
目標：40軒
小計：720万円

特徴：通年メニュー化の可能性（あぷか社長「イタリアン×エゾシカ相性良い」）
仮説：ヘルシー志向との親和性、使い道の多さ
要検証：実際に通年でメニューに載せている店舗の事例
```

### エゾシカ 売上サマリー

| ID | 型 | 年間売上/軒 | 目標軒数 | 小計 |
|----|-----|-----------|---------|------|
| E1 | ホテル型 | 54万円 | 10軒 | 540万円 |
| E2 | フレンチ型（季節） | 8万円 | 30軒 | 240万円 |
| E3 | イタリアン型（通年） | 18万円 | 40軒 | 720万円 |
| | | | **合計 80軒** | **1,500万円** |

## 4. 時間軸でのポジショニング

```
        2026年        2027年        2028年〜
        
DENBA   ████████████████████
        25施設で25百万   横展開継続    新規開拓必要
        キャッシュエンジン
        
エゾシカ ░░░░░░░████████████████████████
        80軒開拓      リピート安定    ストック型収益
        関係構築期間
```

### 戦略的意味

| 商材 | 役割 | 特性 |
|------|------|------|
| DENBA | 短期キャッシュエンジン | 買い切り→横展開で爆発、リピートなし |
| エゾシカ | 中長期リピート基盤 | 関係構築→継続取引、ストック型 |

両方やる意味：
- DENBAで短期の数字を作りつつ
- エゾシカで中長期のリピート基盤を育てる
- 相互にドアオープナーとして機能しうる
