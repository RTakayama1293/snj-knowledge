## 1. 事業の骨格

SNJが事業主体として捕獲インフラに投資し、すまい工房/湯峯さんが技術責任者として現場を統括する。従来の「あぷかから仕入れて売る商社モデル」から、**川上（捕獲）に自ら踏み込む垂直統合モデル**への転換。

| 項目 | 内容 |
|---|---|
| 事業主体 | 新日本海商事 |
| 商事の役割 | 捕獲インフラ整備、事業運営、ブランド開発、販路開拓 |
| 技術責任者 | 湯峯和幸（すまい工房・あぷかの森 社長） |
| 湯峯さんの役割 | 囲い罠運用、一次処理管理、衛生管理、現場人員指導 |
| 設備設計施工 | すまい工房 |
| 設備投資・人件費 | SNJ負担 |
| 二次処理 | 当面すまい工房委託。拡張時は土地建屋SNJ負担・運営すまい工房 |

## 9. 既存分析（一頭PLv3）との差分

| 論点 | 一頭PLv3（2月） | 蜂巣資料（3月） |
|---|---|---|
| 事業モデル | あぷかから仕入→SNJが販売（商社） | SNJが捕獲投資→すまい工房に技術委託（川上統合） |
| 売上/頭 | 109,000円（BtoC価格含む4区分） | 70,000円（骨筋込み部位別卸価格） |
| 原価/頭 | 70,600円（あぷか仕入） | 29,500円（変動費のみ、自社捕獲前提） |
| 粗利/頭 | 38,400円（35.2%） | 40,500円（57.9%、ただし固定費控除前） |
| 部位区分 | A/B/C/D（出口別4チャネル） | 7部位＋骨筋（卸価格ベース） |
| 副産物の扱い | D区分で角・骨・トライプ・革＝12,000円 | 骨筋20kg＝16,000円として売上に内包 |
| ペットフード | C区分10kg×1,000円＝10,000円 | 明示なし |

**重要な違い**：v3は「SNJが何で儲けるか（出口設計）」の分析、蜂巣資料は「事業全体をどう回すか（事業計画）」の設計。視点が違うので矛盾ではなく補完関係にある。ただし売上/頭の前提が大きく異なるため、どちらの単価設計で事業を走らせるかは要確認。

## 10. 要注意ポイント

**a) 初年度のバッファがほぼゼロ**
損益分岐306頭に対し計画300頭。6頭の余裕もない。捕獲の不確実性（初年度は餌付け・群れの定着からスタート）を考えると、計画未達時のシナリオが必要。

**b) 骨筋20kg=16,000円の出口**
売上70,000円のうち22.9%を占める。800円/kgで20kgを安定的に捌ける買い手（ペットフード原料？ボーンブロス？）が確保できるかで事業性が変わる。出口未確保なら一頭売上は54,000円に落ち、貢献利益は24,500円。

**c) 二次処理委託費20,000円/頭の内訳**
一頭PLv3では「あぷか仕入（利益込み）」として61,600円だったものが、ここでは「二次処理委託費」として20,000円。この差は、捕獲〜一次処理をSNJが自前で持つことでコスト構造が変わったため。ただし20,000円の根拠（すまい工房との合意済みか概算か）は要確認。

**d) 販売単価の前提**
部位別構成表の単価（ロース5,000円/kg、モモ3,500円/kg等）はBtoB卸価格ベースと見える。v3で試算していたBtoC価格（加工品化による付加価値）を乗せれば売上/頭は上振れる余地がある。逆に言えば、70,000円はフロアラインとして使える。
