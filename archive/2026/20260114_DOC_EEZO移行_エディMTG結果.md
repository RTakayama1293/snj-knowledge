**作成日**: 2026年1月14日  
**参加者**: 高山、松永（エディ）  
**次回定例**: 毎週火曜 12:00〜13:00

---

## 1. 決定事項

### ブランド/UX方針

| 項目 | 内容 |
|------|------|
| **カラー** | ネイビー基調、アクセントにゴールド、背景は白〜クリーム |
| **タイポグラフィ** | 明朝体ベースで高級感を強調 |
| **ビジュアル構成** | 写真中心のヒーロー、情報量は抑制、余白を活かす |
| **参考サイト** | 養老ミート、伊藤久右衛門、佐久山 |

### ターゲット

| 項目 | 内容 |
|------|------|
| **コア顧客像** | ストーリーに投資する高所得層（単価5,000〜10,000円を許容） |
| **チャネル** | フェリー旅客は重要接点だが依存しない設計 |
| **社内説明** | 「フェリー依存」に見えない抽象化（高所得の体験投資層） |

### 商品戦略

| 項目 | 内容 |
|------|------|
| **方針** | 他所で買える一般商材は削減、「EEZO限定」少数精鋭に集中 |
| **初期商品数** | 4商品程度でも可 |
| **マイルストーン** | 3/5までにヒーロー商材1〜2点を確定 |

### 現行CS-Cartの扱い

- 見た目の完コピはしない（「全部破壊していい」）
- 数値化しづらい運用ノウハウの方が資産
- 高級感を出すためにデザインは刷新

## 2. 未決事項・リスク

### 要社内確認

| 項目 | 内容 | 費用感 | 対応 |
|------|------|--------|------|
| **有償テーマ** | Shopify無償テーマでの再現性未確定 | $100〜200 | 実費計上で承認可能性あり |
| **メールサーバー** | CS-Cart側に依存中、移行後は別途必要 | 年約3万円 | eezo.club継続なら必須 |

### 中長期課題

| 項目 | 内容 | 備考 |
|------|------|------|
| **データ基盤** | 商品/受注/請求/CRM等が分断、属人的運用 | Microsoft 365導入は過去に握りつぶされた経緯あり |
| **ペルソナ詳細** | 関係者調整・検証が必要 | 試しながら固める方針 |
| **フェリー内施策** | 実行権限・予算枠の不確実性 | 外部調整が必要 |

## 4. ヒーロー商材とパッケージ検討

### 商材候補

| 商材 | 温度帯 | パッケージ構成イメージ | EEZO限定の可能性 |
|------|--------|----------------------|-----------------|
| **エゾシカ** | 冷凍 | 真空パック＋化粧箱/スリーブ | ◎ 加工場連携で独自性出しやすい |
| **ヒグマ** | 冷凍 | 同上 | ◎ 希少性が売り |
| **和牛** | 冷凍/冷蔵 | 真空パック＋化粧箱 | △ 競合多い |
| **水産物** | 冷凍/冷蔵 | 真空パック/トレー＋箱 | △ 差別化難しい |
| **酒** | 常温 | 瓶＋ラベル＋化粧箱/桐箱 | ○ ラベルで差別化可能 |

### パッケージ構成の松竹梅

| ランク | 構成 | コスト目安（1個） |
|--------|------|------------------|
| **松** | フルオリジナル化粧箱 | 300〜500円 |
| **竹** | 既製箱＋オリジナルスリーブ | 100〜200円 |
| **梅** | 既製箱＋オリジナルラベル/シール | 50〜100円 |

### 業者候補（相見積もり用）

**ネット印刷系（価格基準）**
- ラクスル
- グラフィック
- パッケージ通販.com

**食品パッケージ専門（品質・提案力）**
- 株式会社フヂヤ（高級食品向け）
- 大一紙工（小ロット相談可）
- シモジマ/プロパック（既製品＋セミオーダー）

**北海道地場（ストーリー・連携）**
- アイワード（札幌、道内食品実績多）
- 須田製版（札幌）
- 中川製函（小樽、水産加工向け）

### パッケージ選定の懸念事項

| 懸念 | 内容 | 対策案 |
|------|------|--------|
| **コスト** | ギフトボックスは1個300〜500円かかる可能性 | 商品単価5,000〜10,000円なら許容範囲か要検証 |
| **ロット** | 小ロット（100〜300個）だと単価が上がる | 最初は竹・梅で試し、売れたら松へ |
| **リードタイム** | オリジナル箱は2〜4週間かかる | 3/5確定に間に合わせるには1月中に発注判断 |
| **デザイン** | 誰がデザインするか | エディ対応可能か確認、または業者込みで依頼 |
