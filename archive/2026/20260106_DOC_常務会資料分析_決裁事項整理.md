## 決裁事項①：Shopifyへの切り替え

### 資料上の論理構造

```
当初仮説：BtoB向けマーケットプレイスをCS-Cartで構築
    ↓
実行課題：対面営業の遅れ、商品品揃え不足、買い手探索コスト増大
    ↓
方針転換：BtoB単独立ち上げの成長制約 → 短期的にBtoCへ軸足
    ↓
構造的不整合：CS-CartはBtoB向けUI、BtoC開発・運用が非効率
    ↓
【結論】Shopifyによる再出発
```

### 比喩による説明（常務会向け）

- マーケットプレイス ＝ 飛行機（空を飛ぶもの）
- CS-Cart ＝ プロペラ機
- BtoC市場 ＝ 高速道路
- Shopify ＝ スポーツカー

「プロペラ機で高速道路を走れなくはないが、本来の性能を活かせない」

### 補足事項（資料には明記されていない）

- CS-Cartで育成した資産（商品データ、顧客情報等）は継承活用
- 移行予算は約300万円（既報）
- 3月完了目標

## 決裁事項④：田嶋さん採用（国内営業専任）

### 資料上の論理構造（P3）

```
海外市場の優位性
・物価高と円安環境、価格受容性の高さ
・商品新奇性の訴求が容易
・英語化による競争環境の緩和
    ↓
海外先行戦略で手応え（優良見込客20+）
    ↓
杉田さんを海外営業に専念させる方針
    ↓
しかし営業リソース制約が顕在化
・時差対応で長時間化（欧米は夕方から）
・国内案件ケア不足（←杉田さんが海外専念するため）
・両方が中途半端になるリスク
    ↓
【結論】国内販売専任者1名の配置が必要 → 田嶋さん採用
```

### 人員計画での位置づけ（P4-5）

| 区分 | 2024年度 | 2025年度 | 2026年度 |
|------|----------|----------|----------|
| 外勤営業 | 0 | 1 | 2 |
| 内勤営業/営業事務 | 0 | 1 | 2 |

- 2025年度の「外勤営業1名」＝ 田嶋さん（4月ジョイン予定）
- 2025年度の「内勤営業1名」＝ **誰を指すか曖昧**

### 人員配置の全体像

**杉田さんの位置づけ**
- P3「海外対応優先による国内顧客との対面接触の減少」の主語は杉田さん
- つまり**杉田さんは海外営業に専念**する方針
- 既存メンバー4名に含まれていると推測

**最も整合的な解釈：**
- 「既存メンバー4名」＝ 蜂巣、永井、門永、杉田（営業系）+ 松本・黒田は事務系で別カウント？
- 「MP/営業戦略/予実管理/AI 2名」＝ 高山 + もう1名
- 「外勤営業1名」＝ 田嶋さん（国内営業専任として新規採用）
- 「内勤営業1名」＝ 別途採用（後述）

### 「内勤営業1名」の正体

**状況証拠から推測される候補者像：**
- 蜂巣さんの前職同僚
- 産休明けで復職先を探している
- 時短勤務を希望
- 年度途中（夏〜秋頃？）での入社想定

**人件費12Mの内訳推測：**

| 人員 | 入社時期 | 勤務形態 | 年間コスト概算 |
|------|----------|----------|---------------|
| 田嶋さん | 4月 | フルタイム | 6-7M |
| 内勤候補 | 年度途中 | 時短 | 3-5M |
| **合計** | | | **9-12M** |

→ 計画の12Mにちょうど収まる計算

**資料上で明示しない理由：**
- 候補者の個人事情（産休明け、時短）を役員会資料に記載するのは不適切
- まだ確定ではない段階で名前を出すリスク回避
- 「内勤1名」という枠だけ確保し、承認後に具体化する戦略

→ 資料の「曖昧さ」に見えた部分は、**意図的な抽象化**だった

## 資料構成の巧みさ

### 4つの決裁事項が相互に補強し合う構造

```
Shopify移行が必要
    → だから松永さんの継続が必要（実装者）
    → だから堀田さんの継続が必要（販促担当）

海外販売に注力する
    → だから国内が手薄になる
    → だから田嶋さんの採用が必要
```

### 「セット売り」の効果

- 個別に議論すると「本当に必要か？」と問われやすい
- 事業計画全体の中に埋め込むことで、個別承認ではなく**計画承認**として通せる
- 反対するなら「計画全体を否定する」必要が生じる

## 所感

**良い点**
- 現実を直視した計画修正（売上半減は勇気ある判断）
- 決裁事項を論理的にパッケージ化した構成力
- 比喩を使った説明のわかりやすさ（常務会向け）
- 人員計画の「曖昧さ」が実は意図的な抽象化（候補者プライバシー配慮＋未確定事項の適切な扱い）
- 裏で採用候補者の目処をつけた上での計画提示（蜂巣さんの根回し力）

**懸念点**
- 松永さん・堀田さんへの依存度が高く、リスク分散なし
- 内勤候補者の入社時期が遅れた場合、田嶋さんの立ち上がり期に負荷集中の可能性
- 時短勤務の内勤1名で営業事務を回せるか（業務設計の詰めが必要）
