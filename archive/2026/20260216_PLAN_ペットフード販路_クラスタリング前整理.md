# ペットフード販路：クラスタリング前整理

> **目的**: エゾシカ飲食店販路クラスタリング（あぷか提案用）と同じフレームワークで、ペットフード販路のクラスタ定義を行うための前段整理。
>
> **現在地**: クラスタリング本体に入る前の「仮説設定」段階。飲食店でいう「ホロニックの一言」に相当するとっかかりを、既存情報から仮説ベースで置く。

---

## 1. 飲食店クラスタリングとの構造比較

飲食店のとき成功した要素を分解し、ペットフードで何が揃っていて何が足りないかを整理する。

| 要素 | 飲食店（成功済み） | ペットフード（現状） |
|------|-------------------|-------------------|
| 母集団リスト | 黒田リスト90件「シカ肉を実際に使っている店」 | **なし**。作るところから |
| 質的確信（リプレイス根拠） | ホロニック「格段にうまい」→品質で勝てる | **直接の声なし**。ドギーマン商談不成立の逆事例あり |
| クラスタリング軸 | 席数×予算帯（定量・Web確認可） | 店舗数×プレミアムPF取扱度（候補、要検証） |
| 商流 | 統一（BtoB直接取引） | **複数レイヤー**（チェーン棚入れ／メーカー原料供給／EC直販） |

**結論**: 飲食店と同じ手順（リスト→クラスタ定義→典型先検証→総量試算）を踏むが、前提条件が異なるため、まず「リプレイス仮説」を立てるところから始める必要がある。

---

## 2. 3つのファクトから導いたリプレイス仮説

### ファクト①：ドギーマン商談の不成立

- あぷかが水田さん経由でドギーマンと商談 → 価格が全く合わず不成立
- 当時のあぷかはハンター持込・湯峯さん自身の狩猟に依存、安定供給不可
- **示唆**: 量販価格帯（安い）には構造的に乗れない → **下限の確定**

### ファクト②：コーナンのペットショップ棚の観察

- 鹿肉PFは「プレミアムペットフード」エリアに存在
- ただしメーカーまちまちで、SKUで面を取っているブランドはなかった
- **示唆**: プレミアム棚に鹿肉PFの居場所はあるが、支配的ブランドが不在 → **上限側の空白**

### ファクト③：既存プレイヤーの構造的制約

- 鹿肉PF専業は全て小規模D2C（ドッグスタンス、ZEN、北のジビエ等）
- 加工場に近い立地で製造直販が基本モデル
- 大手ペットフードメーカーの本格参入は限定的
- **示唆**: チェーンの棚を維持できる安定供給力を持つプレイヤーがいない

### 仮説（＝飲食店での「ホロニックの一言」に相当）

> **「プレミアム鹿肉PFの棚は既にあるが、面を取れるブランドがない。なぜなら既存メーカーは全て小規模D2Cで、チェーンの棚を維持するための安定供給力がないから」**

あぷかの囲い罠による生産増は、この構造的空白を埋める武器になる。品質勝負（飲食店のリプレイス軸）ではなく、**安定供給力によるポジション獲得**がペットフードのリプレイス軸。

## 3. 攻め口の定義：統一ターゲット

### 議論の経緯と帰結

当初「実店舗チェーン」と「既存PFメーカー」を別カテゴリで整理しようとしたが、ペテモがPB（ペテモオリジナル）を持っている時点で、チェーンもメーカーも**「PFメーカー」として同じテーブルに乗る**ことに気づいた。コーナンのペットコーナーも独立区画であり、ペット専門店との本質的差はない。

### 統一された攻め口

> **ターゲット：PFメーカー（PB含む）で、プレミアムエゾシカブランドを持たないところ**

飲食店との対比：

| | 飲食店 | ペットフード |
|---|---|---|
| 母集団の定義 | シカ肉を既に使っている店 | PFメーカー（PB含む）で、プレミアムエゾシカブランドを持たないところ |
| リプレイス軸 | 品質で既存仕入先を置き換える | エゾシカという原料ブランドをまだ持っていないメーカーに供給する |
| 攻め方の性質 | **既存の切替**（リプレイス） | **新規ライン追加**の提案 |

攻め口が「リプレイス」ではなく「新規追加提案」になることで、飲食店より入口のハードルは低い。「今の仕入先を変えてくれ」ではなく「エゾシカという新しいラインを追加しませんか」という提案。

### クラスタリング軸：鹿肉PFとの距離

メーカーを「エゾシカPFからの距離」で3段階に分類する。

| クラスタ | 定義 | 提案の性質 | 例 |
|---------|------|----------|---|
| **CL-近** | 鹿肉PFを既に扱っているが、エゾシカ特化ブランドではない | 原料切替 or 追加提案「今の鹿肉原料に加えて、囲い罠エゾシカを」 | ドッグスタンス、ZEN、北のジビエ等 |
| **CL-中** | プレミアムPF市場にいるが、鹿肉はまだ扱っていない | 新カテゴリ提案「プレミアムラインにエゾシカを加えませんか」 | 大手PFメーカーのプレミアムライン、チェーンPB |
| **CL-遠** | ペット関連事業を持つが、PFはこれから or 拡張中 | 事業提案「PB立ち上げにエゾシカを」 | イオンペット（ペテモPB拡張）等 |

距離が近いほど提案が通りやすいが、ボリュームが小さい（既存D2Cメーカーは少量）。距離が遠いほど獲得時のインパクトが大きいが、意思決定に時間がかかる。

### ペテモ＝イオンCFの戦略的位置づけ

ペテモはCL-中とCL-遠の両面を持つ。

- **CL-中の顔**: プレミアムPFの棚を持つチェーン → NB（ナショナルブランド）としての棚入れ先
- **CL-遠の顔**: ペテモオリジナル（PB）を展開中 → OEM原料供給先

イオンCFを入口にすれば、この両方に同時にアプローチできる。

```
【イオンCF】── 実績＝切符
    │
    ├──→【CL-中】ペテモ棚入れ（NB完成品）
    │        「プレミアム鹿肉PFの棚でエゾシカブランドの面を取る」
    │
    └──→【CL-遠】ペテモPB供給（OEM原料）
             「ペテモオリジナル 北海道エゾシカジャーキー」
```

## 4. 飲食店クラスタリングとの対応表

| 要素 | 飲食店（完了済み） | ペットフード（本文書） |
|------|-------------------|---------------------|
| 母集団定義 | シカ肉を使っている店（黒田リスト90件） | PFメーカー（PB含む）でエゾシカブランドを持たないところ |
| リプレイス仮説 | 「格段にうまい」→品質勝負 | 「面を取れるブランドがない」→安定供給力で新規ライン追加 |
| クラスタ軸 | 席数×予算帯 | 鹿肉PFとの距離（近／中／遠） |
| 典型先検証 | idematsu、TOM TOKYO、ニューバクロ | **要実施**：各クラスタ1社ずつWeb検証 |
| 総量試算 | 年間5,484-9,492kg（90件ベース） | **要実施**：メーカー×年間原料調達量ベース |
| 戦略的要衝 | CL-B（最大ボリュームゾーン、一頭使い提案） | ペテモ（CL-中×CL-遠の交差点、イオンCFが入口） |

## 5. 次のステップ

### Step 1：母集団リストの作成（別チャットでリサーチ）

「PFメーカー（PB含む）で、プレミアムエゾシカブランドを持たないところ」を網羅的にリスト化する。

調査対象：
- 鹿肉PFメーカー（ドッグスタンス、ZEN等＋未把握の事業者）
- プレミアムPFメーカー（鹿肉未参入だがプレミアムラインを持つ大手・中堅）
- PB展開チェーン（ペテモ、その他ペットショップチェーンのPB）
- OEM受託メーカー（レガールファクトリー等）

各社について確認すべき項目：
- [ ] 鹿肉PFの取扱有無・エゾシカ特化の有無
- [ ] 事業規模（売上・店舗数・販路）
- [ ] 原料調達構造（自社狩猟 vs 処理場 vs 卸）
- [ ] PB/OEMの有無・受託条件

### Step 2：クラスタ定義の精緻化

母集団リストができたら、CL-近/中/遠の各クラスタにB層（定量フィルタ）・C層（商談時検証条件）を定義する。

### Step 3：典型先のWeb検証

各クラスタから中央的な1社を選び、飲食店のidematsu/TOM TOKYO/ニューバクロと同じ深度で実態を検証する。

### Step 4：総量試算

クラスタ別の年間取引量ポテンシャルを試算し、蜂巣さんの100M→600M目標との整合性を確認する。
