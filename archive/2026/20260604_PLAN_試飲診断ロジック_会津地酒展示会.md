# 会津地酒 試飲診断ロジック 設計書（展示会ブース用）

作成日: 2026/06/04
用途: 26夏展示会のブース運用ツール（バイヤー向けタイプ診断 → 試飲 → 商談）

---

## 1. 企画概要

- **来場者**: 飲食店・量販店のバイヤー（エンドは飲食 or 小売）。エンド消費者向けではない。
- **目的**: 言語の質問でバイヤーを「タイプ」に振り分け、該当銘柄を複数提示。試飲・300ml持ち帰りで自店検証につなげる商談導線。
- **持参品**: 会津地酒19点（全点が試飲可）。これが診断の本線。
- **冷蔵庫陳列**: 持参の会津地酒に加え、他カテゴリ（五島列島の焼酎ほか）も陳列。診断結果からの回遊先として機能。

---

## 2. 合意済みの設計方針

1. **言語=非官能、試飲=官能** の役割分担。言語ではバイヤーが言葉で即答できる非官能情報（用途・路線）だけを取り、味の好みは試飲で取る。
2. **出力カテゴリに大和川が1本以上含まれればOK**。各カテゴリに大和川が該当する構成なので、強制挿入の処理は不要。
3. **飲食/小売は質問で分けない**。今回はボトル提供（瓶売り・瓶出し）が共通で、見た目・ラベル・形態が両販路で効くため、販路で割る根拠が薄い。販路差は試飲時の口頭トークで吸収。
4. **5カテゴリ構成**（味タイプベース。大和川が単独で全カテゴリを網羅できることを確認済み）。役割×味の3×3=9セルは軸が相関して空セルが出るため不採用。
5. **2段・可変長フロー**。最初に「定番 / 変わり種」の路線を1問で取り、用途で絞り切れたらそこで確定。味の差が残るカテゴリだけ味の質問を追加する。全員に味は聞かない。
6. **中間銘柄は両建て登録**。格と用途が中間にある数本は単一カテゴリに固定せず両路線に登録し、試飲で路線ごと再判定できる設計にする。
7. **試飲の役割は2段**。(a) カテゴリ内の銘柄選別、(b) 路線そのものの再判定（定番で入った人が試飲で「売りに使える」と転ぶ等）。
8. **300ml持ち帰り**=バイヤーが自店の客・スタッフで検証するサンプルとして機能。

## 3. 診断ロジック全体図

```
Q1 路線：このお酒、店でどう使いますか
   ├ 定番として回す ───────→ Q2(味)で T2 / T3 に分岐
   └ 変わり種・売りにする ──→ Q2(狙い)で T1 / T4 / T5 に分岐

【定番路線】Q2(味)
   キリッと辛口で料理を引き締めたい  → T2 食中・定番
   やわらかい旨みで懐深く合わせたい  → T3 旨口・実用

【変わり種路線】Q2(狙い)
   贈答・ギフトで格を出したい       → T1 華やぎ・ギフト
   日本酒が苦手な客／食後に出したい  → T4 甘やか・入門
   他店と差をつける・語れる酒        → T5 個性派・話題

   ↓ カテゴリ確定
該当銘柄セットを提示（大和川を優先表示）
   ↓
試飲＝官能で方向を確認・選別（追加試飲可 / 必要なら路線ごと組み替え）
   ↓
300ml持ち帰り＝自店で検証
```

補足: 質問数は回答者ごとに可変（多くが2問、定番路線は味Q2を含めて2問、変わり種も狙いQ2で2問）。用途で一意に絞れた時点で確定してよい。

## 6. 試飲・持ち帰りの運用

- カテゴリ確定後、そのカテゴリの「大和川＋他蔵」を並べて飲み比べさせる。同カテゴリ＝近い味の中で大和川を選んでもらう導線。
- 味覚の順応を避け、1カテゴリの提示試飲は2〜3杯に絞る。甘口（T4: カスモチ・桃の涙）は試飲順の最後に回す。
- 追加試飲は隣カテゴリへ広げる余地として活用（「もう一段辛い/甘いも試せます」）。
- 気に入れば300mlを持ち帰り＝自店検証。300ml・化粧箱・セットが多い構成はこの持ち帰り運用と相性が良い。

## 7. 未決の論点（次に決めること）

1. **Q1「定番/変わり種」の言葉の基準**（最重要）
   - 役割基準（毎日回す定番にしたい / 他店と差をつける売りにしたい）: 使い方で割る。中間品が試飲で動きやすく、入れ替わりのダイナミズムが大きい。
   - 商品性基準（広く知られた飲みやすい酒 / 珍しい・語れる酒）: 商品で割る。分類が安定し、無濾過・テロワールが変わり種に固定されやすい。
   - 方向性としては「入れ替わりうって面白い」=役割基準が合いそう。要決定。
2. **冷蔵庫の焼酎を診断タイプに含めるか**。含めるなら芋系→T4/T5、麦系→T2に緩く紐付け。診断本体は会津地酒で純化し焼酎は回遊専用とする案が、設計はすっきり。
3. **料理相性(ペアリング)の扱い**。試飲時の口頭フォローに回す（3カテゴリ/5カテゴリは維持）か、各銘柄に軽いペアリングタグを添えるか。
4. **タイプ数・命名の最終確定**（消費者向けネーミング）と、質問文・選択肢ラベルの確定。
