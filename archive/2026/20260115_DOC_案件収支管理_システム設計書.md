# 案件収支管理システム 設計書

## 📋 概要

### 目的
- 案件ごとの収支を可視化し、粗利管理を徹底する
- 見積書作成と収支管理を一体化し、営業の入力負荷を軽減する
- 月次報告・ダッシュボードのデータ基盤とする

### 基本方針
- **「入力しないと見積書が作れない」構造**により、入力習慣を強制
- 商品マスタは既存設計を踏襲（商品コードでユニーク、仕入先込み）
- 国内/海外で粗利計算ロジックを分離（蜂巣方針準拠）

### M3_商品

**設計思想**
- 商品コードでユニーク（1商品コード = 1仕入先の1商品）
- 異なる仕入先の同一商品は別コードとして管理
- 見積時に商品コード選択 → 仕入先・単価が自動確定

| 列 | 項目 | 必須 | 備考 |
|----|------|------|------|
| A | 商品コード | ○ | PRD_SNJ_XXX_0000_00 |
| B | 仕入先コード | ○ | S001〜 |
| C | 仕入先名 | ○ | 自動 or 手入力 |
| D | 商品名 | ○ | 表記統一必須 |
| E | カテゴリ | ○ | 水産/畜産/農産/酒類/他 |
| F | 単位 | ○ | kg/本/パック等 |
| G | 容量 | | |
| H | ロット入数 | | |
| I | 荷姿 | | |
| J | 賞味期限 | | |
| K | 温度帯 | ○ | 冷凍/冷蔵/常温 |
| L | 加工区分 | ○ | 単純仕入/定型加工/特注加工 |
| M | 仕入単価（税抜） | ○ | |
| N | 仕入値更新日 | ○ | |
| O | 国内標準売価 | ○ | 自動計算 |
| P | 海外標準売価 | ○ | 自動計算 |
| Q | 税率 | ○ | 8%/10% |
| R | JANコード | | |
| S | 商品特徴 | | |

**標準売価の算出式**
```
国内標準売価 = ROUNDUP(仕入単価 ÷ (1 - 国内目標粗利率), -2)
海外標準売価 = ROUNDUP(仕入単価 ÷ (1 - 海外目標粗利率), -2)
※百円単位で切り上げ
```

### M4_目標粗利率（固定テーブル）

**利益率ルール（2025-11-28 蜂巣方針）**

| 加工区分 | 国内（送料込） | 海外（送料別） |
|----------|----------------|----------------|
| 単純仕入 | 20% | 30% |
| 定型加工 | 25% | 35% |
| 特注加工 | 30% | 40% |

**運用ルール**
- セールス裁量で5%まで値引き可能
- 5%を超える値引きは蜂巣相談
- 加工ランクで始めた取引は次回以降も同価格

## 🔄 運用フロー

### 見積作成時（営業）

```
1. I1_案件ヘッダー入力
   - 案件番号、案件名、顧客、担当、区分等
       ↓
2. I2_売上明細入力
   - 商品コード選択 → 商品名・標準売価が自動表示
   - 数量・販売単価を入力
       ↓
3. O1_見積書で案件番号入力 → PDF出力
       ↓
※この時点でO6_収支表の売上側は完成
```

### 受注後（営業）

```
4. I3_仕入明細入力
   - 通常はI2からコピー（商品・数量同じ）
   - 仕入先・仕入単価は自動表示
       ↓
5. I4_経費明細入力
   - 物流費、手数料等を入力
       ↓
6. I1_ステータス更新（見積中→受注）
       ↓
7. O2_発注書出力 → 仕入先へ
       ↓
8. O6_収支表で採算確認
```

### 納品・請求（営業/事務）

```
9. O3_納品書出力 → 顧客へ
       ↓
10. O4_請求書出力 → 顧客へ
       ↓
11. I1_ステータス更新（納品済→回収完了）
```

### 月次報告

```
O7_案件一覧 → O8_ダッシュボードで集計
       ↓
月次報告・部店長会議資料へ抜き出し
```

## ⚠️ 運用ルール

### 入力タイミング

| アクション | 入力シート | タイミング |
|------------|------------|------------|
| 引き合い発生 | I1 | 即時 |
| 見積作成 | I2 | 見積書出力前 |
| 受注確定 | I1（ステータス）, I3, I4 | 受注後速やかに |
| 経費発生 | I4 | 都度 |

### 四半期アーカイブ

- 四半期末に「回収完了」案件を別ファイルに移動
- 継続案件は新ファイルにコピー

### マスタ更新

- 商品マスタ：月次更新（既存運用を継続）
- 顧客/仕入先マスタ：随時追加
