## 🎯 技術的解決策

### 座標推定手法: IDW法（Inverse Distance Weighting）

**原理**:
```python
def idw_interpolation(target_lat, target_lon, reference_points, power=2):
    """
    未知の都市の座標を、確認済み8都市からの距離に応じて重み付けして推定
    
    重み = 1 / (距離 ^ power)
    
    近い基準点ほど影響が大きく、遠い基準点ほど影響が小さくなる
    """
    total_weight = 0
    weighted_x = 0
    weighted_y = 0
    
    for ref_data in reference_points.values():
        distance = geo_distance(target_lat, target_lon, ref_data['lat'], ref_data['lon'])
        weight = 1 / (distance ** power)
        
        weighted_x += weight * ref_data['x']
        weighted_y += weight * ref_data['y']
        total_weight += weight
    
    return int(weighted_x / total_weight), int(weighted_y / total_weight)
```

**利点**:
- ✅ 8都市の正確な座標を最大限活用
- ✅ 地図の歪みを自然に吸収
- ✅ 実装がシンプルで高速
- ✅ 全67都市が地図内に正しく配置

## 💡 技術的学び

### 1. 地図投影の難しさ
- ✗ 緯度経度→ピクセル座標の線形変換は失敗
- ✗ 地図の投影法が不明な場合、自動変換は困難
- ✓ 実測値ベースの補間が最も実用的

### 2. IDW法の有効性
- ✓ 少数の基準点（8点）で高精度推定が可能
- ✓ 地図の歪みを自然に吸収
- ✓ 計算が高速で実装が容易

### 3. 段階的アプローチの重要性
```
Step 1: 主要3都市の目視確認（札幌・稚内・釧路）
  ↓
Step 2: 5都市の追加確認（旭川・富良野・小樽・帯広・函館）
  ↓
Step 3: 8都市を基準にIDW法で残り67都市を推定
  ↓
Step 4: 全75都市の画像一括生成
```

### 4. 「完璧より実用」の哲学
- 理論的に完璧な自動変換を追求するより
- 実測値とハイブリッド手法で実用精度を確保
