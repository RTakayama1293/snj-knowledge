## 📋 エグゼクティブサマリー

### プロジェクト概要
新日本海商事の証憑業務（見積・発注・納品・請求）を管理するシステムを、**マクロ不要・関数のみ**で構築する。Access不在の環境下で、Excelの基本機能（VLOOKUP、SUMIF等）のみを使用し、即座に実運用可能なシステムを実現する。

### 開発期間・体制
- **期間**: 2週間（Phase 0）
- **体制**: 
  - 開発担当: あなた（主担当）
  - 技術レビュー: 松永さん（週1回程度）
  - ユーザーテスト: 杉田さん、松本さん
- **投資額**: 5万円（外部コンサル費用）

### 成功基準
- [ ] 法的必須記載事項が漏れなく記載される
- [ ] 案件番号ルールに準拠した運用が可能
- [ ] 5種類の書類（見積・発注・納品・請求・受領発注）が自動生成できる
- [ ] 粗利・粗利率が自動計算される
- [ ] マクロなしで動作（セキュリティ警告なし）

## 🎯 システム設計方針

### 基本コンセプト
**「シンプル・イズ・ベスト」**

- マクロゼロ：関数のみで実装
- 入力最小化：1回入力した情報は再利用
- 自動計算：金額・粗利は全て自動
- 視認性重視：Excel標準機能のみで分かりやすく

### 技術選択の理由
| 選択 | 理由 |
|------|------|
| Excel | 全員が使用可能、追加コスト不要 |
| マクロなし | セキュリティ警告なし、どのPCでも動作 |
| VLOOKUP中心 | 誰でも理解・修正可能 |
| 関数のみ | 保守性が高い、ブラックボックス化しない |

## 📐 案件番号ルール

### 番号体系
```
SNJ-YYMM-NNNN-X-YY

例：SNJ-2504-1001-S-01
```

### 各要素の定義

| 要素 | 桁数 | 説明 | 例 |
|------|------|------|-----|
| SNJ | 固定3文字 | 新日本海商事の略称 | SNJ |
| YYMM | 4桁 | 発注年月（和暦不使用） | 2504（2025年4月） |
| NNNN | 4桁 | 通し番号（毎月1001から開始） | 1001, 1002... |
| X | 1文字 | 担当者コード | S（杉田） |
| YY | 2桁 | 支店コード | 01（大阪本社） |

### 支店コード一覧
| コード | 支店名 |
|--------|--------|
| 01 | 大阪本社 |

※将来的に支店追加の可能性あり

### 通し番号の運用ルール
- **毎月1日にリセット**して1001から開始
- 月内は連番（1001, 1002, 1003...）
- 欠番は作らない（失注案件も番号維持）
- 手動管理（Phase 1で自動化検討）

### 4. 案件マスタ（1案件=1行）

| 列 | 項目名 | データ型 | 必須 | 入力方法 | 備考 |
|----|--------|---------|------|---------|------|
| A | 案件番号 | 文字列 | ○ | 手入力 | SNJ-YYMM-NNNN-X-YY |
| B | 見積日 | 日付 | ○ | 手入力 | YYYY/MM/DD |
| C | 顧客コード | 文字列 | ○ | 手入力 | C001 等 |
| D | 顧客名 | 文字列 | - | 自動（VLOOKUP） | 顧客マスタから取得 |
| E | 担当者 | 文字列 | - | 自動（VLOOKUP） | 顧客マスタから取得 |
| F | 仕入先コード | 文字列 | ○ | 手入力 | S001 等 |
| G | 仕入先名 | 文字列 | - | 自動（VLOOKUP） | 仕入先マスタから取得 |
| H | 納品日 | 日付 | ○ | 手入力 | YYYY/MM/DD |
| I | 納品場所 | 文字列 | ○ | 手入力 | 住所 |
| J | 支払条件 | 文字列 | - | 自動（VLOOKUP） | 顧客マスタから取得 |
| K | 仕入額合計 | 数値 | - | 自動（SUMIF） | 案件明細から集計 |
| L | 販売額合計 | 数値 | - | 自動（SUMIF） | 案件明細から集計 |
| M | 粗利 | 数値 | - | 自動（L-K） | 販売額 - 仕入額 |
| N | 粗利率 | パーセント | - | 自動（M/L） | 粗利 ÷ 販売額 |
| O | ステータス | 文字列 | ○ | 手入力 | 作成済/受注済/失注 等 |
| P | 備考 | 文字列 | - | 手入力 | 自由記述 |

**使用する数式**:
```excel
D列（顧客名）: =IFERROR(VLOOKUP(C2,顧客マスタ!$A:$B,2,FALSE),"")
E列（担当者）: =IFERROR(VLOOKUP(C2,顧客マスタ!$A:$E,5,FALSE),"")
G列（仕入先名）: =IFERROR(VLOOKUP(F2,仕入先マスタ!$A:$B,2,FALSE),"")
J列（支払条件）: =IFERROR(VLOOKUP(C2,顧客マスタ!$A:$G,7,FALSE),"")
K列（仕入額合計）: =SUMIF(案件明細!$A:$A,A2,案件明細!$H:$H)
L列（販売額合計）: =SUMIF(案件明細!$A:$A,A2,案件明細!$I:$I)
M列（粗利）: =L2-K2
N列（粗利率）: =IF(L2=0,"",M2/L2)
```

### 5. 案件明細（1商品=1行）

| 列 | 項目名 | データ型 | 必須 | 入力方法 | 備考 |
|----|--------|---------|------|---------|------|
| A | 案件番号 | 文字列 | ○ | 手入力 | 案件マスタと同じ |
| B | 行No | 数値 | ○ | 手入力 | 1, 2, 3... |
| C | 商品コード | 文字列 | ○ | 手入力 | P001 等 |
| D | 商品名 | 文字列 | - | 自動（VLOOKUP） | 商品マスタから取得 |
| E | 単位 | 文字列 | - | 自動（VLOOKUP） | 商品マスタから取得 |
| F | 数量 | 数値 | ○ | 手入力 | 整数または小数 |
| G | 仕入単価 | 数値 | - | 自動（VLOOKUP） | 商品マスタから取得 |
| H | 仕入額 | 数値 | - | 自動（F×G） | 数量 × 仕入単価 |
| I | 販売単価 | 数値 | - | 自動（VLOOKUP） | 商品マスタから取得 |
| J | 販売額 | 数値 | - | 自動（F×I） | 数量 × 販売単価 |
| K | 備考 | 文字列 | - | 手入力 | 自由記述 |

**使用する数式**:
```excel
D列（商品名）: =IFERROR(VLOOKUP(C2,商品マスタ!$A:$B,2,FALSE),"")
E列（単位）: =IFERROR(VLOOKUP(C2,商品マスタ!$A:$C,3,FALSE),"")
G列（仕入単価）: =IFERROR(VLOOKUP(C2,商品マスタ!$A:$D,4,FALSE),0)
H列（仕入額）: =F2*G2
I列（販売単価）: =IFERROR(VLOOKUP(C2,商品マスタ!$A:$E,5,FALSE),0)
J列（販売額）: =F2*I2
```

## 📄 書類シート設計

### 共通仕様

#### 入力セル
- **B1セル（黄色背景）**: 案件番号を入力
- 案件番号を入力すると、全ての情報が自動表示される

#### 書類番号の生成
各書類シートで、案件番号に応じた書類番号を自動生成：
```excel
=IF(B1="","","プレフィックス-"&B1)
```

#### 明細行の取得
INDEX-MATCH関数を使用して、案件明細から該当商品を取得：
```excel
=IFERROR(INDEX(案件明細!$D:$D,MATCH($B$1&行番号,案件明細!$A:$A&案件明細!$B:$B,0)),"")
```

## 💡 使用する関数一覧

### 1. VLOOKUP（垂直検索）
**用途**: マスタから情報を取得

```excel
=VLOOKUP(検索値, 範囲, 列番号, FALSE)
```

**使用箇所**:
- 顧客マスタからの情報取得
- 仕入先マスタからの情報取得
- 商品マスタからの情報取得

---

### 2. SUMIF（条件付き合計）
**用途**: 案件明細から合計を計算

```excel
=SUMIF(範囲, 条件, 合計範囲)
```

**使用箇所**:
- 仕入額合計の計算
- 販売額合計の計算

---

### 3. INDEX-MATCH（高度な検索）
**用途**: 複数条件での検索

```excel
=INDEX(戻り値の列, MATCH(検索値1&検索値2, 検索列1&検索列2, 0))
```

**使用箇所**:
- 書類シートでの明細取得
- 案件番号+行番号での商品取得

---

### 4. IF（条件分岐）
**用途**: 空欄判定、ゼロ除算回避

```excel
=IF(条件, 真の場合, 偽の場合)
```

**使用箇所**:
- 粗利率計算時のゼロ除算回避
- 書類番号生成時の空欄判定

---

### 5. IFERROR（エラー処理）
**用途**: VLOOKUP等のエラーを空欄に変換

```excel
=IFERROR(数式, エラー時の値)
```

**使用箇所**:
- 全てのVLOOKUPをラップ
- 存在しないコードのエラー回避

---

### 6. TODAY（当日日付）
**用途**: 請求日の自動入力

```excel
=TODAY()
```

**使用箇所**:
- 請求書の請求日

---

### 7. COUNTIF（条件付きカウント）
**用途**: 明細行数の判定

```excel
=COUNTIF(範囲, 条件)
```

**使用箇所**:
- 書類シートでの明細表示制御

## ⚠️ 制約事項・注意点

### 技術的制約

1. **同時編集不可**
   - Excelファイルベースのため、複数ユーザーでの同時編集不可
   - 対策: Google Driveでの排他制御、またはPhase 1でGoogle Apps Scriptへ移行

2. **データ量の上限**
   - 案件マスタ: 約5,000件で動作が重くなる見込み
   - 対策: 定期的なアーカイブ（四半期ごと等）

3. **INDEX-MATCH関数の制限**
   - 配列数式が必要な環境では動作しない可能性
   - 対策: Excel 2016以降を推奨

4. **通し番号の手動管理**
   - 毎月の通し番号リセットは手動
   - 対策: Phase 1でマクロまたはGoogle Apps Scriptで自動化

---

### 運用上の注意点

1. **案件番号の一致**
   - 案件マスタと案件明細の案件番号は必ず一致させる
   - ミスした場合、書類が正しく生成されない

2. **マスタの事前登録**
   - 顧客・仕入先・商品は、案件登録前にマスタに登録必須
   - 未登録コードを使用すると空欄表示になる

   - 自動計算列（D,E,G等）の数式を誤って削除しないよう注意
   - 対策: テンプレート行を常に保持、コピー元とする

## 📝 付録

### A. テンプレート行の使い方

**案件マスタの3行目**、**案件明細の4行目**がテンプレート行：

1. テンプレート行全体を選択
2. コピー（Ctrl+C）
3. 最終行の次の行に貼り付け（Ctrl+V）
4. 手入力項目のみ入力
5. 自動計算列は触らない

これにより、数式が自動調整されて新規データに適用される。

---

### B. よくある質問（FAQ）

**Q1: 案件番号を間違えて入力してしまった**
A1: 案件マスタと案件明細の両方を修正する。書類シートは自動更新される。

**Q2: 顧客マスタに新しい顧客を追加したい**
A2: 顧客マスタシートの最終行に追加。既存案件の自動入力も更新される。

**Q3: 商品の価格が変わった**
A3: 商品マスタの単価を変更。**過去の案件には影響しない**（案件明細に既に値が入っているため）。

**Q4: 書類シートで明細が表示されない**
A4: B1セルの案件番号と、案件マスタ・案件明細の案件番号が一致しているか確認。

**Q5: 粗利率が#DIV/0!エラーになる**
A5: 販売額合計がゼロの場合に発生。案件明細に商品が登録されているか確認。

**Q6: 月が変わったら何をすべきか**
A6: 通し番号を1001にリセット。新しい案件から新しい通し番号を使用。
