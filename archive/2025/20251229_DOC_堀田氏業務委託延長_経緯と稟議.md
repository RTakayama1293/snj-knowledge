# 堀田氏 業務委託契約延長 経緯と稟議内容

## 基本情報

| 項目 | 内容 |
|------|------|
| 対象者 | 堀田弘之氏（EC・デジタルマーケティング専門家） |
| 前回契約期間 | 令和7年10月1日〜12月31日 |
| 延長契約期間 | 令和8年1月1日〜3月31日（3か月） |
| 報酬 | 月額5万円（税込）×3か月 ＝ 計15万円 |
| 前回決裁番号 | 250036（9/29）、250040（10/16） |

## 経緯

### 前回契約の成果
- EEZOの現状分析・課題整理
- CS-Cart → Shopify移行の方針決定

### 延長の背景
- EC改善施策が進行中
- Shopify移行稟議が別途並行して進行
- 担当交代による引継ぎロス回避のため継続が妥当

### 稟議作成時の論点
- 当初案は項目が多すぎる懸念あり → 簡潔版に修正
- 「他の人でなく堀田氏継続の理由」が必要 → Shopify稟議と独立させるため抽象化
- 延長理由を先頭に配置し、論理構成を整理

## 最終稟議内容

```
　稟議内容
次世代マーケットプレイス「EEZO」の改善のため、EC・デジタルマーケティング専門家である堀田弘之氏への業務委託契約の延長（月額5万円×3か月、計15万円）をご承認いただきたい。
　記
　
１．延長理由：EC改善施策がいまだ進行中であり、継続が妥当と判断。
２．業務内容：サイト設計・販促の助言。プラットフォーム移行支援。
３．契約期間：令和8年1月1日〜3月31日（3か月）
４．報酬：月額5万円（税込）×3か月 ＝ 計15万円
５．その他：前回契約（決裁番号250036、250040）と同条件
以上
ご決裁のほど、よろしくお願いいたします。
```
