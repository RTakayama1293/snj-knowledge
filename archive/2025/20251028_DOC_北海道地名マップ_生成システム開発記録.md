# 北海道地名マップ生成システム開発記録

**作成日**: 2025年10月28日  
**目的**: 北海道の主要75地名について、地図上の位置を示す画像を一括生成

---

## プロジェクト概要

### 要件
- ベース画像: 北海道地図（緑、1600x1200px）
- 対象地名: 75箇所の市町村
- 出力形式: PNG（透明背景）
- デザイン: 赤い星マーカー + 日本語地名 + ローマ字

### 達成事項
✅ 透明背景対応（白背景を自動除去）  
✅ 高品質レンダリング（TrueColorAlpha）  
✅ 日本語フォント対応（Noto Sans CJK）  
✅ 座標スケーリング・オフセット補正機能  
✅ サンプル8都市での検証

---

## 技術仕様

### スクリプト構成
- **言語**: Python 3
- **ライブラリ**: Pillow (PIL)
- **フォント**: NotoSansCJK-Bold.ttc
- **出力**: PNG（RGBA、透明背景）

### デザインパラメータ
```python
FONT_SIZE_JP = 90    # 日本語フォントサイズ
FONT_SIZE_EN = 70    # 英語フォントサイズ
STAR_SIZE = 50       # 星マーカーサイズ
```

### 座標補正パラメータ（現在値）
```python
SCALE_X = 0.97       # 東西方向の縮小率
SCALE_Y = 0.985      # 南北方向の縮小率
OFFSET_X = -48       # 東西方向のオフセット（西へ48px）
OFFSET_Y = 0         # 南北方向のオフセット
```

**補正式**:
```python
x_補正 = int(x * SCALE_X + OFFSET_X)
y_補正 = int(y * SCALE_Y + OFFSET_Y)
```

## 問題分析

### 問題1: スケーリング歪み
**現象**: 札幌を基準として、距離に応じて誤差が拡大  
**原因**: スケーリング係数が適切でない、または非線形歪みの存在  
**方向性**: 西南西方向への系統的ずれ

### 問題2: 座標データ精度
**現象**: 元の座標データ自体が実際の位置と一致していない可能性  
**原因**: 手動設定による誤差、または座標系の違い  
**対策**: 正確な緯度経度データからの座標変換が必要

3. **自動位置調整**: 地名の重なり回避機能

## 備考

### 技術的メモ
- 元画像はWEBP形式（24900B）→ RGBA変換
- 白背景除去: RGB値が240以上を透明化
- フォント縁取り: stroke_width で視認性確保

### デザイン考慮点
- 星マーカーは地名の真上に配置
- テキストは星の下に日本語→ローマ字の順
- 白文字 + 黒縁取りで背景を問わず視認可能
