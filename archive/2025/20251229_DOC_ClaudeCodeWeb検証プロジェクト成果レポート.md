# Claude Code on the Web 検証プロジェクト成果レポート

## 概要

**実施日**: 2025年12月29日
**目的**: ブラウザベースの「Claude Code on the Web」を使ったEDA（探索的データ分析）ワークフローの検証
**結果**: 成功。ローカルインストール不要で、実用的なEDAを実行できることを確認

---

## 背景と課題

### 制約条件
- 社内PCへのソフトウェアインストールにIT承認が必要
- ローカル版Claude Codeのnpmインストールは困難
- GitHubは承認済み、プライベートリポジトリ作成可能

### 解決策
- **Claude Code on the Web**（https://claude.ai/code）を採用
- ブラウザのみで動作、GitHubリポジトリと連携
- Pro/Maxプランで利用可能（リサーチプレビュー段階）

---

## 検証手順

### Step 1: リポジトリ準備

以下の構成でテスト用リポジトリを作成：

```
claude-code_test/
├── CLAUDE.md                 # Claude Code用指示書（最重要）
├── README.md
├── requirements.txt
├── .gitignore
├── .claude/
│   └── settings.json         # 自動セットアップ用フック
├── data/
│   ├── raw/
│   │   ├── sales.csv         # 販売データ（500件）
│   │   └── customers.csv     # 顧客データ（100件）
│   └── processed/
├── experiments/
│   └── exp001_baseline/outputs/
└── src/
```

### Step 2: CLAUDE.md の設計

CLAUDE.mdに以下を記載：
- プロジェクト概要（目的・データ・評価指標）
- データセットのスキーマ定義
- ディレクトリルール（data/raw/は編集禁止等）
- EDA標準フロー（8ステップ）
- ドメイン知識（北海道食材商社の業界知識）

### Step 3: GitHubにプッシュ

```bash
git init
git add .
git commit -m "Initial setup"
git remote add origin https://github.com/[username]/claude-code_test.git
git push -u origin main
```

### Step 4: Claude Code on the Web で実行

1. https://claude.ai/code にアクセス
2. リポジトリ「claude-code_test」を選択
3. 指示: **「data/raw/sales.csv のEDAを実行して」**

### Step 5: 結果確認

- 自動でTodoリストが生成され、順次実行
- 約10分でEDAレポート + 6枚のグラフが生成
- PRを作成してGitHubにマージ

## 生成された成果物

### EDAレポート（eda_report.md）

#### 基本情報
| 項目 | 値 |
|------|-----|
| 分析対象期間 | 2024年1月〜12月 |
| 総レコード数 | 500件 |
| 総売上 | 10,781,200円 |
| 平均注文単価 | 21,562円 |
| ユニーク顧客数 | 91人 |

#### 主要な分析結果

**1. 季節性**
- 12月が最大売上（約184万円、全体の17%）
- 8月も高売上（お中元需要）
- 4月が最低（年度切替の法人需要減）

**2. 商品カテゴリ別**
| カテゴリ | 売上構成比 | 特徴 |
|---------|-----------|------|
| 水産物 | 36.4% | 主力商品、毛ガニが最高売上 |
| 畜産物 | 23.3% | 平均単価最高（約3万円） |
| 酒類 | 21.6% | 安定した売上 |
| 農産物 | 18.7% | 注文数多いが単価低い |

**3. 顧客種別**
| 種別 | 売上構成比 | 平均単価 |
|------|-----------|----------|
| toB（法人） | 80.1% | 39,436円 |
| toC（個人） | 19.9% | 7,633円 |

**4. チャネル別**
| チャネル | 売上構成比 | 特徴 |
|---------|-----------|------|
| 直販 | 63.1% | 主力、高単価 |
| 卸 | 20.9% | 高単価だがボリューム少 |
| EC | 16.0% | 注文数最多だが単価低い |

**5. 地域別**
- 関東が売上の約60%
- 北海道地元は14%（伸びしろあり）

#### ビジネス提言（AIが自動生成）
1. 年末需要の最大化（早期予約キャンペーン）
2. toB顧客への営業強化
3. ECチャネルのLTV向上（セット商品等）
4. 北海道地産地消キャンペーンの余地
5. 畜産物のプレミアム訴求強化

## 検証結果の評価

### 成功点

| 観点 | 評価 | 詳細 |
|------|------|------|
| セットアップ容易性 | ◎ | ローカルインストール不要、ブラウザのみ |
| CLAUDE.mdの効果 | ◎ | 指示書通りにEDA標準フローを実行 |
| 指示のシンプルさ | ◎ | 「EDAを実行して」の一言で全工程を自動化 |
| 出力品質 | ◎ | 実用的なレポート + 可視化を自動生成 |
| ドメイン知識の反映 | ○ | 季節性・顧客種別など業界特性を考慮 |

### 改善点・注意点

| 観点 | 内容 |
|------|------|
| データサイズ | GitHub制限（100MB/ファイル）に注意 |
| 日本語フォント | japanize-matplotlibの設定が必要な場合あり |
| セッション時間 | 長時間タスクはタイムアウトの可能性 |
| ネットワーク | 外部API接続は制限あり |

## 今後の活用方針

### 1. テンプレートリポジトリ化

今回のリポジトリ構成をテンプレートとして、新規EDAプロジェクトに再利用：

```
snj-eda-template/
├── CLAUDE.md          # 雛形（プロジェクト固有部分を編集）
├── .claude/settings.json
├── requirements.txt
└── ...
```

### 2. 命名規則

```
snj-[テーマ]-[種別]-[時期]

例:
snj-sales-eda-2024
snj-lead-analysis-expo2025
snj-inventory-forecast-q1
```

### 3. 適用候補タスク

| タスク | 優先度 | 備考 |
|--------|--------|------|
| 展示会リード分析 | 高 | 111件のリードデータ |
| EC購買行動分析 | 高 | EEZO改善に直結 |
| 顧客セグメント分析 | 中 | Sansan連携データ |
| 在庫回転率分析 | 中 | 季節商品の仕入れ最適化 |

### 4. CLAUDE.mdの拡充

実務データを扱う際は以下を追記：
- 機密情報の取り扱いルール
- 業界固有の指標定義（粗利率、リピート率等）
- 過去分析からの学び

## まとめ

**「data/raw/sales.csv のEDAを実行して」** という一言の指示から、約10分で：
- 10セクションの分析レポート
- 6枚の可視化グラフ
- 5つのビジネス提言

が自動生成された。

**核心的な学び**:
1. **CLAUDE.mdに文脈を書いておく** → 毎回の説明が不要
2. **ざっくり指示で十分** → 「何を」だけ伝え、「どう」はAIに任せる
3. **GitHubベースのワークフロー** → PRで変更管理、ローカル同期も容易

ローカルインストールの制約がある環境でも、実用的なAI駆動データ分析が可能であることを確認できた。
