- ABEファームに経緯報告書作成依頼中

### 目的

## 🌳 原因分析ツリー（構造的問題の特定）

### 前提
- 直接原因「見間違えた」は一旦受け入れる
- 焦点：**なぜ古い在庫が選択される状況だったのか**（構造的問題）
- 俗人的要素（注意不足等）は排除し、プロセス・仕組みの問題を特定

```
【問題】
古い在庫（2024/10製造）が選択され出荷された

├─ なぜ1-A：古い在庫がピッキング対象位置にあった
│  ├─ なぜ2-A：在庫配置がFIFO原則に基づいていない
│  │  ├─ なぜ3-A（真因）：製造日順配置ルールが定義されていない
│  │  └─ なぜ3-B（真因）：倉庫レイアウトが製造日順配置を前提としていない
│  │
│  └─ なぜ2-B：三分の一ルール超過在庫が通常在庫エリアに混在していた
│     ├─ なぜ3-C（真因）：賞味期限1/3経過在庫の隔離保管ルールがない
│     ├─ なぜ3-D（真因）：B品/特価品在庫の保管区分ルールがない
│     └─ なぜ3-E（真因）：定期的な在庫区分見直しプロセスがない
│
├─ なぜ1-B：製造日と賞味期限の識別が困難だった
│  └─ なぜ2-C：ラベルレイアウトがヒューマンエラーを防ぐ設計になっていない
│     ├─ なぜ3-F（真因）：製造日・賞味期限の表記位置/サイズ/色に区別がない
│     └─ なぜ3-G（真因）：ピッキング時の視認性を考慮したラベル設計基準がない
│
└─ なぜ1-C：三分の一ルール超過在庫が存在していた
   └─ なぜ2-D：賞味期限1/3経過後の在庫処分プロセスがない
      ├─ なぜ3-H（真因）：B品/特価品としての販売チャネルが定義されていない
      ├─ なぜ3-I（真因）：在庫廃棄判断基準とプロセスが定義されていない
      └─ なぜ3-J（真因）：製造〜販売サイクルと在庫回転期間の設計ミスマッチ
```

## 💡 ヒアリング結果から見えるシナリオ（想定）

### 【シナリオA】区分管理ルール不在型
```
→ Q5で「B品区分の仕組みなし」
→ Q4で「1/3超過も通常在庫と同じエリア」
→ Q3で「2024/10製造品は通常在庫エリアの奥にあった」

【構造的問題】
・真因3-C: 1/3超過在庫の隔離ルールがない
・真因3-D: B品保管区分ルールがない
・真因3-H: B品販売チャネルがない

【対策の方向性】
①賞味期限1/3経過時点で通常在庫から隔離
②B品/特価品としての販売ルート確立
③隔離在庫は物理的に別エリアへ
```

### 【シナリオB】FIFO非対応型
```
→ Q1で「製造日順配置ルールなし」
→ Q2で「倉庫レイアウトがランダム配置」
→ Q3で「2024/10製造品が手前に置かれていた」

【構造的問題】
・真因3-A: 製造日順配置ルールがない
・真因3-B: FIFO前提の倉庫レイアウトでない

【対策の方向性】
①製造日順配置ルールの策定
②倉庫レイアウトの見直し（古い→新しいの順で取れる設計）
```

### 【シナリオC】複合型
```
両方の問題が重なっている可能性
→ FIFO非対応 + 1/3超過在庫の混在

【対策の方向性】
上記①〜③すべて実施
```
