### Step 2: 残り67都市の座標を準備

**推奨アプローチ: 4点基準の補間法**

札幌・稚内・釧路に加えて函館を目視確認し、4点の正確な座標を基準点とする。

**技術的手法**:
```
エリア分割方式:
- 道北エリア（稚内基準）
- 道央エリア（札幌基準）
- 道東エリア（釧路基準）
- 道南エリア（函館基準）

各都市の緯度経度から最も近い基準点を特定し、
その基準点からの相対位置で座標を計算
```

**実装イメージ**:
```python
def calculate_coordinates(lat, lon, reference_points):
    """
    4つの基準点からの逆距離重み付け補間（IDW法）
    距離が近い基準点ほど影響が大きい
    """
    total_weight = 0
    weighted_x = 0
    weighted_y = 0
    
    for ref_point in reference_points:
        # 基準点からの距離を計算
        distance = calculate_geo_distance(lat, lon, ref_point.lat, ref_point.lon)
        
        # 重み = 1 / 距離^2（近いほど大きい）
        weight = 1 / (distance ** 2)
        
        # 基準点の座標補正率を適用
        corrected_x = apply_correction(lon, ref_point)
        corrected_y = apply_correction(lat, ref_point)
        
        weighted_x += weight * corrected_x
        weighted_y += weight * corrected_y
        total_weight += weight
    
    return int(weighted_x / total_weight), int(weighted_y / total_weight)
```

## 💡 学んだ教訓

### 1. 緯度経度の自動変換は非現実的
地図の投影法が不明な場合、完全自動変換は困難。実用的には：
- 主要な基準点（10-15箇所）を目視で正確に設定
- 残りは補間計算で推定
- 「完璧より実用」を重視

### 2. 座標のズレパターンを早期に発見すべき
旧座標が「全体的に東＋北にずれている」という系統的エラーを早く発見できていれば、一括オフセット補正で済んだ。

### 3. 目視確認の重要性
最終的には人間の目で「この位置でOK」と判断するのが最も確実。自動化にこだわりすぎない。

## 🚀 次回チャット開始時のコマンド

```python
# Step 1: 8都市の個別画像を生成
python3 << 'EOF'
import json
from PIL import Image, ImageDraw, ImageFont
import math
import os

BASE_IMAGE = '/mnt/user-data/uploads/hokkaidomap.png'
OUTPUT_DIR = '/mnt/user-data/outputs'
FONT_SIZE_JP = 90
FONT_SIZE_EN = 70
STAR_SIZE = 50

# 修正済み座標を読み込み
with open('/home/claude/corrected_locations.json', 'r', encoding='utf-8') as f:
    LOCATIONS = json.load(f)

def draw_star(draw, x, y, size, color='red'):
    points = []
    for i in range(10):
        angle = math.pi * 2 * i / 10 - math.pi / 2
        r = size if i % 2 == 0 else size * 0.4
        points.append((x + r * math.cos(angle), y + r * math.sin(angle)))
    draw.polygon(points, fill=color)

def create_location_map(location_data):
    img = Image.open(BASE_IMAGE).convert('RGBA')
    
    # 白背景を透明化
    datas = img.getdata()
    newData = []
    for item in datas:
        if item[0] > 240 and item[1] > 240 and item[2] > 240:
            newData.append((255, 255, 255, 0))
        else:
            newData.append(item)
    img.putdata(newData)
    
    draw = ImageDraw.Draw(img)
    
    # フォント設定
    try:
        font_jp = ImageFont.truetype("/usr/share/fonts/opentype/noto/NotoSansCJK-Bold.ttc", FONT_SIZE_JP)
        font_en = ImageFont.truetype("/usr/share/fonts/opentype/noto/NotoSansCJK-Bold.ttc", FONT_SIZE_EN)
    except:
        font_jp = ImageFont.load_default()
        font_en = ImageFont.load_default()
    
    x = location_data['x']
    y = location_data['y']
    
    # 星マーカー
    draw_star(draw, x, y, STAR_SIZE)
    
    # テキスト配置
    text_y = y + STAR_SIZE + 20
    
    # 日本語地名
    bbox_jp = draw.textbbox((0, 0), location_data['name'], font=font_jp)
    text_width_jp = bbox_jp[2] - bbox_jp[0]
    text_x_jp = x - text_width_jp/2
    draw.text((text_x_jp, text_y), location_data['name'], 
              fill='white', font=font_jp, stroke_width=4, stroke_fill='black')
    
    # ローマ字
    text_y += FONT_SIZE_JP + 10
    bbox_en = draw.textbbox((0, 0), location_data['romaji'], font=font_en)
    text_width_en = bbox_en[2] - bbox_en[0]
    text_x_en = x - text_width_en/2
    draw.text((text_x_en, text_y), location_data['romaji'], 
              fill='white', font=font_en, stroke_width=3, stroke_fill='black')
    
    return img

# 生成実行
os.makedirs(OUTPUT_DIR, exist_ok=True)

for location in LOCATIONS:
    try:
        img = create_location_map(location)
        filename = f"hokkaido_map_{location['romaji'].lower()}.png"
        filepath = os.path.join(OUTPUT_DIR, filename)
        img.save(filepath, 'PNG', optimize=False, compress_level=1)
        print(f"✓ 生成完了: {location['name']} → {filename}")
    except Exception as e:
        print(f"✗ エラー: {location['name']} - {e}")

print(f"\n全{len(LOCATIONS)}件の画像を生成しました")
print(f"出力先: {OUTPUT_DIR}")
EOF
```
