## 🎨 1. 複数仕入先対応

### 変更点
**案件明細シート**に「仕入先コード」列（G列）を追加

### 構造の変化
```
【v1.0】
案件マスタ → 仕入先コード（1つだけ）
     ↓
案件明細 → 商品リスト

【v2.0】
案件マスタ → 案件全体情報
     ↓
案件明細 → 商品リスト + 各商品の仕入先コード
```

### 使用例
```
案件番号: SNJ-2504-1001-S-01

明細1: エゾシカ肉 50kg → 仕入先: S004（ニセコ高原牧場）
明細2: じゃがいも 100kg → 仕入先: S001（北海道農協）
明細3: タラバガニ 30kg → 仕入先: S002（函館漁協）
```

### 発注書の発行方法
1. **案件番号**と**仕入先コード**の両方を入力
2. 該当仕入先の商品のみが自動表示
3. 仕入先ごとに発注書を印刷

**例**: 
- 発注書1: SNJ-2504-1001-S-01 + S004 → エゾシカ肉のみ
- 発注書2: SNJ-2504-1001-S-01 + S001 → じゃがいものみ
- 発注書3: SNJ-2504-1001-S-01 + S002 → タラバガニのみ

## 📄 2. 受領発注書の正しい定義

### 変更内容

**v1.0での誤解**: 注文請書（仕入先が発行）のようなもの  
**v2.0での正しい定義**: 顧客が内容確認・捺印して返送する発注確認書

### 書類の流れ
```
見積書（EST-） → 顧客検討
     ↓
受領発注書（RCV-） → 顧客が内容確認・捺印・返送
     ↓
発注書（POC-） → 仕入先へ発注
     ↓
納品書（DEL-） → 顧客へ納品
     ↓
請求書（INV-） → 顧客へ請求
```

### 受領発注書の特徴
- 赤字で「内容をご確認の上、ご捺印いただき、ご返送ください」と記載
- 捺印欄を明示
- 確認日、会社名、部署・役職、担当者名を記入する欄
- 見積書の内容（販売価格）を表示

## 📖 各書類シートの詳細

### 見積書（EST-）

**用途**: 顧客への見積提示  
**色**: 青系  
**特徴**:
- 見積番号: EST-（案件番号）
- 有効期限: 30日間（備考欄に記載）
- 販売価格を表示（仕入価格は非表示）
- 納品日・納品場所・支払条件を明記

**入力項目**:
- B3セル: 案件番号（黄色）

---

### 発注書（POC-）

**用途**: 仕入先への発注  
**色**: オレンジ系  
**特徴**:
- 発注番号: POC-（案件番号）-（仕入先コード）
- **仕入先コード指定**で該当商品のみ表示
- 仕入価格を表示（販売価格は非表示）
- 納品希望日・支払条件を明記

**入力項目**:
- B3セル: 案件番号（黄色）
- B4セル: 仕入先コード（黄色）← **v2.0の重要な追加機能**

---

### 納品書（DEL-）

**用途**: 顧客への納品確認  
**色**: 緑系  
**特徴**:
- 納品番号: DEL-（案件番号）
- 数量と単位のみ表示（金額なし）
- 納品場所を明記

**入力項目**:
- B3セル: 案件番号（黄色）

---

### 請求書（INV-）

**用途**: 顧客への代金請求  
**色**: 赤系  
**特徴**:
- 請求番号: INV-（案件番号）
- インボイス制度対応（登録番号明記）
- 消費税区分表示（10%対象）
- 振込先情報を明記
- 販売価格を表示

**入力項目**:
- B3セル: 案件番号（黄色）

---

### 受領発注書（RCV-）

**用途**: 顧客からの発注確認（捺印・返送用）  
**色**: 紫系  
**特徴**:
- 受注番号: RCV-（案件番号）
- 「内容をご確認の上、ご捺印いただき、ご返送ください」と赤字で記載
- **捺印欄を明示**
  - 確認日
  - 会社名
  - 部署・役職
  - ご担当者名と印
- 見積書の内容（販売価格）を表示

**入力項目**:
- B3セル: 案件番号（黄色）

## 🚀 使い方ガイド

### 基本的な業務フロー

#### 1. マスタデータの登録
```
【初回のみ】
1. 顧客マスタに取引先情報を登録
2. 仕入先マスタに仕入先情報を登録
3. 商品マスタに商品情報を登録
```

#### 2. 見積作成
```
【営業担当】
1. 案件マスタに新規案件を登録
   - 案件番号: SNJ-2504-1001-S-01
   - 見積日: 2025/04/07
   - 顧客コード: C001
   - 納品日: 2025/04/15
   
2. 案件明細に商品を登録
   - 商品コード: P001
   - 数量: 50
   - 仕入先コード: S004  ← v2.0で追加
   
3. 見積書シートで印刷
   - B3セルに案件番号入力
   - PDFで保存・送付
```

#### 3. 受注確認
```
【営業担当】
1. 顧客から受注連絡
2. 受領発注書シートで印刷
   - B3セルに案件番号入力
   - 顧客に送付（捺印・返送を依頼）
3. 案件マスタのステータスを「受注済」に更新
```

#### 4. 発注処理
```
【事務担当】
1. 仕入先ごとに発注書を作成
   - 発注書シートのB3に案件番号
   - B4に仕入先コード（例: S004）← v2.0の重要機能
   - 該当仕入先の商品のみ表示される
   
2. 複数仕入先がある場合は繰り返し
   - S001用の発注書を印刷
   - S002用の発注書を印刷
   - S004用の発注書を印刷
```

#### 5. 納品・請求
```
【事務担当】
1. 納品時
   - 納品書シートで印刷
   - 商品と共に送付
   
2. 請求時
   - 請求書シートで印刷
   - PDFで送付
```

## ⚠️ 注意事項

### 必須の入力順序
```
1. マスタデータ → 2. 案件マスタ → 3. 案件明細 → 4. 書類印刷
```

### よくある間違い

#### ❌ 間違い1: 仕入先コードの入力忘れ
```
案件明細で仕入先コード（G列）を入力しないと、
発注書が正しく生成されません。
```

#### ❌ 間違い2: 発注書の仕入先コード指定忘れ
```
発注書シートのB4セル（仕入先コード）を
入力しないと、全商品が表示されてしまいます。
```

#### ❌ 間違い3: テンプレート行の削除
```
案件マスタの3行目、案件明細の4行目は
テンプレート行なので削除しないでください。
```

## 📊 データ構造の変化

### v1.0 vs v2.0

| シート名 | v1.0 | v2.0 | 変更点 |
|---------|------|------|--------|
| 案件マスタ | 14列 | 14列 | 仕入先コードを削除（案件明細に移動） |
| 案件明細 | 11列 | **13列** | 仕入先コード・仕入先名を追加 |
| 商品カタログ | なし | **新規** | 仕入先別商品一覧 |

### 案件明細の列構成（v2.0）

| 列 | 項目名 | 入力/自動 | 説明 |
|----|--------|----------|------|
| A | 案件番号 | 手入力 | SNJ-YYMM-NNNN-X-YY |
| B | 行No | 手入力 | 1, 2, 3... |
| C | 商品コード | 手入力 | P001, P002... |
| D | 商品名 | 自動 | VLOOKUP |
| E | 単位 | 自動 | VLOOKUP |
| F | 数量 | 手入力 | 50, 100... |
| G | **仕入先コード** | **手入力** | **S001, S002... ← 新規** |
| H | **仕入先名** | **自動** | **VLOOKUP ← 新規** |
| I | 仕入単価 | 自動 | VLOOKUP |
| J | 仕入額 | 自動 | 数量×仕入単価 |
| K | 販売単価 | 自動 | VLOOKUP |
| L | 販売額 | 自動 | 数量×販売単価 |
| M | 備考 | 手入力 | 自由記述 |

## 🎓 改善のポイント

### 1. なぜ複数仕入先対応が重要か

**実務の現実**:
```
住友化学への納品案件
- エゾシカ肉 → ニセコ高原牧場から仕入
- じゃがいも → 北海道農協から仕入
- タラバガニ → 函館漁協から仕入

これを1つの仕入先でまとめるのは不可能！
```

### 2. なぜ受領発注書の定義が重要か

**法的リスクの回避**:
```
見積書 = 申込の誘引（法的拘束力なし）
受領発注書 = 顧客の発注意思の確認（証拠書類）
→ 後々のトラブル防止
```

### 3. なぜ体裁が重要か

**顧客の信頼獲得**:
```
シンプルすぎる書類 → 素人っぽい
プロフェッショナルな書類 → 信頼できる
```

## 🔄 v1.0からの移行手順

### ステップ1: マスタデータのコピー
```
1. v1.0の顧客マスタをコピー
2. v1.0の仕入先マスタをコピー
3. v1.0の商品マスタをコピー
   ※v2.0では「主要仕入先」列が追加されています
```

### ステップ2: 案件データの移行
```
1. v1.0の案件マスタをv2.0にコピー
   ※仕入先コード列は削除してOK
   
2. v1.0の案件明細をv2.0にコピー
   ※仕入先コード（G列）を手入力で追加
```

### ステップ3: 動作確認
```
1. 各書類シートで案件番号を入力
2. 正しく表示されるか確認
3. 発注書で仕入先コードを変えて確認
```

## 📞 サポート情報

### よくある質問

**Q1: 発注書で全商品が表示されてしまう**
A1: B4セル（仕入先コード）を入力してください

**Q2: 仕入先コードを間違えて入力した**
A2: 案件明細のG列を修正すれば、自動的に反映されます

**Q3: 新しい仕入先を追加したい**
A3: 仕入先マスタに新規行を追加してください

**Q4: 商品カタログの並び順を変えたい**
A4: 商品マスタの並び順を変更すれば、自動的に反映されます
