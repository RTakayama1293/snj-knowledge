## 1. エグゼクティブサマリー

### 事業概要
新日本海商事は、新日本海フェリー（日本海航路：小樽⇄舞鶴・新潟）の子会社として、旅客・貨物に続く「第3の事業価値」創出を目的に設立された北海道食材専門商社である。「現代の北前船」をコンセプトに、北海道の高品質食材を国内外に届けるビジネスモデルを構築中。

### 9ヶ月間の総括
2025年度は「仕込み期」と位置づけられ、商品・仕入先の開拓、販路構築、組織体制整備に注力した。売上目標6,000万円に対し実績約620万円（達成率10%）と数値面では未達だが、80社860商品の仕入先ネットワーク構築、展示会での169件商談獲得、初の海外出荷完了など、来期以降の「刈り取り」に向けた基盤整備が進んだ。

## 3. 売上構成計画の変遷

事業環境と商談進捗に応じて、売上構成計画を3度修正した。

### 6月時点の計画（初期構想）
```
日本酒30 / 百貨店5 / 牛鹿5 / 旅客3 / EEZO3 / DENBA4 / 魚国6 / 京番茶3 / その他1 = 60百万円
```
**特徴**: 日本酒輸出を柱に、百貨店物産展・魚国（給食）を両翼に据えた構成

### 8月時点の修正（展示会後）
```
日本酒30 / あか牛10 / 水産物9 / 旅客5 / DENBA3 / 魚国2 / その他1 = 60百万円
```
**変更点**: 百貨店・京番茶を削除、あか牛・水産物を追加。「ハレの日」市場への注力を反映

### 12月時点の修正（最終見通し）
```
日本酒25 / 水産物17 / あか牛5 / 旅客5 / DENBA3 / 魚国2 / みかん2 / その他1 = 60百万円
→ 実際の着地見込み：10～30百万円
```
**変更点**: 日本酒-5、あか牛-5、水産物+8。「立ち上がりの遅れ」を認識

## 6. SWOT分析

### 6.1 強み（Strengths）

| 分類 | 内容 | 具体例 |
|------|------|--------|
| **ブランド力** | 北海道ブランドの信頼性・人気 | 職域販売で「北海道ブランドは安定・人気」との評価 |
| **親会社アセット** | フェリー物流網、グループホテル | 船上販売成功、オーセント・楽水山との連携 |
| **仕入ネットワーク** | 80社860商品の開拓完了 | エゾシカ処理場9社、漁協4社、蔵元多数 |
| **展示会実績** | 短期間で多数の商談獲得 | 2回のEXPOで183社名刺、58商談 |
| **人材の多様性** | 多言語対応、専門性 | 永井（海外）、門永（調達）、高山（分析） |
| **機動性** | 小規模ゆえの意思決定の速さ | EEZO方針転換、Sansan即時導入 |

### 6.2 弱み（Weaknesses）

| 分類 | 内容 | 影響 |
|------|------|------|
| **組織規模** | 9名の小規模体制 | 配送頻度・対応力に限界（ヒルトン失注要因） |
| **EC転換率** | 0.04～0.09%（業界平均の1/50以下） | 販促投資が売上に直結しない |
| **与信管理** | 体制未整備 | 海外取引リスク、ヤマトヤシキクレーム |
| **インサイドセールス** | 体制未確立 | リピート受注の取りこぼし |
| **輸出プロセス** | 標準化未完了 | 契約・検疫対応に都度工数 |
| **在庫・物流** | 自社倉庫なし、加工機能限定 | 鮮魚は「不加工・運搬」が欠点 |

### 6.3 機会（Opportunities）

| 分類 | 内容 | 根拠 |
|------|------|------|
| **海外市場** | アジアの日本食ブーム | EXPO商談相手国TOP3がフィリピン・台湾・香港 |
| **ハレの日市場** | ホテル・結婚式場の高級需要 | ミシュラン店191店、高級ホテルリスト500社作成 |
| **ジビエ需要** | エゾシカ・ヒグマの注目度上昇 | ホロニック継続、ヒグマ肉引き合い多数 |
| **中国牛肉輸出** | 再開の可能性 | グループ出口氏（青島）との情報交換継続 |
| **EC移行** | Shopifyによる運用効率化 | toC特化で体験品質向上 |
| **道の駅連携** | 北海道-関西の自治体連携 | 旭川-和歌山、江差-東近江モデル |

### 6.4 脅威（Threats）

| 分類 | 内容 | 対策状況 |
|------|------|----------|
| **規制・検疫** | 各国の輸入規制、HACCP要件 | EU HACCP施設調査済、対応中 |

| **品質クレーム** | ヤマトヤシキ事件の再発リスク | 賞味期限管理・品質基準策定中 |
| **季節変動** | 水産物の不漁、農産物の天候依存 | ホタテ不漁で供給困難経験 |

## 10. 総括と提言

### 10.1 総括

2025年度前半9ヶ月は、「仕込み期」として以下の成果を達成した。

**達成事項**
- 80社860商品の仕入先ネットワーク構築（目標80%達成）
- 展示会での169件商談獲得、見積1,100万円提出
- イタリア向け初出荷完了（海外販売実績ゼロ→有へ）
- 組織体制整備（5名→9名体制、Sansan導入）
- EEZO方針確定（Shopify移行決断）

**未達事項**
- 売上620万円/6,000万円（達成率10%）
- 日本酒輸出の本格立ち上がり
- EEZO転換率改善
- リピート受注体制構築

### 10.2 提言

#### 短期（Q4）：「刈り取り」への転換
1. **EXPO見積1,100万円のクロージングに全リソース集中**
   - 担当者別アサイン、週次進捗管理
   - 「12月はバケーション＆クリスマス営業でスロー」を踏まえた1月攻勢

2. **Shopify移行の確実な完了**
   - 3月カットオーバー厳守
   - 移行後の販促計画同時策定

#### 中期（来期）：「選択と集中」
1. **売上目標の現実的設定**
   - 30百万円を基準に、達成可能な商材・チャネルに絞り込み

2. **「勝ちパターン」の確立**
   - エゾシカ×高級業態、日本酒×アジア輸出の2軸に注力
   - 成功事例のパターン化とナレッジ共有

3. **体制面の整備**
   - 与信管理・輸出プロセスの標準化
   - インサイドセールス体制の確立

### 10.3 最後に

「現代の北前船」というコンセプトは、地域間の需給ギャップを埋めるという明確な価値を持つ。9ヶ月間で構築した仕入先ネットワークと展示会実績は、来期以降の「刈り取り」に向けた確かな基盤である。

重要なのは、「仕込み期」から「刈り取り期」への意識転換。数字への執着を強め、「受注」をゴールとした営業活動への移行が求められる。
