# 証憑フロー整備プロジェクト
## 理想的な体制とスモールスタート要件

**作成日**: 2025年10月6日  
**目的**: 法的要件を満たす書類自動化の実現  
**対象**: SENDO書類生成機能（見積書・発注書・請求書）

---

## 📋 エグゼクティブサマリー

### **プロジェクトの本質**
```
短期目標: 書類作成自動化（VBAマクロ）で法的必須記載事項を漏らさない
長期目標: 電帳法対応・内部統制構築による完全な証憑管理体制
```

### **リソース投入の判断基準**

| フェーズ | 目的 | 必要リソース | 投資規模 |
|---------|------|------------|---------|

| **Phase 1（3ヶ月後）** | 電帳法対応・保存体制整備 | 4人×2ヶ月 | 50万円 |

## 🎯 Part 3: スモールスタート要件（Phase 0詳細）

### **3-1. プロジェクト定義**

#### **目的**
VBAマクロによる書類自動生成で、法的必須記載事項を漏らさない

#### **スコープ**
- **対象書類**: 見積書、発注書、請求書
- **対象機能**: テンプレート自動生成、PDF出力
- **対象外**: 電帳法保存要件、内部統制機能

#### **成功基準**
- [ ] 法的必須記載事項100%網羅
- [ ] 顧問税理士による最終承認取得
- [ ] 実案件での動作確認完了

---

### **3-2. あなたが習得すべきスキル（30時間）**

#### **スキル①: 商取引法務の基礎（15時間）**

**学習内容**:

**【見積書】**
- 法的性質: 申込の誘引（契約ではない）
- 必須記載事項:
  ```
  □ 見積番号、日付
  □ 有効期限
  □ 宛名（会社名・担当者名）
  □ 商品名・数量・単価・合計金額
  □ 消費税額（税率明記）
  □ 見積条件（納期・納品場所・支払条件）
  □ 発行者情報（住所・電話・登録番号）
  ```

**【発注書（注文書）】**
- 法的性質: 申込（これで契約成立する場合あり）
- 必須記載事項:
  ```
  □ 発注番号、日付
  □ 宛名（仕入先名）
  □ 商品名・数量・単価・合計金額
  □ 納期・納品場所
  □ 支払条件
  □ 検収条件
  □ （下請法対象なら）3条書面記載事項12項目
  ```

**【請求書】**
- 法的性質: 債権の行使
- 必須記載事項（インボイス対応）:
  ```
  □ 請求書番号、日付
  □ 宛名（会社名）
  □ 請求金額（税込・税抜明記）
  □ 消費税額（税率ごとに区分）
  □ 適格請求書発行事業者登録番号
  □ 取引内容（軽減税率対象品目の明記）
  □ 支払期限
  □ 振込先
  □ 発行者情報
  ```

**学習リソース**:
| 資料 | 所要時間 | 優先度 |
|------|---------|--------|
| 実務書籍『ビジネス文書の法律知識』（日本法令） | 3時間 | 必須 |
| 中小企業庁「契約書の作り方」PDF | 1時間 | 必須 |
| 国税庁「インボイス制度Q&A」該当部分 | 2時間 | 必須 |
| 顧問税理士との確認ミーティング | 2時間 | 必須 |
| 実装しながらの確認・調査 | 7時間 | - |

**習得目標**:
「見積書・発注書・請求書のテンプレートに何を書くべきか、法的に漏れがないか判断できる」
