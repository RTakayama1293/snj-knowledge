# カレンダータスク管理 - 更新フロースキル

**スキル名**: カレンダータスク一覧更新  
**作成日**: 2025年10月20日  
**対象ユーザー**: 高山（ミナトへ依頼する際のガイド）  
**目的**: Googleカレンダーの予定をExcelタスク一覧に効率的に反映するための標準化された手順

---

## 📋 スキル概要

### このスキルで実現できること
- Googleカレンダーの予定を指定期間で取得
- 不要な繰り返し予定（mail、リマインド等）を自動除外
- Excelタスク一覧形式に変換
- 優先順位リストとの統合

### 想定利用シーン
- **Weekly前**: 今週〜来週のタスクリスト作成
- **月次報告前**: 月間活動の振り返り用
- **プロジェクト確認**: 特定期間のタスク抽出
- **蜂巣さんへの報告**: 全タスクリストの可視化

## 🔧 ミナトの内部処理フロー

### Step 1: カレンダーデータ取得

```python
# Googleカレンダーからイベント取得
list_gcal_events(
    calendar_id="primary",
    time_min="2025-10-20T00:00:00+09:00",
    time_max="2025-10-31T23:59:59+09:00",
    max_results=100
)
```

### Step 2: 繰り返し予定の除外

除外対象の `recurringEventId`:
- `0fot4i4ibh71ufv2uqga6dkqd5`: mail（毎日8:30、11:45）
- `26kuhbenh1bdkb8hr1nccormv4`: リマインド（ドライブパック）
- `0u6qm1lnsdqoe7bnbvl91lkihm`: weekly（毎週月曜9:30）※明示的に指定された場合のみ除外
- `6qtv33ctjl910edkj18jt04e0i`: mail（11:45）

### Step 3: データ整形

カレンダーイベント → Excelフォーマット変換:

```python
{
    "日付": "2025-10-20",
    "曜日": "月",
    "開始": "09:30:00",
    "終了": "10:00:00",
    "id": 自動採番,
    "タスク": イベントのsummary,
    "所要時間": 終了-開始（時間単位）,
    "報告不要タスク": NaN（ユーザー判断）
}
```

### Step 4: Excelファイル生成

- ファイル名: `[YYYYMMDD]_DATA_カレンダータスクリスト.xlsx`
- シート構成:
  - タスク一覧（メインデータ）
  - 優先順位リスト（見込客、ワークフロー、EEZO、その他）

## 📊 出力フォーマット

### Excelファイル構造

#### シート1: タスク一覧

| 列名 | データ型 | 説明 | 例 |
|------|---------|------|-----|
| 日付 | Date | タスク実施日 | 2025-10-20 |
| 曜日 | Text | 曜日（月〜日） | 月 |
| 開始 | Time | 開始時刻 | 09:30:00 |
| 終了 | Time | 終了時刻 | 10:00:00 |
| id | Integer | タスクID（連番） | 1 |
| タスク | Text | タスク内容 | 議事録フォーマット見直し |

| 報告不要タスク | Integer | 1=報告不要 | 1 or NaN |

## ⚙️ カスタマイズ例

### 条件指定パターン

#### パターン1: 特定キーワード抽出
```
条件: タスク名に「EEZO」を含むもの
→ EEZO関連タスクのみ抽出
```

#### パターン2: 時間帯フィルタ
```

→ 通勤時間等を除外
```

#### パターン3: 所要時間閾値
```
条件: 所要時間が1時間以上
```

## 🚨 トラブルシューティング

### よくある問題と対処法

#### 問題1: データが取得できない
**症状**: カレンダーからデータが取得されない  
**原因**: 期間指定が不適切、またはカレンダーへのアクセス権限  
**対処**:
- 期間指定を明確にする（YYYY-MM-DD形式）
- カレンダーの共有設定を確認

#### 問題2: 繰り返し予定が除外されない
**症状**: mailやリマインドが残っている  
**原因**: 除外指定が不明確  
**対処**:
```
除外: mail、リマインド、weekly
```
と明示的に指定

#### 問題3: 所要時間が正しくない
**症状**: 所要時間の計算がおかしい  
**原因**: 終日イベントや時刻なしイベント  
**対処**:
- カレンダー側で時刻を設定
- 手動で所要時間を修正

#### 問題4: id が重複している
**症状**: タスクIDが被っている  
**原因**: 複数期間のデータをマージした  
**対処**:
- 最新データで id を振り直す
- 期間を分けて別ファイルで管理

## 🎓 ベストプラクティス

### 1. 依頼時のコツ

**Good**:
```
カレンダーのタスクをExcelに落として。
期間: 10/20〜10/31
除外: mail、リマインド
追加: 担当者列（空白で出力）
```

**Bad**:
```
タスク出して
```
→ 期間や条件が不明確

### 2. 定期運用

- **週次**: 毎週月曜のWeekly前に更新
- **月次**: 月末に月間タスクを抽出
- **臨時**: プロジェクト単位で随時抽出

### 3. データ管理

- ファイル名に日付を含める（例: `20251020_タスク一覧.xlsx`）
- 過去データは別フォルダで保管
- 最新版は常にデスクトップに配置

### 4. チーム連携

Weekly等で共有する際:
- タスク一覧をスクリーンショット
- 重要タスクをハイライト
- 次週の優先事項を明示
