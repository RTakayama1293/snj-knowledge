## 🔄 Sansan案件管理移行設計

### JIRAからSansanへの移行内容

#### 現在のJIRA管理項目
- F～A段階（見込み客）
- 25%～100%（案件進捗）
- 案件金額・商品情報
- 活動記録・次回アクション

#### Sansanでの管理方式
```
【案件ステータス】
- 見込み: F→E→D→C→B→A
- 商談: 25%→50%→75%→受注→納品→入金

【活動記録】
- 訪問・電話・メール履歴
- 提案内容・顧客反応
- 次回アクション・期限

【連携ポイント】
- ステータス変更 → 事務作業トリガー
- 受注確定 → 請求書生成準備
- 納品完了 → 請求書発行
```

### 進捗ステータス連携ロジック
```python
# Sansanステータス変更検知
def on_status_change(deal_id, new_status):
    if new_status == "受注":
        # 請求書マスタに情報追加
        add_to_invoice_master(deal_id)
        # 発注書作成トリガー
        trigger_purchase_order(deal_id)
    
    elif new_status == "納品":
        # 請求書発行準備
        prepare_invoice_generation(deal_id)
        # 営業にメール送信依頼通知
        notify_sales_for_invoice(deal_id)
```
