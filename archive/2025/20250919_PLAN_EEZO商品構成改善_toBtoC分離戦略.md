# EEZO商品構成改善プラン：toBとtoC体験分離戦略

## 📊 現状分析：なぜ「ボロクソ」と言われたのか

### 【LPと実商品の致命的ギャップ】

#### LPのメッセージ（toC向け）
```
"北の大地と海が育む旬を、匠の元へ"
- ニセコメロンのストーリー
- チーズ職人の哲学
- あか牛の健康価値
- エゾシカの環境貢献
```

#### 実際のECサイト商品（toB仕様）
```
【和菓子】
- 月寒あんぱん40個/箱
- どらやき50個/箱  
- 十勝ぜんざい30個/箱

【洋菓子】  
- シュークリーム80個入り/箱
- マドレーヌ80個/箱
- バターカステラ60個/箱

【あか牛】
- 部位別細分化（28部位）
- サイズ・価格表記なし
```

### 【若い女性陣の批判の核心】
1. **「箱売りばかり」** → 家庭で80個のシュークリームは無理
2. **「写真が行けてない」** → 業務用パッケージの無機質さ
3. **購入意欲が湧かない** → LPの世界観と購入体験の断絶

## 💡 解決策：段階的分離戦略

### Phase 1：商品サイズ多様化（即効策）

#### 【A. 家庭用サイズの追加】
```
現行商品の小分け対応：

【和菓子】
月寒あんぱん40個/箱 → 6個セット・12個セット追加
どらやき50個/箱 → 6個セット・10個セット追加

【洋菓子】  
シュークリーム80個 → 6個セット・12個セット追加
マドレーヌ80個 → 12個セット・20個セット追加

【効果】
- 家庭での購入可能性向上
- ギフト需要への対応
- toC顧客獲得
```

#### 【B. ギフト対応強化】
```
パッケージリニューアル：
- 美しいギフトボックス
- のし・メッセージカード対応
- 季節限定パッケージ

価格設定：
- 家庭用：やや高めの単価（利益率確保）
- 業務用：従来通り（効率重視）
```

### Phase 2：サイト体験分離（根本対策）

#### 【統合プラットフォーム設計】
```
EEZO.club 統一ランディング
    ↓
【入口選択】
"どちらをお探しですか？"
    ↓              ↓
【家庭・ギフト】    【事業・業務用】
toC体験           toB体験
```

#### 【toC体験の設計】
```
商品表示：
✓ 美しい商品写真（プロ撮影）
✓ 家庭サイズ中心（6-20個セット）
✓ ストーリー・背景説明
✓ レシピ・調理法提案
✓ ギフト対応機能

購入フロー：
✓ 1クリック購入
✓ 定期購入オプション  
✓ ギフト包装・のし
✓ メッセージカード
✓ 配送日時指定
```

#### 【toB体験の設計】  
```
商品表示：
✓ スペック・規格詳細
✓ 大容量・箱売り中心
✓ 価格・納期・MOQ
✓ 営業担当連絡先
✓ サンプル依頼機能

購入フロー：
✓ 見積もり依頼
✓ 商談・相談機能
✓ 継続取引対応
✓ 請求書払い
✓ 大口割引対応
```
