## 1. サービス概要

### 提供元
株式会社ADVATEC（旧KOLテクノロジーズ）。D2C事業の立ち上げ・売却経験を持つ実践者集団。導入3,600社超、登録インフルエンサー1万人超。資金調達7.1億円。

### 2つのプロダクトの役割

| | Beee（生成） | BLING（活用） |
|---|---|---|
| 何をするか | インフルエンサーを見つけて商品を渡し、SNS投稿を生み出す | 投稿を自動収集→選定→ECサイトに埋め込み→効果測定 |
| 核心機能 | AIマッチング、直接オファー、採用人数無制限、案件テンプレ（5分作成） | ハッシュタグ/アカウント自動収集、ノーコード埋込、投稿別CVR分析 |
| EEZOでの用途 | 食・ライフスタイル系インフルエンサーにエゾシカ商品をギフティング | 生成されたUGCをShopify商品ページ・トップに動的配置 |

### 一気通貫の構造

```
STEP1: GENERATE（Beee）
  商品登録 → インフルエンサー選定・オファー → 商品発送 → SNS投稿

STEP2: UTILIZE（BLING）
  投稿自動収集 → 管理画面で選定 → 商品紐付け → サイト埋込タグ発行 → 効果分析
```

競合は「生成のみ」か「活用のみ」のどちらか一方。両方をワンストップで持つのがADVATECの差別化ポイント。

### 実績データ（他社事例・スキンケア）

- ページ滞在時間: 47%向上（1分12秒→1分46秒）
- CVR: 1.3%→1.7%（約1.3倍）

### Shopify互換性

対応済み。タグ埋め込みのみ。モール型（楽天・Amazon等）は非対応。EEZOはShopify移行済みのため問題なし。

### 制約事項

- 登録ドメイン: 最大3つ
- ハッシュタグ: 最大2つ
- Facebook連携: ハッシュタグ収集にはInstagram API経由で必須
- 契約: 原則1年・一括払い（分割は+10%手数料）

### 4-4. UGCのEEZOサイト配置設計

EEZO既存ページ構造（ワイヤーフレーム準拠）に対するUGC配置:

| ページ | 配置箇所 | UGCの役割 | 実装方法 |
|---|---|---|---|
| **トップ** | キュレーションセクション下 | 「みんなの食卓」的な社会的証明 | BLINGウィジェット（カルーセル型） |
| **鹿の店（カテゴリ）** | 商品グリッド上部 | 購買意欲の喚起、商品利用イメージ | BLINGウィジェット（グリッド型） |
| **商品詳細** | 感覚的詳細セクション直下 | 「この商品を食べた人の声」として購買の最後の一押し | BLINGウィジェット（商品紐付け型） |
| **萬屋** | ギフトセット下部 | ギフト利用者の声 | 将来拡張（エゾシカ以外の投稿蓄積後） |

**配置の優先順位**: 商品詳細 > トップ > 鹿の店 > 萬屋

CVR改善への寄与が最も大きいのは商品詳細ページ。購買直前の意思決定をUGCで後押しするのが最大のレバレッジポイント。

### 4-5. インフルエンサー選定基準

堀田マニュアルのブランドトーン（静か・押し付けない・北欧ミニマル）との整合が必要。

**インフルエンサー分類の定義**（業界標準）:

| 分類 | フォロワー数 | 特徴 |
|---|---|---|
| ナノ | 1,000〜1万人 | エンゲージメント率最高、フォロワーとの距離が近い、PR臭が少ない |
| マイクロ | 1万〜10万人 | 特定ジャンルの専門性、費用対効果が高い |
| ミドル | 10万〜100万人 | 拡散力と信頼のバランス |
| メガ | 100万人以上 | 圧倒的リーチ、認知拡大向き |

**EEZOの狙い: ナノインフルエンサー（1,000-10,000人）中心**

理由: エゾシカ×丁寧な暮らしというニッチ領域では、リーチ量よりもエンゲージメントの質が重要。ナノの方がフォロワーとの信頼関係が深く、堀田マニュアルの「静かなトーン」とも親和性が高い。Beeeは採用人数無制限のため、ナノを複数起用して「面」でカバーする戦略が取れる。

**合致するインフルエンサー像**:
- 食・暮らし系（料理、テーブルコーディネート、丁寧な暮らし）
- フォロワー1,000-10,000人のナノインフルエンサー中心（良質なマイクロがいれば1万人台も可）
- 投稿トーンが落ち着いている（煽り系・テンション高め系は不適合）
- 40代以上、または40代以上に響くライフスタイル発信者
- 北海道・食材・ジビエへの関心あり

**避けるべきインフルエンサー像**:
- フォロワー数だけ多く、エンゲージメント率が低い
- 「激ウマ」「神コスパ」等の煽り系
- 商品レビューが浅い（写真1枚＋一言コメントだけ）
- ブランドの世界観と合わないビジュアルトーン

**Beeeでの具体的な選定フロー**:
1. AI解析でカテゴリ「食品」「ライフスタイル」「料理」で絞り込み
2. フォロワー数1,000-10,000でフィルタ（上限1万台まで許容）
3. 過去投稿のビジュアルトーン・文体を堀田が目視チェック（5-10名/回）
4. 合格者にオファー送信

### 4-6. ハッシュタグ戦略（BLING登録用: 2つまで）

| 候補 | メリット | デメリット |
|---|---|---|
| `#EEZO` | 自社ブランド完全捕捉 | 認知ゼロからの立ち上げ。初期は投稿ゼロ |
| `#eezo` | 同上（小文字版） | 同上 |
| `#エゾシカ` | 既存の市場投稿を収集可能 | ノイズ多い（猟・害獣駆除系も混在） |
| `#エゾシカ料理` | 料理文脈に絞れる | 投稿母数が少ない可能性 |

**推奨**: `#EEZO`（自社ブランド用）+ `#エゾシカ料理`（市場UGC収集用）の2本立て。

Beee経由のインフルエンサーには `#EEZO` を必須タグとして指定。市場の自然発生UGCは `#エゾシカ料理` で拾う。

## 5. KPI設計

### 5-1. 導入3ヶ月の評価指標

| 指標 | 目標 | 測定方法 |
|---|---|---|
| UGC生成数 | 月10件以上 | Beee管理画面の投稿完了数 |
| BLING掲載UGC数 | 累計20件以上（3ヶ月） | BLING管理画面 |
| UGCウィジェット表示回数 | 月500回以上 | BLINGレポート |
| UGCウィジェットクリック率 | 1%以上 | BLINGレポート |
| 商品詳細ページ滞在時間変化 | +20%以上 | GA4（BLING導入前後比較） |
| CVR変化 | +0.1ポイント以上 | GA4 |

### 5-2. ROI判定基準（6ヶ月時点）

**年間コスト**: BLING/Beee 70万 + 堀田延長分60万 = **130万/年**

**損益分岐の考え方**: 年間130万の追加投資を回収するには、CVR改善による売上増が月約11万（年130万）以上あればよい。EEZOの現在の月商水準でCVRが0.1ポイント改善すれば達成可能な範囲。

ただしEEZOは再構築フェーズにあり、UGC単体でのROI切り出しは困難。「サイト全体のCVR改善」「コンテンツ制作コスト削減」「ブランド信頼醸成」の複合効果として評価するのが現実的。

### 5-3. 撤退判断基準

6ヶ月時点で以下のいずれかに該当した場合、契約更新しない:

- UGC生成が月5件未満で改善見込みなし（インフルエンサーの食品分野ミスマッチ）
- ウィジェット表示はあるがクリック率0.3%未満（UGCの質が低い）
- CVR・滞在時間に統計的に有意な変化なし

## 6. リスクと対策

### 6-1. サービスリスク

| リスク | 影響 | 対策 |
|---|---|---|
| エゾシカ×食品という限定カテゴリでインフルエンサーが集まらない | UGC生成が停滞 | 「ジビエ」「北海道食材」「ペットフード」に間口を広げる。ナノインフルエンサー（1,000-10,000人）を複数起用して「面」でカバー。Beeeは採用人数無制限のためコストは変わらない |
| 投稿のトーンがEEZOのブランドと合わない | ブランド毀損 | BLING事前確認機能で全投稿を掲載前に検閲。堀田が品質ゲートキーパー |
| 1年契約・一括払いの資金負担 | キャッシュフロー影響 | Light（年46万税抜）は商事の予算規模で管理可能。分割は+10%のため一括推奨 |

### 6-2. 体制リスク

| リスク | 影響 | 対策 |
|---|---|---|
| 堀田延長が実現しない | 品質管理者不在 | 高山が監修を巻き取る（月3-5hの増加）。ただし他業務への圧迫あり |
| 黒田のオーガニック制作品質が堀田基準に達しない | SNS投稿のブランド不整合 | 3月中のテスト投稿で検証済みのはず。不足なら堀田残存期間でOJT集中 |
| 門永のサンプル手配が滞る | ギフティングが遅延→投稿サイクルが崩れる | 月初に翌月分のサンプルを一括手配。予約ウィンドウと連動 |

### 6-3. 法的リスク

| リスク | 対策 |
|---|---|
| 薬機法・景表法抵触（「健康にいい」等の表現） | BLING事前確認＋堀田チェック。エゾシカの健康効果は投稿ガイドラインでNGワードに指定 |
| 著作権・肖像権 | Beee経由投稿は二次利用許諾取得済み。市場UGC（ハッシュタグ収集）はBLINGの許諾依頼機能で対応 |
| ステマ規制（2023年10月施行） | Beee経由投稿にはPR表記を義務付け。案件テンプレートに `#PR` `#提供` を標準装備 |

## 7. 堀田延長の稟議メモ（参考）

堀田さんの契約延長を蜂巣さんに上申する場合の材料整理。

**延長しない場合に失われるもの**:
- UGC投稿の品質ゲートキーパー（ブランドトーンの番人）
- インフルエンサー選定の目利き
- SNS全体のクリエイティブディレクション
- 上記すべてを高山が巻き取ることによる企画業務の圧迫（月3-5h→実質的にはそれ以上）

**延長する場合のコスト**:
- 月5万×12ヶ月 = 年60万
- 高山が巻き取る場合の機会コスト（分析・企画に充てるはずだった時間）と比較すれば安い

**松竹梅の設計**:
- 松: 月10万（現行25hの約半分の12h。SNS＋UGC運用の主担当として週3hペース）
- 竹: 月5万（図の想定。月5h。監修・レビュー・品質管理に限定）
- 梅: 契約終了。高山が全巻き取り

**推奨**: 竹（月5万）。品質管理だけでも外に出しておく価値がある。高山のボトルネック化を防ぐ保険として安い。

## 8. 「使い倒す」ための追加施策

BLING/Beeeの基本機能を超えて、EEZOの資産として最大化するアイデア。

### 8-1. UGC→同梱カードへの還流

インフルエンサーの投稿で反応が良かったレシピ・盛り付けを、同梱カードの「食べ方提案」素材として二次利用する。Beee経由なら二次利用許諾済み。コンテンツ制作コストの削減と「顧客が作った食卓の写真」という社会的証明の紙媒体展開。

### 8-2. UGC→メルマガへの転用

BLINGで効果測定が高い投稿（クリック率上位）をメルマガのビジュアル素材として使用。プロ撮影なしでメルマガのリッチ化が可能。堀田メルマガガイドラインの「静かなトーン」に合う投稿を優先的に選定。

### 8-3. インフルエンサー→生産者ストーリーへの橋渡し

Beeeで関係構築したインフルエンサーのうち、特に親和性が高い人を「あぷかの森」取材に招待。生産者訪問コンテンツは通常のギフティング投稿より圧倒的にエンゲージメントが高い。代田さん（ライター兼PG）との協業で長尺コンテンツ化も可能。ただし協業成立後の将来施策。

### 8-4. ペットフード × UGCの別軸展開

エゾシカペットフードのUGCは人間用食品とは別のインフルエンサー層（犬・猫アカウント）が対象。ハッシュタグ枠は2つしかないため、ペットフード用のハッシュタグはBeee案件の投稿指示で個別管理し、BLINGでの自動収集はエゾシカ料理に集中させる。
