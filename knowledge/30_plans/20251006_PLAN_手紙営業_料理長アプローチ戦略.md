# 大阪ホテル料理長向け手書き手紙営業戦略
**新日本海商事 営業アプローチ計画書**

## 📋 **戦略概要**

### **■ 実施概要**
• 大阪の一休掲載ホテル102店舗の料理長・総料理長に手書きで手紙を送付
• 現代の北前船としての自己紹介と北海道食材の魅力を伝達
• 無償サンプル選択権を付与し、返信・問い合わせを促進

### **■ 背景**
• ホテル日航大阪との商談が順調に進展（ホテレス懇親会での出会いがきっかけ）
• 懇親会という「自然な出会いの場」での人脈構築が最も効果的と判明
• 料理長との直接対話により、具体的なニーズと解決策の提案が可能

### **■ 課題**
• メールでのアプローチは開封率が低く、スルーされる可能性が高い
• 電話は代表窓口で料理長まで繋いでもらえず、予約窓口では営業電話として迷惑をかける
• しばらくホテレスのような業界懇親会・展示会の予定がなく、自然な接点機会が限定的

### **■ 目的**
• 料理長・総料理長との直接面談機会を創出し、信頼関係を構築
• 北海道食材に関する具体的な見積提出まで進展
• 最終的に受注獲得し、継続的な取引関係に発展

### **■ 仮説**
• 手書き手紙は開封率99%で、メールの20倍以上の効果が期待できる
• 無償サンプル選択権により、料理長にとって「試してみたい」インセンティブを提供
• 「なぜあなたに」の特別感演出により、画一的な営業ではない印象を与える

## ✍️ **手紙構成・内容設計**

### **基本構成フレームワーク**
```
【導入】（30秒で興味喚起）
- 現代の北前船としての挨拶
- なぜこの料理長にお手紙したかの理由

【信頼構築】（60秒で安心感）
- 新日本海フェリーグループの実績
- 既存導入事例（オーセントホテル等）
- フェリー物流の独自性

【提案価値】（90秒で具体的メリット）
- その料理長のスタイルに合った食材の魅力
- 品質・ストーリー性・価格優位性
- 他では手に入らない特別感

【行動喚起】（30秒で次のステップ）
- 無償サンプル選択権の案内
- 簡単な返信方法の提示
```

### **パーソナライゼーション要件**
• **料理長名**: 必ず手書きで正確に記載
• **ホテル特性**: 施設の特徴・客層を反映した食材提案
• **季節性**: 送付時期に応じた旬の食材提案
• **差別化**: 「なぜあなたに」の特別感演出

```

【Option C：電話方式】
- 専用ダイヤル設置
- 営業時間明記
- 担当者直通番号提示
```

## 💰 **コスト試算・投資回収**

### **直接コスト**
```
【郵送費】：51通 × 94円（定形外） = 4,794円
【サンプル商品代】：申込率30%想定で約15件 × 3,000円 = 45,000円
【配送費】：サンプル15件 × 1,500円 = 22,500円
【印刷・封筒代】：約5,000円
【合計】：約77,000円
```

### **人件費・機会コスト**
• **手書き時間**：10分/通 × 51通 = 8.5時間
• **事務処理時間**：3時間
• **フォローアップ時間**：10時間

### **投資回収試算**
• **面談設定10件**：51通に対し約20%の反応率想定
• **見積提出5件**：面談実施の50%で具体的商談に発展
• **受注獲得1件**：見積提出の20%で受注
• **必要単価**：77,000円 ÷ 1件 = 77,000円（通常取引の1/10程度）

## 🔄 **フォローアップ計画**

### **段階的アプローチ**
```
【Phase 1】：サンプル到着確認（送付後1週間）
- 到着確認とお礼の連絡
- 使用感・感想のヒアリング

【Phase 2】：本格提案（サンプル送付後2-3週間）

【Phase 3】：関係構築（継続的）
- 季節商品の情報提供
- 新商品入荷情報の優先案内
- 長期的パートナーシップ構築
```

• **手紙開封推定率**: 返信・問い合わせ率から逆算

• **商談転換率**: サンプル送付から商談設定率
• **受注転換率**: 商談から実際受注率

## 📋 **成功要因・リスク対策**

### **成功のポイント**
• **個別性**: 画一的でない、その料理長への特別感演出
• **品質**: サンプル・書類すべてプロ品質維持
• **迅速性**: 申込から発送まで素早い対応
• **継続性**: 一度きりでない長期関係構築視点

### **リスク対策**
• **無反応**: 15%の反応率でも7-8件、十分な成果期待
• **サンプル原価負担**: 1件3,000円でも商談1件で回収可能
• **配送トラブル**: 信頼できる運送業者・保冷梱包の徹底

## 🚢 **「現代の北前船」コンセプトとの整合性**

• 北前船商人も各地で信頼関係を一から構築
• 紹介があっても最終的には自分たちの誠実さで勝負
• 手書きの温かみは江戸時代の商人の心意気と共通

### **戦略的価値**
• 人脈は活用するが依存はしない自立した営業スタイル
• 品質とストーリー性で差別化を図る本質的アプローチ
• 持続可能な関係構築への真摯な投資
