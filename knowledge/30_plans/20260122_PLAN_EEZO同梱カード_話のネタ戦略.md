# EEZO同梱カード設計：「話のネタ」戦略

**作成日**: 2026年1月22日  
**文脈**: 4月Shopifyローンチに向けた無形価値創出施策の具体化

---

## 1. 戦略的位置づけ

### 同梱カードの本質的役割

```
【従来の発想】
「商品の説明を伝える」

【今回の発想】
「買い手が"自分のネタ"として使える情報を渡す」
```

### 情報の非対称性を価値に転嫁する

```
生産者の状態：
- 「うちは普通だよ」「昔からこうしてるだけ」
- 自分の価値を「当たり前」と思っている
- 魚の目に水が見えない

商社だから見える景色：
- 「他の産地はそこまでやってない」
- 「この工程、省略してるところ多い」
- 複数生産者を比較できるから「差分」が見える

キュレーションの仕事：
- 発見：生産者との会話から「隠れた価値」を発見
- 翻訳：消費者に伝わる言葉に変換
- 編集：ブランドトーンで統一して届ける
```

### 食べチョク/ポケマルとの決定的差異

| 要素 | 食べチョク型 | EEZO型 |
|------|-------------|---------|
| 情報の出し手 | 生産者本人 | 商社（キュレーター） |
| トーン | 素朴・多様 | 統一・編集済 |
| 価値の発見 | 消費者に委ねる | 商社が提示する |
| 差別化軸 | 生産者の「声」 | 商社の「目利き」 |

## 2. 語り手の設計：EEZOの人格化

### 結論

**同梱カードの語り手 = EEZO自身**

新しいキャラクター名を作らず、ブランドそのものが語る。

### EEZOの由来

```
EEZO = 蝦夷（えぞ）+ ええぞ（関西弁）

北海道 × 大阪 = 北前船のルートそのもの
```

### EEZOの人格設定

```
【基本姿勢】
- 「売りたい」ではなく「届けたい」
- 生産者の言葉を翻訳する通訳者
- 押し付けない、でも確信がある

【語り口】
- 一人称は使わない（「私たち」も避ける）
- 主語をぼかすことで、静かな存在感
- 「〜なんです」「〜なんですよね」くらいの柔らかさ

【立ち位置】
- 生産者と買い手の「間」にいる
- どちらにも寄りすぎない中立
- でも選んでいるという責任は持つ
```

### デザインシステムとの整合

```
【カラー】
- Navy (#1a2a3a) + Gold (#c9a962) + Cream (#f8f5ef)
- 深みと落ち着き、静かな高級感

【タイポグラフィ】
- 見出し: Noto Serif JP（明朝）
- 本文: Noto Sans JP（ゴシック）
- letter-spacing広め → ゆったり、急がない

【トーン】
- 「静かな確信」「誠実な上質さ」「和のモダン」
```

## 5. 「話のネタ」の設計原則

### 良いネタの条件

```
- 短い（30秒で言える）
- 意外性がある（「へぇ」が出る）
- 検証可能（嘘っぽくない）
- 伝言ゲームに耐える（劣化しにくい）
```

### ネタの類型

| 類型 | 例 | 伝言しやすさ |
|------|-----|------------|
| **数字系** | 「40日干す（普通は14日）」 | ◎ |
| **比較系** | 「競走馬と同じ牧草」 | ◎ |
| **逆説系** | 「生産者は"普通"と言う」 | ◎ |
| **由来系** | 「漁師が船上で保存食にしたのが始まり」 | ○ |
| **職人系** | 「3代続く製法」 | ○ |
| **地理系** | 「火山灰土壌だから甘くなる」 | ○ |

### ネタの価値

```
【toC】
- 食卓で「これ知ってる？」と言える
- ギフトで贈るとき「実はこれね…」と添えられる
- SNSで「へぇ」と言われる投稿ができる

【toB】
- 料理人がお客さんに説明できる
- 「なぜこの食材を選んだか」のストーリーになる
- メニューの説明文に使える
```

## 6. 具体例

### 鮭とばの場合

```
【ネタの核】
「40日干す（普通は14日）」

【表紙キャッチ】
「40日、待つ。」

【30秒トーク】
「この鮭とば、40日かけて干してるんだって。
 普通は14日らしいんだけど、ここは昔から40日。
 生産者に聞いたら『昔からこうしてるだけ』って。
 その"昔から"が、この味なんだって。」
```

### あか牛の場合

```
【ネタの核】
「競走馬と同じ牧草を食べて育った牛」

【表紙キャッチ】
「馬と同じ草を、食む。」

【30秒トーク】
「この牛、競走馬と同じ牧草食べてるんだって。
 新冠って競馬の産地で、馬用の牧草が余るから
 牛にも食べさせてるらしい。だから脂が軽いんだって。」
```

## 7. 将来構想との接続

```

【Step 3】Norte実装（Shopify成熟後）

【Step 4】フィードバックループ
- 購買データから「刺さるストーリー」を特定
- 次の同梱カードに反映
```
