## 1. 要望の分解 — 先方が探しているのは「運送会社」ではない

英文の "Japanese shipper" は運送業者ではなく、**B/L上のShipper＝輸出者（荷主）**を指していると読むのが自然。要望は3つに分解できる。

| # | 要望 | 実体 |
|---|---|---|
| ① | consolidate 4-5 breweries' products | 複数蔵の貨物を1本にまとめる（物流の混載）／場合により商流の一本化 |
| ② | clear export customs | 輸出申告。**申告には輸出者の名義が要る** |
| ③ | affordable | 国際輸送費を下げる |

ここで効いてくる原則がひとつある。

> **輸出者になれるのは貨物を輸出する者（＝原則その所有者・売主）であって、フォワーダーや通関業者ではない。**
> 乙仲は「申告を代行」できるが「輸出者になる」ことはできない。名義貸しは不可。

したがって **②は①（商流）に従属する**。「商流はまとめないが通関だけFWが一本化する」という案は、厳密には成立しない。FWにできるのは各蔵を輸出者とする複数申告の取りまとめまでで、それは先方の要望を満たさない。

**この構造こそが、先方が詰まっている理由の本体である可能性が高い。** 先方は「日本側で輸出者になってくれる会社」を探しており、それが見つかっていない。

## 2. ボトルネック仮説（先方ヒアリング前の当社仮説）

杉田さんの聞き取り結果と突き合わせる用。確度順。

| # | 仮説 | 根拠・示唆 |
|---|---|---|
| B1 | **輸出者を引き受ける日本企業がいない** | 水産の輸入では、産地問屋や大手荷主が輸出者を務めてくれた。酒蔵は小規模で、輸出者になる体制（英文書類・輸出免税手続き・与信）を持たない蔵が多い。§1の構造そのもの |
| B2 | **酒類の免許の壁** | 日本で他社の酒を仕入れて海外へ売るには**輸出酒類卸売業免許**が要る。水産のパートナーはこれを持っていない。「水産の輸入パートナーがいるのに酒で使えない」という一見不思議な状況が、これで説明できる。**最有力** |
| B3 | **温度帯と数量のミスマッチ** | 先方が当たった「隔週定温リーファー便」は日本酒専用の定温サービスと推測される。要冷蔵前提で単価が高い。かつ4〜5蔵の数量ではリーファーFCLが埋まらず、LCL単価が跳ねている可能性 |
| B4 | **蔵ごとの既存代理店・独占条項** | 一部の蔵はSGに既存代理店を持ち、そもそも出せない。当社側でも `snj_sake` の「既存NG国」とダルマ（アイルランド）型の地域独占条項の確認が要る |
| B5 | **SG側の酒類ライセンス・倉庫が水産と別建て** | グループ内の輸入代理店をわざわざ使っている事実がこれを示唆。日本側だけの問題ではない |
| B6 | **決済・与信** | 4〜5蔵へ個別に前払い・個別送金は先方にとって負担。一本化の動機になる |

## 3. 打ち手 — 商流／物流／通関の3層に分けて考える

3層を分けると選択肢が整理できる。**②通関は①商流に従属し、③物流だけが独立に動かせる。**

### 案A: 当社が商流を一本化する（当社が買って売る）

```
各蔵 ──仕入──> 新日本海商事 ──販売（1インボイス）──> theSFC
                    └ 輸出者＝当社。FWに集荷・混載・通関・船積を一括手配
```

- **満たす要望**: ①②③すべて。先方の要望に正面から答える唯一の案
- **必要なもの**: 輸出酒類卸売業免許／他社蔵の仕入口座開設／与信・在庫リスクの引受け／酒税・消費税の輸出免税手続き
- **収益**: 商品マージン（粗利15%下限ルール適用可）＋ 物流手配のマージン
- **リスク**: 他社蔵分の品質・納期・クレームまで当社が負う

### 案B: 当社は商流に入らず取りまとめだけ（コーディネート料）

```
各蔵 ──販売（各蔵が輸出者）──> theSFC
新日本海商事 = 集荷調整・書類取りまとめ・FW手配の代行（手数料）
```

- **満たす要望**: ③のみ、①②は部分的
- **利点**: 免許不要（自ら売らないため）。リスクが小さい
- **弱点**: 蔵が輸出者になれない／なりたがらないことが問題の本体なので、**そこが解けない限り成立しない**。輸出慣れした蔵（大和川など海外実績あり）に限れば部分的に成立

### 案C: ハイブリッド（現実解になりやすい）

当社取扱蔵（会津4蔵：大和川・栄川・名倉山・ほまれ 等）は案A、それ以外の蔵は案B。

- **弱点**: インボイスが2本以上に割れる＝輸出申告も割れる。先方の「一本化」要望は半分しか満たさない
- ただし**物流（コンテナ）は1本にまとめられる**ので、③のコスト効果は取れる。ここが重要

### 案D: 既存の酒類輸出商社に丸ごと乗せる

- **利点**: 最速。免許・混載・SG実績を持つ事業者は複数存在する
- **弱点**: 当社の取り分が薄い。顧客を中抜きされるリスク。既存客を他社に渡す判断になる

### 案E: 先方が日本にバイイングオフィスを置く

名義貸しが不可である以上、実質は案Aか案Dに帰着する。先方から「名義だけ貸してほしい」と言われる可能性があるので、**その依頼は受けられない**と事前に整理しておく。

## 4. コストを下げる打ち手（③への回答）

「高すぎる」への対抗は、商流の話とは独立に打てる。

| # | 打ち手 | 効き方・留意点 |
|---|---|---|
| L1 | **火入れ酒に限定してドライコンテナ＋断熱ライナー** | 最大のコスト削減。生酒・生詰を外す判断とセット。SGは高温多湿で現地保管も含めた品質方針の議論が要る |
| L2 | **数量を集めて20ftリーファーFCLを埋める** | LCLの定温混載は単価が高い。「4〜5蔵をまとめる」話は、そもそもFCLを埋めるための集約とも読める。**必要ケース数の逆算が要る** |
| L3 | **頻度を落として1回のロットを大きくする** | 隔週便に乗る必要が本当にあるか。四半期1回で足りるなら単価は大きく下がる |
| L4 | **相見積を最低3社**（大手系・酒類専門系・地場乙仲） | 「高い」の比較対象がないまま議論しない |
| L5 | **運賃を着払い（Freight Collect）にして先方FWに払わせる** | 当社はFCA/FOBまで。先方が安いレートを持っているなら有効。ただし§5の通り、持っていない可能性が高い |
| L6 | **初回はサンプル少量で実務を1周させる** | 書類・英文ラベル・SG通関を小さく通してから本番の混載を組む |

## 5. 請求はどう流れるか — インコタームズで決まる

先方の質問（FW→当社なのかFW→theSFCなのか）への答えは「建て値次第」。

| 建て値 | 輸出者 | 海上運賃の請求先 | 日本国内費用（集荷・CFS・通関・THC） | 当社のリスク |
|---|---|---|---|---|
| EXW（現状の一部） | 実務上は先方（＝回せていない） | theSFC | theSFC | 最小。ただし先方が回せないので今回は不成立 |
| **FCA / FOB Japan** | 当社 | theSFC（着払い・先方指定FW） | 当社 → 商品代に転嫁 | 小 |
| **CFR / CIF Singapore** | 当社 | 当社 → 商品代に含めて請求 | 当社 | 運賃変動・為替 |
| DAP / DDP | 当社 | 当社 | 当社 | 大。輸入通関・SG酒税は先方の免許が要るため**酒類では非推奨** |

### 現時点の方針案

**CFR Singapore へ寄せる**方向を推す。理由は単純で、**先方は「安い選択肢がない」と言っている＝先方側に良いレートがない**。当社がFWを相見積で叩いて運賃込みで提示したほうが、先方にとっての「affordable」を作れる。運賃を当社の収益に乗せる余地も生まれる。

ただし初回は **FOB＋着払いで先方FWを使わせ、実勢運賃を実測してから CFR へ移行**するのが安全。当社に運賃の相場観がない状態でCFRを建てると、変動を丸かぶりする。

（既存の価格ルール：粗利率15%下限、うちFOBコスト＝工場出し→FOB約5%。CFR化する場合はここに海上運賃・保険を積む形になる。出典: `knowledge/10_rules/20260113_DOC_価格設定ルール_事例集.md`）

## 6. SG市場の構造 — 「安く大量に」が効きにくい

シンガポールの酒類関税・物品税は**従量制（アルコール量あたり）**である。

- 課税額 ＝ 数量(L) × (関税＋物品税) × アルコール度数
- 物品税率は品目により異なる（清酒の分類・適用レートは**要確認**）
- 加えてGST（税率は2026年時点の値を**要確認**）

**含意**: 従量税なので、単価の安い酒ほど税の相対負担が重くなる。「安い物流で安い酒を大量に」という設計はSG市場では効きにくく、**単価の取れる酒を適量**のほうが成立しやすい。

先方が "affordable" を強調していることは、低価格帯を狙っているサインかもしれない。もしそうなら、物流費以前に**商品設計が市場構造と噛み合っていない**可能性がある。杉田さんのヒアリングで狙う価格帯（想定小売）を必ず取る。

## 10. 戦略的な位置づけ（蜂巣さんに上げるべき論点）

これは1案件の物流手配の話にとどまらない。**当社が「EXW／FOBで売るだけの商社」から「複数蔵の混載輸出を組成する事業者」に上がれるかどうか**の分岐である。「現代の北前船」の物流面での実装にあたる。

一方で、他社蔵の分まで抱えると**マージンの薄い代行業**になりかねない。判断が要る論点は3つ。

1. **他社蔵の分まで商流に入れるか**（案A／案C の選択）
2. **運賃を当社が握るか**（CFR化するか、FOB＋着払いに留めるか）
3. **免許取得に投資するか**（未取得の場合。約2か月のリードタイム）

いずれも粗利15%ルールの適用可否と直結する。C1・C2の確認結果が出た時点で、案A／C／Dの比較表を作って判断を仰ぐ。
