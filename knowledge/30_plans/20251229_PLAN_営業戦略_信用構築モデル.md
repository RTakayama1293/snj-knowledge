# 20251229_PLAN_営業戦略_信用構築モデル

## エグゼクティブサマリー

**核心命題**: 新日本海商事が売っているのは「北海道食材」ではなく「信用」である。

食材業界において、リプレイスには「理由」が必要。強烈なドアオープナーで扉を開け、そこで築いた信頼関係で課題を聞き、解決策を提案する。これが国内外共通の営業モデルである。

---

## 背景：なぜ「食材」では勝てないのか

### 競争環境の現実

フェリー基盤を除いた場合、「北海道食材商社」としての明確な強みがない。

- 大手商社系：資金力、物流網、信用で圧倒
- 産直EC：生産者直結、ストーリー、UI/UXで差別化
- 地元専門商社：長年の仕入先関係、地元信用
- カテゴリ特化業者：深い専門知識、固定客

### 料理長インタビューからの発見

> 「今の関係を切りたくないってもあるんですよね。500円しか変わらないなら多分買う人いないじゃないですか。よっぽど付加価値がないと、そんなにコロコロ変えないですよね」
> — 泊谷料理長

> 「困ってることに届いてない」
> — 菅原総料理長・金木料理長

**結論**: 「うちの食材の方が良い」では勝負にならない。相手が「困っていること」を解決しない限り、リプレイスは起きない。

## 戦略フレームワーク：信用構築モデル

### 基本構造

```
【従来の発想】（失敗パターン）
良い食材を持っていく → 「間に合ってます」 → 終了

【信用構築モデル】（成功パターン）
ドアオープナーで興味を引く → 話を聞いてもらう → 課題を発見する → 解決策を提案する → 信頼を得る → 本当の商売が始まる
```

### 6ステップ・プロセス

| Step | 内容 | 目的 |
|------|------|------|
| 1. ドアを開ける | 「他にない」武器で興味を引く | 話を聞いてもらう権利を得る |
| 2. 話を聞いてもらう | 相手の状況を理解する | 信頼関係の土台を作る |
| 3. 課題を発見する | 「何に困っているか」を聞く | 解決すべき問題を特定する |
| 4. 解決策を提案する | 「うちならこうできます」 | 価値を具体的に示す |
| 5. 信頼を得る | 約束を守る。期待を超える | 継続取引の基盤を築く |
| 6. 本商売の開始 | クロスセル、紹介獲得 | 収益化・拡大 |

## 二本柱戦略：国内と海外の独立運用

### 戦略の全体像

```
【国内戦略】
・ドアオープナー：エゾシカ（輸出不可→国内専用武器）
・ターゲット：高級業態（ミシュラン191店、高級ホテル）
・担当：杉田さん（国内）+ 門永さん（仕入れ）

【海外戦略】
・ドアオープナー：日本酒・和牛（小ロット対応）
・ターゲット：大手が相手にしない中小バイヤー
・担当：杉田さん（英語対応）+ 永井さん（スーパーバイズ）
```

**重要**: 国内と海外は相乗効果ではなく、独立した2つの柱として育てる。エゾシカは輸出できないため、商材自体が分かれる。

## 国内戦略：エゾシカを入口に

### なぜエゾシカが「ドアオープナー」になるか

| 要素 | 説明 |
|------|------|
| 希少性 | 安定供給できる業者が少ない |
| 話題性 | メニューの差別化になる |
| ストーリー | 新冠の競走馬牧草、SDGs、害獣問題 |
| 独占性 | あぷかの森出資で供給を押さえる |

### 営業シナリオ

```
【Step 1】
「エゾシカを安定供給できます」
　↓
【Step 2】
「え、どこから？」→ 話が始まる
　↓
【Step 3】
「他に何かお困りのことは？」
・「8月の価格高騰が困る」
・「土日に届かない」
・「珍しい食材でメニュー差別化したい」
　↓
【Step 4】
課題に対して解決策を提案
・「DENBAで通年価格安定」
・「フェリー物流で週末対応検討」
・「ヒグマ、蝦夷鮑もご提案可能」
　↓
【Step 5-6】
約束を守る → 信頼獲得 → クロスセル
```

### 川上確保の必要性

「仲介するだけ」では価値が出にくい時代。あぷかの森への出資（加工場増築）により、供給能力を独占し「うちの鹿」というポジションを確立する。

```
単なる仕入れ先 → 誰でも買える
　↓
出資・加工場確保 → 供給能力の独占
　↓
「うちの鹿」というポジション → 他社が真似できない
```

## 海外戦略：杉田さんの英語力で中小バイヤー開拓

### なぜ「大手が相手にしない中小」か

**大手商社の行動原理**
- やる：大ロット、標準化商品、安定供給、規模の経済
- やらない：小ロット、多品種個別対応、手間がかかる割に金額小さい

**展示会で出会った客の共通点**
- SOLAIRE（フィリピン）：カジノホテルの一部門
- Roubo Station（台湾）：焼肉屋チェーン
- DOMECHAN（イタリア）：日本食EC

→ 大手が相手にしない規模だが、継続取引になれば美味しい

### 杉田さんの英語力が効く理由

| 競合 | 状況 |
|------|------|
| 小粒国内業者 | 英語できない、通訳頼み、フォロー弱い |
| 大手商社 | 英語できる人は山ほどいるが「この規模の客に時間使うな」 |
| **杉田さん** | 英語で直接対応、小規模案件でも全力、30歳体育会系で粘れる |

### 営業シナリオ

```
【Step 1】
「36銘柄の日本酒、1ケースから対応できます」
　↓
【Step 2】
「え、小ロットでいいの？」→ 話が始まる
　↓
【Step 3】
「他に何かお困りのことは？」
・「日本の業者はレスポンスが遅い」
・「何を選べばいいかわからない」
・「和牛も扱いたいが仕入れ先がない」
　↓
【Step 4】
課題に対して解決策を提案
・「杉田が直接対応、即日返信」
・「顧客層に合わせて銘柄提案」
・「和牛も小ロットで対応可能」
　↓
【Step 5-6】
約束を守る → 信頼獲得 → クロスセル
```

## 検証すべきKPI

### 国内（エゾシカ）

| 指標 | 検証内容 |
|------|----------|
| ドアオープン率 | エゾシカ提案で何%が話を聞いてくれるか |
| 課題発見率 | 話を聞いた先の何%で課題を特定できるか |
| クロスセル率 | エゾシカ納品先の何%に他商材を提案できるか |
| クロスセル成約率 | 提案した他商材の何%が成約するか |

### 海外（日本酒・和牛）

| 指標 | 検証内容 |
|------|----------|
| 継続取引率 | 初回取引先の何%が2回目を発注するか |
| 年間取引額 | 1社あたり年間いくらになるか（目標：100万円以上） |
| 紹介発生率 | 既存客から新規紹介が何件発生するか |

### 試金石：DOMECHAN（イタリア）

- 初回：36銘柄、31.5万円（11月出荷完了）
- 追加引合：ビール、追加日本酒銘柄
- 検証：年間取引額、なぜ新日本海商事を選んだか、同モデルの他国展開可能性

## リスクと対策

### 杉田さん依存リスク

| リスク | 対策 |
|--------|------|
| 1人でどこまでカバーできるか | 顧客数上限を見極め、優先順位付け |
| 杉田さんが抜けたら終わる | 営業プロセスの組織知化、ドキュメント化 |
| 国内外両方は負荷が高い | 田島さん着任後の分業体制構築 |

### 「大手がやらない」の裏の意味

「大手がやらない」=「儲からないからやらない」可能性

→ 1社あたり年間取引額、継続率を検証し、持続可能なビジネスになるか見極める

## 結論：新日本海商事が売っているもの

```
新日本海商事が売っているのは「北海道食材」ではない。

売っているのは：
・「困りごとを解決してくれる」という信頼
・「約束を守る」という信用
・「この人に任せれば大丈夫」という安心

エゾシカも日本酒も、その信頼を築くための「きっかけ」に過ぎない。
```
