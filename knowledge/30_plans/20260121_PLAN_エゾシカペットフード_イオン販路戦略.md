# エゾシカペットフード事業戦略 - イオン販路開拓構想

## 1行サマリ

**「あぷかの森でペットフード製造をメイン事業に→副産物の人間用加工品をEEZOで販売→イオンCFを切符にペテモ187店舗への卸売りを狙う」**

---

## 戦略構想の背景

### 従来の発想
- エゾシカ＝人間用食肉がメイン
- ペットフードは端材活用の副産物
- 需要先：ホロニック等の高級店（小ロット・不安定）

### 新しい発想（発想の逆転）
- **ペットフード製造がメイン事業**
- 人間用加工品（ハンバーグ、ソーセージ等）が高付加価値の副産物
- 需要先：OEM先・ペットフード市場（大口・安定）

## あぷかの森との協業構想

### 現状
- 所在地：恵庭市
- 処理能力：年800頭
- 蜂巣さん方針：「あぷかの森協業が最優先」（12月月次報告）
- 支援打診済み：土地建物の支援＝増設余地あり
- 田嶋さん（タッシー）：月1週程度入って手伝う計画

### この構造のメリット

1. **歩留まり問題の解決**
   - ロース・ヒレ等の高級部位は1頭あたり限定的
   - モモ・バラ・スネ・トリミング等の「使いにくい部位」が大量に余る
   - ペットフードなら全部位活用可能→採算性UP

2. **需要の安定性**
   - 人間用ジビエ市場：ニッチで需要に波がある
   - ペットフード市場：4,594億円・9年連続成長
   - OEM契約取れれば計画生産が可能

3. **EEZOブランドとの両立**
   - 人間用＝高級路線を維持
   - ペット用＝別カテゴリとして展開
   - 「飼い主とペットの北海道ご褒美セット」で新市場創出

## イオン販路開拓戦略

### イオンCFの位置づけ

イオンCF（まいクラウドファンディング）は単なる資金調達ではなく、**イオングループ販路への切符**。

| 項目 | 内容 |
|------|------|
| 運営 | イオンフィナンシャルサービス |
| リーチ | イオンカード会員3,615万人、メルマガ700万人 |
| ターゲティング | 購買履歴ベースでセグメント配信可能 |
| コンセプト | 地方創生、自然保護、持続可能なくらし |
| グループ連携 | CF実績→イオンバイヤーへの商品紹介ルートあり |

### CFの資金使途候補

- ジビエカー導入（移動解体車で鮮度・品質向上）
- 加工場の拡張・設備投資
- ペットフード製造ラインの整備
- ハンター育成・捕獲体制の強化

### CFストーリーの軸

- エゾシカは害獣駆除の副産物→命を無駄にしない
- 北海道の森林保全・農業被害軽減という社会課題解決
- 現代の北前船として地域資源を全国へ届ける

## ペテモ（PETEMO）への販路開拓

### ペテモ基本情報

| 項目 | 内容 |
|------|------|
| 運営 | イオンペット株式会社 |
| 店舗数 | ペット用品販売187店舗、トリミング156店舗、動物病院50院 |
| ブランド | 2021年12月「PETEMO」に統一 |
| コンセプト | 「ペットの命を守る」「Pet + Emotion」 |
| 特徴 | プレミアムフード中心、自社オリジナルストアブランドあり |

### ペテモを狙える理由

1. **イオンCFからの導線が明確**
   - 「CF実績→イオンバイヤーに仕入提案」のルートが存在
   - イオングループ内横展開で「イオンペット→ペテモ」は自然な流れ

2. **ペテモオリジナルストアブランドがある**
   - 自社PB商品を展開中
   - エゾシカ原料のOEM供給先として組める可能性

3. **ストーリーとの親和性**
   - ペテモコンセプト：「ペットの命を守る」
   - エゾシカ：「害獣の命を無駄にしない」
   - 両方とも「命」を軸にした価値観で合致

4. **鹿肉ペットフード市場の空白**
   - 現状ペテモで鹿肉系商品の大々的な展開は見当たらない
   - 「北海道産エゾシカ」で差別化できる枠がある

### 攻め筋のロードマップ

```
【Phase 1】イオンCFで実績を作る
  │
  │  資金調達＋「北海道エゾシカ×ペットフード」の需要検証
  ▼
【Phase 2】ペテモオリジナルへOEM供給を打診
  │
  │  「ペテモオリジナル 北海道エゾシカジャーキー」的な
  ▼
【Phase 3】187店舗への棚入れ
  │
  │  安定した大口需要＝あぷかの森の加工場フル稼働
  ▼
【Phase 4】EEZO連携強化
  │
  │  人間用＋ペット用セット販売で新市場創出
  ▼
【将来】エゾシカ事業の安定収益基盤確立
```

## 規制・注意点

### ペットフード安全法関連

| 項目 | 内容 |
|------|------|
| 届出 | 製造・輸入業者は届出必須 |
| 帳簿 | 製造・販売記録の保管義務 |
| 表示基準 | 原材料・賞味期限等の表示義務 |
| 成分規格 | 有害物質の基準値遵守 |

### ジビエ特有の規制（FAMIC）

- シカの肉骨粉製造→他社出荷は**原則禁止**
- ジャーキー等の完成品製造なら可能だが、**事前相談必須**
- 製造工程等の資料を準備してFAMICに相談

### あぷかの森での対応事項

- ペットフード製造業の届出
- 製造ライン・衛生管理体制の整備
- FAMICへの事前相談と認可取得

## EEZO連携：人間用×ペット用セット販売

### EEZOブランドとの整合性

| 懸念 | 対応策 |
|------|--------|
| ブランド希釈リスク | ペット用は別カテゴリとして明確に分離 |
| 高級感との両立 | 「北海道の匠」路線を人間用で維持しつつ、ペット用は「愛犬・愛猫への贈り物」文脈で訴求 |
| ターゲット重なり度 | 高所得シニア×ペットオーナーは親和性高い |

### 商品構成イメージ

**人間用（EEZO既存路線）**
- エゾシカハンバーグ
- エゾシカソーセージ
- エゾシカロース（高級部位）

**ペット用（新規）**
- エゾシカジャーキー（犬用・猫用）
- エゾシカミンチ（手作り食向け）
- エゾシカボーン（おもちゃ兼おやつ）

**セット商品（新市場）**
- 「飼い主とペットの北海道ご褒美セット」
- 人間用ハンバーグ＋ペット用ジャーキーの詰め合わせ
