## 1. 何が変わるか

### これまで（～2月）
既存のInstagram運用ガイドラインはBtoB（プロ料理人・ホテル仕入れ担当）向けに設計されていた。ハッシュタグ15-25個、商品規格重視、情報インフラ型。

### これから（3月～）
堀田さんが納品した「コミュニケーション設計」に基づき、**BtoCフォーカス**に切り替える。ターゲットは40代以上の「量より質」を重んじる個人消費者。トーンは「静かな選択」「北欧ミニマル」「余白70%」。4月のShopifyローンチと連動する。

### 変化の要点

| 項目 | 旧（BtoB寄り） | 新（BtoCフォーカス） |
|------|----------------|---------------------|
| ターゲット | プロ料理人・仕入れ担当 | 40代以上の個人消費者 |
| トーン | 情報量重視・規格訴求 | 静か・押し付けない・余白 |
| ハッシュタグ | 15-25個 | 5-7個に厳選 |
| ビジュアル | 商品アップ・規格表 | マット質感・低彩度・余白70% |
| CTA | 「サンプル請求はDMで」 | 静かにプロフィールリンクへ |
| コンテンツ構造 | 商品情報カード型 | カルーセル7枚の物語型 |
| 絵文字 | 適宜使用 | 最小限 |
| カラー | 特に統一なし | 深いボルドー・マットダーク・生成り |

## 3. 堀田マニュアルの構成

堀田さんから受領した設計書は2本。いずれもBtoC（エゾシカ肉 × 40代以上）に特化したブランドガイドライン。

### ① Instagramコミュニケーション設計

世界観の定義書。以下を規定している:

- **ブランドキャラクター（5タグ）**: 静か / 押し付けない / 北欧ミニマル / 完全マット / 感情控えめ
- **引き算の美学**: 「命」「環境問題」「ワイルドさ」「健康機能」は語らない（背景に留める）
- **ビジュアルルール**: 鹿を大きく扱わない、余白70%、低彩度・柔らかな光
- **カルーセル7枚の型**: 哲学的問い → 共感 → 価値提示 → 感情移入 → テーマ開示 → 体験描写 → 静かなCTA
- **カルーセル運用ルール**: 文字数は15-25文字/スライド。文節ごとにこまめな改行でリズムを作る。EEZO（エエゾン）の登場は1-2枚に限定
- **ハッシュタグ**: 5-7個厳選、絵文字最小限

### ② メルマガコミュニケーション設計

メルマガ（新規立ち上げ）の執筆ガイドライン。SNSと同じ世界観で、より深く語るメディア:

- **スタンス**: 商品を売る存在ではなく「橋渡し役（静かな案内人）」
- **文体**: 一文短く、意図的な改行で「間」を作る。「！」「？」は避ける。句点で静かに言い切る
- **件名の型**: 「父の日に、ひとつだけ。」のように短く静か
- **本文5段構造**: 導入 → 背景 → 味覚表現 → 比喩 → 結論
- **弱者化の禁止**: 父を「疲れた体に」等の老いや弱さを前提とした対象として描かない。静かな強さや重ねてきた時間への敬意を示し、人生の主人公として描く
- **NGワード**: 「とろける」「号泣」「絶対喜ばれる」「今しかない」等の煽り表現
- **クロージング**: 売り込みではなく語りでリンク誘導。追伸で余韻を残す

## 4. 誰が何をするか

### 役割分担

| 役割 | 担当 | 内容 |
|------|------|------|
| **ブランド監修** | 堀田さん（～3月末） | マニュアル納品済。契約期間中は質問対応可 |
| **企画・構成** | 高山 | 投稿テーマ設計、カルーセル構成案、メルマガ原稿 |
| **制作実行** | 黒田さん | 画像選定・加工、テキスト入力、投稿作業 |
| **承認** | 蜂巣さん | デザイン品質の最終チェック |

### 黒田さんの作業イメージ

v4の業務配分（月24h）においてSNSは端数時間（1-3h/月）の位置づけ。当面は以下の範囲:

- **投稿の実行作業**: 高山が作った構成案・テキストに基づき、画像を選んで投稿する
- **テンプレート作業**: 堀田マニュアルの型に沿って、決まったフォーマットで制作する
- **リスト生産が主業務であることは変わらない**

投稿頻度が上がるフェーズでは工数配分を見直す。
