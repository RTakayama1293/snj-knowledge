# EEZO UX設計構想：「静かな好奇心」の導線

**作成日**：2026年1月22日  
**ステータス**：構想段階（検討・ブラッシュアップ中）  
**関連資料**：食品EC無形価値創出事例集、同梱カード設計書、クイズ・大喜利心理研究

---

## 本構想の位置づけ

本ドキュメントは、EEZO ECサイトの購買体験設計における**初期構想**である。4月のShopifyローンチに向けて、堀田氏のブランド設計提案、門永氏の調達可能商材、認知心理学リサーチを統合し、「高級感」と「認知特性を活用したエンゲージメント設計」の両立を目指す。

確定版ではなく、今後の議論・検証を経て更新される前提で作成している。

---

## 1. 設計思想

### 1.1 避けたいこと

- 「今だけ！」「限定！」「売り切れ間近！」といった煽り表現
- 「ランキング1位」「〇〇で話題」といった外部権威への依存
- 「あなたは何タイプ？」的なポップなクイズ感
- 過剰な装飾、賑やかなデザイン
- 価格訴求を前面に出すコミュニケーション

### 1.2 実現したいこと

- 「…これは何だろう」という静かな好奇心の喚起
- 「なるほど、そういうことか」という知的満足
- 「この話、誰かにしたい」という自然な共有欲
- 押し付けない、でも確信がある語り口
- 北前船の歴史と現代をつなぐストーリー性

### 1.3 核心コンセプト

**「煽り」ではなく「問いかけ」で情報ギャップを作る**

認知心理学の知見（情報ギャップ理論、アハ体験、ドーパミン報酬系）を活用しつつ、高級ブランドにふさわしい静謐なトーンを維持する。

## 2. 全体フロー

```
【認知】広告・SNS
    │
    │ 「静かなフック」
    │ 例：「猟師が残す肉がある。」
    ↓
【興味】LP / トップページ
    │
    │ 「発見の入口」
    │ 例：診断 or キュレーションコンテンツ
    ↓
【検討】商品詳細ページ
    │
    │ 「深まる理解」
    │ 例：ストーリー → スペック → 楽しみ方
    ↓
【決定】カート・購入
    │
    │ 「静かな確信」
    │ 例：選んだ理由の言語化
    ↓
【期待】配送通知
    │
    │ 「待つ時間も体験」
    │ 例：産地からの旅路の可視化
    ↓
【体験】開封・同梱カード
    │
    │ 「アハ体験」
    │ 例：広告で見た謎が解ける
    ↓
【消費】食事
    │
    │ 「話のネタ」
    │ 例：30秒で語れるストーリー
    ↓
【共有】SNS・口コミ
    │
    │ 「自分の言葉で語る」
    │ 例：#北前船ごはん
    ↓
【循環】→ 新規顧客の認知へ
```

## 3. 各タッチポイントの設計

### 3.1 広告・SNS【認知】

#### 従来のEC広告との対比

| 従来のEC広告 | EEZOのアプローチ |
|-------------|-----------------|
| 「北海道直送！新鮮なウニが今だけ30%OFF！」 | 「猟師が残す肉がある。」 |
| 「ランキング1位！リピート率90%！」 | 「40日、干す理由。」 |
| 価格・割引を前面に | 問いかけだけ。説明しない |

#### 静かなフックの例

```
「猟師が残す肉がある。」
「40日、干す理由。」
「禁漁期に届く鮑。」
「馬と同じ草を、食む。」
```

説明しない。問いかけだけ。「え、どういうこと？」を誘発し、クリックして「答え」を知りたくなる構造。

#### デザイントーン

- Navy背景 + Cream文字
- 写真は商品単体、余白多め
- 文字は最小限、明朝体基調
- 価格・割引は載せない

#### 認知心理学的根拠

> **情報ギャップ理論（Loewenstein, 1994）**：好奇心は「知っていることと知りたいことのギャップ」の認識から生じる。クイズの問題文は意図的にこのギャップを作り出し、回答者に「認知的剥奪感」を与えることで情報獲得への強い動機を生む。

### 3.2 LP / トップページ【興味】

#### 2つの入口設計

```
┌─────────────────────────────────────────────┐
│                                             │
│   EEZO                                      │
│   北海道・小樽から届く、量より質を極めた贅沢    │
│                                             │
├─────────────────────────────────────────────┤
│                                             │
│   ┌───────────────┐  ┌───────────────┐      │
│   │               │  │               │      │
│   │  あなたに合う  │  │  今月の       │      │
│   │  北海道食材を  │  │  届けたいもの  │      │
│   │  見つける      │  │               │      │
│   │               │  │               │      │
│   │  → 診断する   │  │  → 見る      │      │
│   │               │  │               │      │
│   └───────────────┘  └───────────────┘      │
│                                             │
│   入口A：診断        入口B：キュレーション    │
│   （能動的発見）     （受動的発見）          │
│                                             │
└─────────────────────────────────────────────┘
```

#### 入口A：診断（能動的発見）

「クイズ」ではなく「マッチング」のトーン。ポップさを排し、静かな問いかけで構成。

**導入文**
```
北海道には、まだ届いていない食材がある。
あなたに届けたいものを、探してみませんか。
```

**質問設計（6問想定）**

| # | 質問 | 選択肢A | 選択肢B |
|---|------|---------|---------|
| 1 | 食卓で「へぇ」と言われることは | 嬉しい。話のネタになる | 特に気にしない |
| 2 | 食べたことのないものを試すのは | 新しい発見がありそう | 少し不安がある |
| 3 | 贈り物を選ぶとき、大切にしているのは | 相手が驚く意外性 | 安心して渡せる定番 |
| 4 | 「北海道」と聞いて浮かぶのは | 海の幸 | 山の幸 |
| 5 | 料理するとき | レシピ通りに作りたい | アレンジを加えたい |
| 6 | 今、どんな気分ですか | 何か新しいものに出会いたい | 確かなものを手に入れたい |

**診断結果タイプ（案）**

| タイプ | 特徴 | 推奨商材 |
|--------|------|----------|
| 冒険の食卓 | 新しい発見を求める | ヒグマ、エゾシカ |
| こだわりの食卓 | 品質と背景を重視 | 蝦夷鮑、塩水ウニ（将来） |
| 贈りものの食卓 | 話題性と安心感の両立 | ジビエセット、チーズ×日本酒 |
| 定番の食卓 | 確かなものを求める | 鮭とば、黒松内チーズ |

**結果画面のトーン**
```
あなたには、

「冒険の食卓」

をお届けしたい。

─────────────────────────────

食べたことのないものに手を伸ばす。
その好奇心が、食卓を豊かにする。

EEZOがお届けするのは、
北海道でも限られた人しか知らない、
本当に届けたいものだけ。
```

#### 入口B：キュレーション（受動的発見）

堀田氏提案の「今月のおすすめ4選」を活用。

```
【今月の届けたいもの】

「猟師が残す肉がある。」
   ↓
[ヒグマ肉の写真]
   ↓
「年50頭。その理由を知る →」
```

煽らない。説明しない。「知りたければどうぞ」というスタンス。

#### 認知心理学的根拠

> **クイズのエンゲージメント効果**：インタラクティブコンテンツは静的コンテンツより52.6%高いエンゲージメントを生み、コンバージョンは2倍に達する。クイズコンテンツの平均完了率は80%と極めて高い。クイズ利用者は非利用者より126〜469%高いCVRを示す。

### 3.3 商品詳細ページ【検討】

#### 構成：ストーリーファースト

従来のEC（商品名→価格→スペック→カート）ではなく、ストーリーを先に、スペックは後に配置。

```
┌─────────────────────────────────────────┐
│                                         │
│   [写真：ヒグマ肉のロース]              │
│                                         │
├─────────────────────────────────────────┤
│                                         │
│   猟師が、残す肉。                      │
│                                         │
│   ─────────────────────────────────     │
│                                         │
│   北海道のヒグマは、年間約1,200頭       │
│   駆除される。                          │
│   そのうち、食用に回るのは200頭。       │
│   さらに、この品質で届くのは50頭。      │
│                                         │
│   猟師は山に入る前に冷蔵車を準備する。  │
│   撃ってから冷却までの時間が、          │
│   肉質を決めるから。                    │
│                                         │
│   そして猟師自身は、バラ肉しか食べない。│
│   ロースは「売れるから」と言って残す。  │
│   つまり、これが一番美味しい。          │
│                                         │
│   ─────────────────────────────────     │
│                                         │
│   楽しみ方                              │
│   ・ロースは塩胡椒のみで焼く            │
│   ・バラは煮込みに（脂が甘い）          │
│                                         │
│   ─────────────────────────────────     │
│                                         │
│   商品情報                              │
│   産地：北海道函館近郊                  │
│   加工：ソヴァージュド函館              │
│   内容量：ロース 300g                   │
│   価格：¥3,600（税込）                  │
│   配送：冷凍                            │
│                                         │
│   [カートに入れる]                      │
│                                         │
└─────────────────────────────────────────┘
```

#### 設計ポイント

- ストーリーが先、スペックは後
- 「煽り」ではなく「事実」で希少性を伝える（数字の提示）
- 「楽しみ方」で購入後のイメージを持たせる
- 価格は最後に、自然に目に入る位置

#### 認知心理学的根拠

> **ストーリーの記憶効果**：ストーリーは事実より22倍記憶に残る。消費者の65%は明確な産地ストーリーのある商品により高い金額を支払う意思がある。

### 3.6 開封・同梱カード【体験】

**認知ハックの本丸**。広告で見た「猟師が残す肉がある。」の謎が、ここで解ける。

#### フォーマット

十字折りパンフレット（閉：A6、開：A4）

#### 4面構成

**①表紙（フック）**
```
猟師が、残す肉。

[ヒグマ肉の写真]

EEZO
```

**②開いて最初（「へぇ」）**
```
北海道のヒグマ：年間駆除 約1,200頭
食用に回るのは：約200頭（16%）
この品質で届くのは：50頭

猟師は、ロースを食べない。
「売れるから」と言って、残す。
```

**③全面展開左（深掘り）**
```
[生産者の写真]

「猟師は山に入る前に冷蔵車を準備する。
 撃ってから冷却までの時間が肉質を決める。
 うちと取引する猟師は、そこを妥協しない。」
 ── ソヴァージュド函館

EEZOが届けたいのは、
この工程を守れる猟師からしか出てこない、
本当に食べる価値のあるヒグマ肉。
                          ── EEZO
```

**④全面展開右（行動誘発）**
```
おすすめの楽しみ方
・ロースは塩胡椒のみで
・バラは煮込みに

─────────────────────────────

このネタ、誰かに話してみてください。

#北前船ごはん

[QRコード]

投稿いただいた方の中から
次回使える500円クーポンをお届けします。
```

#### 認知心理学的根拠

> **アハ体験の記憶強化効果**：デューク大学の研究（Becker et al., 2025）では、アハ体験が記憶をほぼ2倍に強化することが確認されている。洞察問題解決時に右前側頭葉が活性化し、解答の約0.3秒前にガンマ波のバーストが生じる。

### 3.7 SNS投稿【共有】

#### 投稿促進の設計

同梱カード④面の仕組みに加えて、**お題**を用意する。

**月次お題企画（案）**

| 月 | お題 |
|----|------|
| 1月 | 「2026年、最初の北前船ごはん」 |
| 2月 | 「誰かに贈った北前船ごはん」 |
| 3月 | 「春を先取り、北前船ごはん」 |
| 4月 | 「新生活の北前船ごはん」 |

お題があると投稿しやすい。制約が創造性を高めるという認知心理学の知見を活用。

#### 投稿の「型」を示す

同梱物で投稿例を示唆し、ハードルを下げる。

```
たとえばこんな投稿

───────────────────────
ヒグマ肉、初めて食べた。
猟師さんは自分で食べないらしい。
「売れるから残す」んだって。

つまりこれが一番美味しいってこと。

#北前船ごはん #EEZO
───────────────────────
```

30秒トークをそのまま投稿に使える設計。

#### 認知心理学的根拠

> **制約と創造性の関係**：Patricia Stokes（2006）は適切な制約が逆説的に創造的思考を高めることを示した。Acar, Tarakci, & van Knippenberg（2019）のメタ分析は、制約と創造性の関係が逆U字型であることを明らかにした。

> **UGCの効果**：UGCはEC購買者のCVRを5倍に高める。顧客写真でCVRは最大29%向上する。

## 8. 未解決の論点・今後の検討事項

### 8.1 診断実装の技術選定

- Typeform（外部ツール）vs Shopifyアプリ vs カスタム開発
- メールリード取得タイミング（結果表示前 or 後）
- 診断結果からカートへの導線設計

### 8.2 広告クリエイティブの検証

- 「静かなフック」が実際にCTRを取れるか
- A/Bテストの設計（従来型 vs 静かなフック）
- 広告プラットフォーム別の最適化

### 8.3 同梱カードの効果測定

- SNS投稿のトラッキング方法
- QRコード経由の計測設計
- レビュー内容の定性分析方法

### 8.4 商材拡張時の設計

- 新商材追加時のストーリー開発プロセス
- 門永氏へのヒアリングフレームワークの標準化
- カードテンプレートの汎用化

### 8.5 堀田氏提案との整合

- 塩水ウニ・タグ付きカニなど調達困難商材の扱い
- 商材の弱みを体験の強みに変換する具体策の深掘り
- 木箱・和紙包装など開封体験要素の優先順位
