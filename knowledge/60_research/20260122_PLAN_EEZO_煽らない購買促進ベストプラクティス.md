## 核心原則：なぜ「煽らない」が効くのか

| 心理学的根拠 | 実務への示唆 |
|-------------|-------------|
| **自律的動機 > 外発的動機**（Self-Determination Theory） | 「今すぐ！」より「あなたが選ぶ」が持続的購買を生む |
| **情報ギャップ = 報酬**（Loewenstein, 1994） | 謎を提示し、解消の快感を与える |
| **物語への没入は理性を迂回する**（Green & Brock, 2000） | ストーリーで「説得」ではなく「共感」を |
| **供給ベース希少性 > 需要ベース希少性** | 「残りわずか！」より「年間200kg限定生産」 |

**一言で言えば**：顧客の知性を尊重すると、逆説的に購買意欲が高まる。

---

## 1. 広告・SNS（認知段階）

### Do / Don't

| Don't | Do |
|-------|-----|
| 「北海道直送！今だけ30%OFF！」 | 「猟師が残す肉がある。」 |
| 「ランキング1位！リピート率90%！」 | 「40日、干す理由。」 |
| 「送料無料キャンペーン中！」 | 「禁漁期に届く鮑。」 |
| 価格・割引を前面に | 問いかけだけ。説明しない |

### ベストプラクティス

- **情報ギャップを作る**：答えを言わず、「え、どういうこと？」を誘発
- **ビジュアル**：商品単体、余白多め、文字は最小限
- **色彩**：Navy背景 + Cream文字、派手な色は避ける
- **価格・割引は載せない**：クリック先で価値を伝えてから

## 2. LP・トップページ（興味段階）

### Do / Don't

| Don't | Do |
|-------|-----|
| 「人気商品ランキング」 | 「あなたに届けたいものを探す」 |
| 「今週の特売」 | 「今月の、届けたいもの」（キュレーション） |
| 「お客様の声」を最上部に | 世界観を伝えるビジュアルを最上部に |
| ポップなクイズ感 | 静かなマッチング体験 |

### ベストプラクティス

- **2つの入口**を用意：診断（能動的発見）とキュレーション（受動的発見）
- **診断の導入文**：「北海道には、まだ届いていない食材がある。」
- **質問設計**：6問以内、二択、「正解がない」問い
- **結果画面**：「あなたにはこれ」ではなく「こんな出会いがありそうです」

## 3. 商品詳細ページ（検討段階）

### 情報アーキテクチャ

```
【ファーストビュー】
├─ 大型ヒーロー画像（余白を活かす）
├─ 商品名（志向的ポジショニング含む）
├─ 核心的価値提案（1行）
├─ 価格（明確だが支配的でなく）
└─ CTA「この食材を選ぶ」

【セカンドスクロール】
├─ ストーリー（生産者・産地・製法）
├─ 感覚的詳細（味、香り、食感）
└─ 楽しみ方（レシピ、ペアリング）

【下部】
├─ 展開可能な仕様詳細
├─ 専門家・メディア推奨（控えめに）
├─ レビュー（星より文章重視）
└─ 「一緒に楽しむ」提案
```

### ストーリーテリング構造

1. **フック**：好奇心を喚起する問いや意外な事実
2. **コンテクスト**：産地の風景、生産者の哲学
3. **転換点**：この商品が生まれた理由
4. **感覚的詳細**：五感に訴える描写
5. **投影**：「食卓に並べたとき…」

### 「話のネタ」の埋め込み方

| 種類 | 例 |
|------|-----|
| **数字** | 「マイナス30度で3ヶ月熟成」 |
| **比較** | 「東京の刺身が100なら、これは127」 |
| **意外性** | 「実は酪農危機から生まれた」 |
| **専門知識** | 「プロが教える"やってはいけない"調理法」 |
| **五感** | 「箱を開けた瞬間、潮の香りが…」 |

## 4. CTA・価格表示

### CTAの言語選択

| 煽り系（避ける） | 静謐系（推奨） |
|----------------|--------------|
| 今すぐ購入 | この食材を選ぶ |
| カートに入れる | お取り寄せリストに加える |
| 急いで！ | 詳しく見る |
| 限定販売中 | この食材の物語を読む |

### CTAデザイン

- **色**：黒またはダークネイビー（信頼・洗練）
- **形**：角丸は控えめ、派手なアニメーションなし
- **文字数**：3-4語が最適（9語以上は効果半減）

### 価格表示の哲学

- **価格を謝らない**：割引文化を持たない
- **理由を伝える**：「職人が一つ一つ手作業で」
- **コスト・パー・ユース**：「一杯あたり約80円」
- **比較しない比較**：他社ではなく素材・製法で

## 5. 希少性の「品のある」表現

### Do / Don't

| Don't（煽り） | Do（静謐） |
|--------------|----------|
| 「残り3点！急いで！」 | 「今季の収穫量：200kg」 |
| 「24時間限定セール」 | 「毎年11月、初霜の後にのみ収穫」 |
| 「10,000人が購入！」 | 「佐藤さんが手がけるのは年間50件のみ」 |
| 「売り切れ続出」 | 「次回入荷は来春を予定しています」 |

### 原則

- **供給ベース**（生産量・製法の制約）を伝える
- **需要ベース**（「人気！」「残りわずか」）は避ける
- **嘘をつかない**：実際の制約に基づく誠実な表現

## 6. 社会的証明

### Do / Don't

| Don't | Do |
|-------|-----|
| 「★★★★★ 4.8！」を目立たせる | 星より文章レビューを重視 |
| 「人気No.1」 | 「〇〇シェフが自店で使用」 |
| 「10万人が選んだ」 | 「Featured in」メディアロゴ |
| ポップアップで「〇〇さんが購入」 | 「3日で12点がお求め先を見つけました」 |

### 原則

- **命令的規範**（専門家・目利きの推奨）＞ 記述的規範（大衆の行動）
- レビューは「認証購入者」で信頼性担保、視覚的には控えめに
- 肯定的レビューと批判的レビューを並置（バランスが信頼を生む）

## 7. 配送コミュニケーション（期待段階）

### メールシーケンス

| タイミング | 件名例 | 内容 |
|-----------|-------|------|
| 注文直後 | 「北海道から心を込めて」 | 購入決定の正当化 |
| 出荷時 | 「〇〇さんの食材が旅立ちました」 | 物語の始まり |
| 配送中 | 「届いたらまず香りを」 | 期待の具体化 |
| 到着後3日 | 「お召し上がりいただけましたか？」 | レビュー誘導 |

### 原則

- **待ち時間を「期待」に変える**（Savoring理論）
- トラッキングページを自社サイトで提供
- 待機中にストーリー、レシピ、ペアリング提案を表示

## 8. 開封体験

### 要素

| 要素 | EEZO実装案 |
|------|-----------|
| **外箱** | 北海道の自然を想起させる素材感 |
| **内層** | 「開ける」体験を演出する構造 |
| **インサート** | 生産者メッセージ、レシピカード |
| **おまけ** | 小さなサンプル、産地の写真葉書 |

### 原則

- 開封を「儀式」にする
- 同梱カードで広告の「謎」を解消（アハ体験）
- SNSでシェアしたくなる要素を入れる

## 9. カート放棄メール

### Do / Don't

| Don't | Do |
|-------|-----|
| 「お忘れではありませんか？」 | 「お取り寄せリストを保存しました」 |
| 「今なら10%オフ！」 | 「ゆっくりご検討ください」 |
| 「在庫残りわずか！」 | 「生産者からのメッセージ」 |

### 推奨シーケンス

| タイミング | 内容 | 割引 |
|-----------|------|------|
| 1時間後 | 商品画像＋「保存しました」 | なし |
| 17時間後 | 商品のストーリー、社会的証明 | なし |
| 3日後 | 「迷っていれば、お気軽に」 | 送料無料程度（控えめ） |

## まとめ：7つの核心メカニズム

1. **情報ギャップで好奇心を喚起**する（答えを言わない）
2. **自律性を尊重**する（「選ばせる」ではなく「選んでもらう」）
3. **物語で理性を迂回**する（説得より共感）
4. **供給ベースの希少性**を伝える（需要ベースは避ける）
5. **専門家の推奨**で信頼を構築する（大衆の行動は避ける）
6. **待ち時間を期待に変える**（配送も体験の一部）
7. **話のネタを埋め込む**（シェアされる情報設計）

**「煽らない」ことは弱さではない。プレミアムブランドの最も強力な差別化要因である。**
