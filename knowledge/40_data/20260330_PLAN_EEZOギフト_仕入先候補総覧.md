# EEZOギフト 仕入先×商品イメージ 総覧

> 作成日: 2026-03-30
> ステータス: 仮説（70%精度ゾーン）

## 前提条件

- **合わせ技なし**: 各仕入先が単独でギフトセットを組む。EEZOは仕入れて販売するだけ
- **冷凍あり**: 冷凍配送ギフトも対象
- **SI定義（セリングアイデア15）**: ギフト toC 3帯
  - **15_1**: 季節のお礼（5千円帯 / 年4回 / 衝動買い的「ちょっとしたお礼」）
  - **15_2**: 年1回の記念日（1万円帯 / 奮発した感 / 物語性・パッケージで判断）
  - **15_3**: 人生の節目（2万円帯 / 結婚・還暦・定年等 / 本気度が伝わる価格帯）
- **ジャンル構成**: 肉・魚・菓子・おつまみ の4軸

## 魚ジャンル

### 1. 山下水産（寿都町）— 生たきほたて貝柱

**概要**: 創業110年。伝統の「生たき製法」によるほたて貝柱佃煮の専業。大丸札幌店にも出店。

| SI帯 | 商品 | 上代（税込）目安 |
|---|---|---|
| 15_1 | 10粒プラスチックケース | 3,172円 |
| 15_1〜15_2 | 18粒木箱 | 6,867円 |
| 15_2 | 24粒木箱 | 8,554円 |
| 15_3 | 230g（29〜39粒） | 12,800円 |

**ヤマトヤシキとの差分**: 催事では袋入り小袋（1,050円）のみ出品。木箱ギフトラインは完全に別商品。

**EEZOでの位置づけ**: 既製ギフトが粒数違いで完成済み。卸率交渉のみで即載せ可能。3帯すべてカバーできる唯一の魚仕入先。

**口説きポイント**: 物撮り写真が最も効く（EC写真が素朴で改善余地大。撮影データは先方のECでも転用可能と伝える）。

**口説く難易度**: 低（既製品を卸すだけ）

**概要**: ヨシムラ・フード・ホールディングスグループ。「RUMOY」ブランドでおつまみ・珍味の新概念を展開。

| SI帯 | 商品 | 上代（税込）目安 |
|---|---|---|
| 15_1 | RUMOY 選べる3種セット（ギフトBOX付） | 3,880円 |
| 15_1 | RUMOY 5種セット（ギフトBOX付） | 5,880円 |
| 15_1 | 本燻ワイルドサーモン170g / 鮭とば300g / にしん蕎麦 | 各1,900〜3,200円 |
| 15_1 | 5種の北海道海鮮セット（コンフィ・甘露煮・鮭節） | 要確認 |
| 15_2候補 | 早獲れいくら醤油漬 600g（冷凍） | 要確認（高単価） |

**ヤマトヤシキとの差分**: 催事ではジャーキー・サーモン・数の子の小袋バラ売りのみ。RUMOY BOXや鮭とば上位ライン、いくらは未出品。

**EEZOでの位置づけ**: RUMOYは既製ギフトBOXで15_1即戦力。いくら醤油漬が冷凍ギフトの高単価商品として15_2を狙える可能性。

**口説きポイント**: 物撮り＋インフルエンサー（グループのEC販路拡大戦略と合致。RUMOYのブランディングを一緒に広げるという文脈で対等感を出す）。

**口説く難易度**: 低〜中

### 3. 小樽水産加工業協同組合（＋ホリ商店・NSニッセイ）

**概要**: 小樽の水産加工業者の協同組合。小樽百貨UNGA↑とのコラボで詰合せギフト企画・出荷の実績あり。

| SI帯 | 商品 | 上代目安 |
|---|---|---|
| 15_1 | 小樽恵比寿箱 8種朝めしセット | 約5,000円 |
| 15_2 | 厳選10品セット（干物・マリネ・おこわ・刺身・甘露煮・唐揚げ等） | 約10,000円 |
| 15_2〜15_3 | 厳選14品セット（上記拡張版） | 要確認 |

**ヤマトヤシキとの差分**: 催事ではバラ売り単品のみ（にしん甘露煮、棒たら炊き、食べるスープ、生茶漬け等）。詰合せセットは未出品。

**EEZOでの位置づけ**: 「小樽」ブランド×北前船コンセプトの親和性が最高。UNGA↑との実績があるため、セットを組む能力・オペレーションは実証済み。1万円帯の本命。

**口説きポイント**: カタログが最も効く。「ヤマトヤシキ催事の実績データを基に、BtoB営業で御組合の商品を推し続ける。カタログ掲載のプロ写真もこちらで撮影する」。組合員全体への販路開拓になるため理事会が通りやすい。

**口説く難易度**: 中（理事会決裁が必要）

| SI帯 | 商品 | 上代（税込）目安 |
|---|---|---|
| 15_1 | オール三海幸セット | 3,500円 |
| 15_1 | おつまみセット（6種/計17袋） | 5,000円 |
| プチギフト | Ori-Oriお試しセット（おちちまめ等） | 850円 |
| プチギフト | まきまき昆布お試しセット | 1,500円 |

**ヤマトヤシキとの差分**: 催事では小袋バラ売り（おちちまめ30袋、おつまみイカ各20個等、発注数は多い＝売れ筋）。既製セット商品は未出品。

**EEZOでの位置づけ**: 15_1のカジュアルギフト・プチギフト帯が本領。「ちょっとしたお礼」「お酒好きの方へ」というSI15_1の購買動機にドンピシャ。Ori-Oriのパッケージはかわいく、若年層向けのプチギフトとしても機能する。上位帯（15_2以上）は商品構成上厳しい。

**口説きポイント**: 物撮り＋インフルエンサー（Ori-Oriのかわいいパッケージはインスタ映え。自社ECは簡素な構成でEC弱者。全国認知拡大のニーズ大）。

**口説く難易度**: 低〜中

## 菓子ジャンル

### 5. 梅屋（旭川市）— 大正3年創業の焼き菓子

**概要**: 大正3年（1914年）創業の老舗洋菓子店。「シュークリームの梅屋」として道内で知られる。

| SI帯 | 商品 | 上代目安 |
|---|---|---|
| 15_1 | 黒いチーズケーキ（冷凍） | 要確認（Amazon販売実績あり） |
| 15_1 | 焼き菓子アソート（しゅろす・あんバタマドレーヌ・バターカステラ・ミルクッキー・野菜クッキー4種） | 要確認 |

**ヤマトヤシキとの差分**: 催事ではしゅろす120本、あんバタマドレーヌ80個等の個包装バラ売り。ギフトセット形態は未出品。

**EEZOでの位置づけ**: 15_1の菓子帯。冷凍OKなら黒いチーズケーキがホールケーキギフトとして差別化可能。焼き菓子アソートは個包装で詰め合わせしやすいが、既製ギフトBOXの有無が未確認（ボトルネック）。

**口説きポイント**: 物撮り＋インフルエンサーのフルセット（EC弱者でBASEのみ。全国認知が課題。手札3枚がすべて刺さる）。

**口説く難易度**: 中（既製BOXの有無確認が必要。なければ梅屋側に作ってもらう交渉が追加発生）

**要確認事項**:
- 黒いチーズケーキの卸価格・最小ロット
- 焼き菓子の既製ギフトBOXの有無
- BOXがない場合、梅屋側で企画してもらえるか

### 6. ファームズ千代田（美瑛町）— びえい和牛【主軸】

**概要**: 美瑛町の一貫生産牧場。ふれあい牧場・ファームレストラン・キャンプ場を運営。種牛飼育から肥育まで自社完結。

| SI帯 | 商品 | 上代目安 |
|---|---|---|
| 15_1 | びえい牛おつまみセット＋男山純米酒コラボ | 約5,000円（過去実績あり） |
| 15_2 | びえい和牛ステーキ / すき焼きセット（冷凍） | 要確認 |
| 15_3 | 要確認 | — |

**EEZOでの位置づけ**: 一銘柄一牧場＝びえい和牛はファームズ千代田でしか買えない独占ブランド。男山の酒粕を飼料に使用するストーリー。EEZOの「語れるギフト」コンセプトとの相性は全社中トップ。EC販路が弱く全国認知拡大のニーズが大きい。

**口説きポイント**: 物撮り＋インフルエンサー＋カタログの3枚フルセットが刺さる（美瑛の絵面はSNS最強クラス。EC弱者でBtoB販路なし。手札の刺さり度は全社中トップ）。

**口説く難易度**: 中（小規模事業者。ただし手札3枚が全部効くため交渉材料は十分）

**要確認事項**:
- びえい和牛のギフト用カット・パッケージ対応可否
- 15_2（1万円帯）のステーキ/すき焼きセットの卸条件
- 酒コラボセットの再現可否（男山との関係性）
