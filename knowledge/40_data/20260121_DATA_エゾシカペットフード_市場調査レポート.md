# エゾシカペットフード市場調査レポート

## エグゼクティブサマリ

日本のペットフード市場は4,594億円規模で9年連続成長中。プレミアム・ナチュラル志向の高まりにより、国産ジビエ（特にエゾシカ）を使用したペットフードへの需要が急増している。エゾシカは高タンパク・低脂肪・低アレルゲンという特性から、アレルギー対応食やシニア犬向け市場で差別化が可能。

---

## 1. 日本ペットフード市場概況

### 1.1 市場規模

| 指標 | 数値 | 備考 |
|------|------|------|
| 市場規模（2023年） | 4,594億円 | 一般社団法人ペットフード協会 |
| 成長率 | 9年連続成長 | 2015年以降継続 |
| プレミアムセグメント | 965億円（2028年予測） | CAGR 8-10% |
| 犬用フード | 約2,800億円 | 市場の約60% |
| 猫用フード | 約1,700億円 | 市場の約37% |

### 1.2 成長ドライバー

1. **ペットの家族化**
   - 少子高齢化による「コンパニオンアニマル」需要
   - ペット1頭あたり支出額の増加

2. **プレミアム化・ナチュラル志向**
   - 原材料の品質・産地へのこだわり
   - 無添加・グレインフリー需要

3. **ペットの高齢化**
   - シニア犬・シニア猫向け療法食市場の拡大
   - 健康維持・疾病予防ニーズ

4. **アレルギー対応ニーズ**
   - 食物アレルギー持ちのペット増加
   - 新規タンパク源（鹿肉・馬肉等）への関心

## 2. ジビエペットフード市場

### 2.1 市場動向

| 指標 | 数値 |
|------|------|
| ジビエ利用率 | 30.8%（ペットフード原料として） |
| 成長率 | 前年比15-20%増（推計） |
| 主要原料 | 鹿肉、猪肉、熊肉 |

### 2.2 鹿肉ペットフードの訴求ポイント

| 特徴 | 詳細 | 競合優位性 |
|------|------|-----------|
| 高タンパク | 牛肉比約1.5倍 | 筋肉維持・成長期に最適 |
| 低脂肪 | 牛肉の約1/6 | ダイエット・シニア向け |
| 低アレルゲン | 新規タンパク源 | アレルギー対応食として差別化 |
| 鉄分豊富 | 牛肉の約2倍 | 貧血予防・活力維持 |
| 国産・天然 | トレーサビリティ | 安心安全訴求 |

### 2.3 エゾシカ特有の強み

- **北海道ブランド**：産地イメージの良さ
- **安定供給可能性**：年間約15万頭の捕獲実績（北海道）
- **品質管理**：処理施設の整備が進んでいる
- **SDGs文脈**：害獣駆除×命の有効活用ストーリー

## 3. 競合分析

### 3.1 主要プレイヤー

| 企業/ブランド | 特徴 | 価格帯 | 販売チャネル |
|--------------|------|--------|-------------|
| **ドッグスタンス** | 鹿肉専門、獣医師監修 | 3,500-5,000円/kg | D2C、専門店 |
| **ZEN** | 国産鹿肉、グレインフリー | 4,000-6,000円/kg | D2C、ペットショップ |
| **北のジビエ** | 北海道エゾシカ専門 | 2,000-4,000円/kg | D2C |
| **メゾン・ド・ジビエ** | 九州産鹿肉、リゾット形式 | 高価格帯 | D2C |
| **FUJIDOG** | 無添加こだわり | 中価格帯 | D2C |

### 3.2 競合の特徴と参入余地

**現状の市場構造**
- 小規模D2C事業者が中心
- 大手ペットフードメーカーの本格参入は限定的
- 量販店（ペットショップチェーン）での棚確保は少ない

**参入余地**
- 大手小売チェーンへの卸売りルートが空白
- OEM供給先としての需要あり
- 「北海道産エゾシカ」の本格的ブランド展開は未開拓

## 4. 消費者インサイト

### 4.1 鹿肉ペットフード購買層の特徴

| セグメント | 特徴 | 購買動機 |
|-----------|------|----------|
| アレルギー対応層 | 獣医師推奨で購入 | 他のタンパク源でアレルギー発症 |
| プレミアム志向層 | 高所得、情報感度高い | 品質・産地へのこだわり |
| シニア犬オーナー | 40-60代女性中心 | 健康維持、低脂肪ニーズ |
| 手作り食派 | 原材料から調理 | 安全性、カスタマイズ性 |

### 4.2 購買決定要因

1. **品質・安全性**（最重要）
   - 国産・産地明記
   - 無添加・人工保存料不使用
   - 製造工程の透明性

2. **効果実感**
   - アレルギー症状の改善
   - 毛艶・体調の変化
   - 食いつきの良さ

3. **価格**
   - プレミアム層は価格感度低い
   - 3,000-4,000円/kgが許容ライン

4. **ストーリー・共感**
   - SDGs（害獣問題解決）
   - 地域貢献
   - 作り手の顔が見える

## 5. 規制要件

### 5.1 ペットフード安全法

| 義務 | 内容 |
|------|------|
| 届出 | 製造業者・輸入業者は届出必須 |
| 帳簿備付け | 製造・販売記録の保管（3年間） |
| 表示基準 | 名称、原材料名、賞味期限、事業者名等 |
| 成分規格 | 有害物質（アフラトキシン等）の基準値 |

### 5.2 ジビエ特有の規制（FAMIC）

| 項目 | 内容 |
|------|------|
| 肉骨粉製造 | シカの肉骨粉→他社出荷は**原則禁止** |
| 完成品製造 | ジャーキー等は可能（事前相談必須） |
| 製造要件 | 製造工程資料を準備しFAMICに相談 |
| BSE対策 | 牛・豚・シカ等の骨肉粉状物は原則禁止 |

### 5.3 認可取得の流れ

```
1. FAMICへ事前相談（製造工程資料持参）
     ↓
2. 製造ライン・衛生管理体制の整備
     ↓
3. ペットフード製造業の届出
     ↓
4. 製造開始
```

## 7. 参入戦略オプション

### 7.1 製造形態の選択肢

| 形態 | メリット | デメリット | 初期投資 |
|------|----------|-----------|----------|
| **自社製造** | 品質管理、利益率 | 設備投資、認可取得 | 高 |
| **OEM委託** | 低リスク、早期参入 | 利益率、差別化困難 | 低 |
| **原料供給** | 最低リスク | 付加価値小 | 最低 |

### 7.2 販売チャネルの選択肢

| チャネル | メリット | デメリット |
|---------|----------|-----------|
| **D2C（自社EC）** | 利益率、顧客データ | 集客コスト |
| **ペットショップ卸** | 販売量、認知度 | 利益率、棚確保競争 |
| **動物病院ルート** | 信頼性、高単価 | 営業コスト |
| **ふるさと納税** | 低リスク検証 | 継続購入への転換 |

### 7.3 推奨参入ステップ

```
【Step 1】商品企画・認可取得
  │  ジャーキー等の低難易度商品から開始
  │  FAMICへの事前相談、届出
  ▼
【Step 2】テストマーケティング
  │  ふるさと納税、自社EC、展示会
  │  需要検証、価格感度確認
  ▼
【Step 3】販路拡大
  │  ペットショップ卸、動物病院ルート
  │  OEM供給の受注
  ▼
【Step 4】商品ライン拡充
  │  総合栄養食、療法食への展開
  │  獣医師監修商品の開発
```

## 8. リスクと対策

| リスク | 影響度 | 対策 |
|--------|--------|------|
| 原料供給不安定 | 高 | 複数処理場との契約、在庫管理 |
| 規制強化 | 中 | FAMIC動向モニタリング、早期対応 |
| 価格競争 | 中 | ブランド構築、ストーリー訴求 |
| 品質事故 | 高 | 衛生管理徹底、保険加入 |
| 競合参入 | 中 | 先行者優位の確立、差別化 |

## 9. 市場機会のまとめ

### 参入の好機である理由

1. **市場成長**：ペットフード市場4,594億円、9年連続成長
2. **ニッチ市場**：鹿肉ペットフードは小規模事業者中心、大手未参入
3. **需要増加**：アレルギー対応、プレミアム志向の高まり
4. **供給優位**：北海道でのエゾシカ調達ルート確保済み
5. **ストーリー性**：SDGs×地域課題解決の文脈で訴求可能

### 成功のKSF（重要成功要因）

1. **品質管理体制**の確立
2. **北海道産エゾシカ**ブランドの構築
3. **安定供給体制**の確保
4. **規制対応**の早期完了
5. **適切な販売チャネル**の選択
