# エゾシカ一頭P/L：部位別収支フレームワーク

**作成日**: 2026年2月9日  
**最終更新**: 2026年2月10日（v3.0 あぷか仕入モデルに再構築）  
**目的**: エゾシカ一頭（生体100kg）を起点に、捕獲→加工→販売の全プロセスにおけるコスト構造と収益構造を可視化する  
**背景**: 蜂巣さんの問題提起「ax+by+cz、x:y:z一定、aを吊り上げるのは限界があり、捌けないzは売上原価に跳ね返ってくる」に対する構造的回答

---

## 1. 問題の構造

エゾシカも牛も、部位の比率は不変でいじれない。人気部位だけ売って残りを安く叩き売ると収支が合わない。

数式化すると：

```
一頭あたりの収益 = aA + bB + cC + dD

A: 人気部位（ロース・モモ・フィレ）  → 単価高、量は固定
B: その他部位                        → 加工次第で単価が変わる
C: ペット用端材                      → 最も安い、量で捌く
D: 副産物（角・骨・トライプ・革）    → 原価ほぼゼロ、売上＝純利益

A:B:C:Dの比率は固定。動かせるのは単価（a, b, c, d）と出口の質。
```

---

## 2. 歩留まりフロー

```
生体 100kg（※オス120-150kg、メス70-90kgの混合平均）
  │
  ├→ 一次加工（内臓除去・放血・剥皮・枝肉化）【あぷかの森】
  │    枝肉 50kg（歩留50%）  ※日本ジビエ振興協会調査と一致
  │    内臓・血液等 50kg → 廃棄 or D区分へ
  │
  ├→ 二次加工（脱骨・整形・カット・製品化）【あぷかの森】
  │    A: 人気部位精肉   12kg  ※フィレ0.3kg＋ロース3kg＋モモ系8kg
  │    B: その他部位     18kg → 原料肉状態でSNJへ納品
  │    C: ペット用端材   10kg → ミンチ・乾燥等のPF原料化
  │    骨・トリミング等  10kg → D区分へ
  │
  └→ D: 副産物
       角 1対、革 1枚、骨、グリーントライプ（胃内容物）等

※捕獲〜二次加工（精肉化・原料化）まではあぷかの森が一貫して担う。
　SNJはあぷかから各区分を仕入れ、販売チャネルの最適化に専念する。
```

**歩留まりの根拠**：生体→枝肉50%は業界標準値。牛60-65%、豚約70%に対し鹿は皮下脂肪が少なく頭部・角比率が大きいため低い。精肉合計30kg（生体の30%）は日本ジビエ振興協会の「精肉歩留まり約30%」と一致。A区分12kgは大型個体で最大14kg、小型メスで8kg程度の中央値。

## 3. コスト構造（あぷかの森からの仕入モデル）

あぷかの森が捕獲→一次加工→二次加工（精肉化）を担い、各区分をSNJへ販売する。仕入価格にはあぷかの原価＋利益が含まれる。協業関係のため市場仕入より1〜2割安い設定。

| 仕入区分 | 仕入単価 | 数量 | 金額 | 備考 |
|---|---|---|---|---|
| **A: 精肉（ロース・モモ・フィレ）** | 2,500円/kg | 12kg | **30,000** | 市場BtoB卸3,500円/kgの約71%。あぷか協業価格 |
| **B: 原料肉（肩・ウデ・バラ等）** | 1,200円/kg | 18kg | **21,600** | 精肉状態で仕入。加工品化は別途 |
| **C: PF用端材** | 600円/kg | 10kg | **6,000** | ミンチ・乾燥原料向け |
| **D: 副産物一式** | — | 1頭分 | **4,000** | 角・骨・トライプ・革。塩蔵・洗浄済み |
| **小計：あぷか仕入** | | | **61,600** | |
| B: 加工外注費 | 500円/kg | 18kg | **9,000** | ハンバーグ・カレー等の製品化。受託加工賃300〜1,000円/kgの中央値 |
| **仕入原価合計** | | | **70,600** | |

**市場仕入との比較**：枝肉を市場から仕入れた場合の原価は約82,400円（v2試算）。あぷか協業で約14%安い。あぷか側も安定した大口出荷先を確保できるメリットがあり、双方にとって合理的な水準。

※仕入単価は市場調査に基づく推計値。あぷかの森（湯峯さん）との交渉で精緻化する。

## 6. 比較：仕入モデル3パターン

| | ①あぷか協業 | ②枝肉市場仕入 | ③自社一貫（参考） |
|---|---|---|---|
| 仕入原価/頭 | 70,600円 | 82,400円 | 32,900円 |
| 売上/頭 | 109,000円 | 109,000円 | 109,000円 |
| 売上総利益 | 38,400円 | 26,600円 | 76,100円 |
| 売上総利益率 | 35.2% | 24.4% | 69.8% |
| 前提条件 | あぷか協業の維持 | 既存の精肉業者から仕入可 | 自社加工場＋捕獲体制が必須 |

**①を基本シナリオとする理由**：SNJは9名体制の商社であり、捕獲・解体・加工の自社運営（③）は現実的でない。あぷかとの協業（①）は市場仕入（②）に対し一頭あたり約11,800円の粗利優位があり、かつ副産物・端材まで含めた一頭丸ごとの仕入が可能。

## 7. 感度分析

### 一頭あたり粗利への影響

| 変数 | ベース | 変更後 | 粗利変動 |
|---|---|---|---|
| A仕入単価 | 2,500円/kg | 2,800円/kg（あぷか値上げ） | **▲3,600** |
| A販売単価 | 3,500円/kg | 4,000円/kg（高級路線強化） | **+6,000** |
| B販売単価 | 2,500円/kg | 3,000円/kg（高付加価値化） | **+9,000** |
| C販売単価 | 1,000円/kg | 1,500円/kg（PB供給） | **+5,000** |
| D売上 | 12,000円 | 0円（副産物未活用） | **▲12,000** |
| D仕入 | 4,000円 | 0円（副産物仕入なし） | +4,000（但し売上▲12,000と相殺で**▲8,000**） |

### 最も効くレバー

1. **D（副産物）の有無**：仕入4,000円に対し売上12,000円。差し引き8,000円の純貢献。これがゼロになると粗利30,400円（27.9%）に低下し商社として厳しい
2. **B（加工品）の販売単価**：500円/kgの改善で9,000円/頭。18kgと最大ボリュームのため影響が大きい
3. **A（人気部位）の仕入・販売スプレッド**：仕入2,500→販売3,500で1,000円/kgのスプレッド。スプレッド維持が収益の安定性に直結
4. **C（ペット用）の出口の質**：原料卸→PB供給で5,000円/頭の改善

## 9. 構造的結論

蜂巣さんの「ax+by+cz、比率固定でどうするか」への回答：

**単一チャネルでは成立しない。一頭の中で複数チャネルを組み合わせ、各区分の出口を最適化する必要がある。**

具体的には：

- **Aで稼ぐ**：人気部位はレストランBtoBで確実に捌く。仕入2,500→販売3,500のスプレッド1,000円/kgを維持する
- **Bで利益を上乗せする**：原料肉1,200円/kgで仕入れ、加工品化して2,500円/kgで販売。加工外注費500円/kgを引いても800円/kgのスプレッドが残る。18kgと最大ボリュームなので加工品の商品力が事業の太さを決める
- **Cは量を安定的に流す**：仕入600→販売1,000のスプレッド400円/kg。単価は低いが叩き売りではなくOEM/PBで安定出口を作る
- **Dが事業成立の分水嶺**：仕入4,000円に対し販売12,000円。一頭あたり8,000円の純貢献。Dがなければ粗利率は27.9%に低下し、商社として成立が厳しくなる

**SNJの付加価値**：あぷかの森にない販売チャネル（ホテルBtoB・EEZO BtoC・ペットフードOEM・副産物販路）を持つことがSNJの存在意義。仕入はあぷかに依存するが、出口の多様化＝一頭丸ごとの価値最大化はSNJにしかできない。
