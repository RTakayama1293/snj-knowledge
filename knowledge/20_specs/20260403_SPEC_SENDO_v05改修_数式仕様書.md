## Part 1: 案件明細（tbl_明細）の改修

### 1-1. 新しい列構造

旧テーブル範囲: A2:AB202（28列）
新テーブル範囲: A2:AI202+（35列、M列7列を非表示化して実質同サイズ感）

#### 追加列（テーブルの右端に追加）

| 新列名 | 位置 | 入力方法 | 初期値 |
|--------|------|---------|--------|
| **版（Ver）** | AC列 | 手動 | 1 |
| **版ステータス** | AD列 | 手動 | 現行 |
| **変更理由** | AE列 | 手動（任意） | 空欄 |
| **仕入税区分** | AF列 | 数式＋手動上書き可 | 仕入先マスタから引当 |
| **仕入価格（税抜）** | AG列 | 数式 | 税区分に応じた計算 |
| **仕入価格（税込）** | AH列 | 数式 | 税区分に応じた計算 |
| **行種別** | AI列 | 手動 | 商品（デフォルト） |

※列の物理位置は追加順に右端へ。テーブルの列追加はExcel上でテーブル範囲を拡張するだけで可能。

### 1-2. 新列の数式

#### AC列: 版（Ver）
```
入力: 手動（数値）
初期値: 1
備考: 版上げ時に全行コピー→版番号+1
```

#### AD列: 版ステータス
```
入力: 手動（データ入力規則でリスト: 現行, 旧版）
初期値: 現行
備考: 入力ルール用シートにリスト追加
```

#### AE列: 変更理由
```
入力: 手動（自由記述 or データ入力規則でリスト）
候補値: 数量変更, 価格改定, 追加発注, 商品変更, 初版
```

#### AF列: 仕入税区分
```excel
=IF(tbl_明細[[#This Row],[仕入先]]="","",
  IFERROR(
    _xlfn.XLOOKUP(tbl_明細[[#This Row],[仕入先]],テーブル1[仕入先名],テーブル1[仕入先見積税区分],"外税",0,1),
    "外税"
  )
)
```
※手動で「内税」に上書き可能（数式が消えるが問題なし。その行はその取引で固定）

#### AG列: 仕入価格（税抜）
```excel
=IF(tbl_明細[[#This Row],[仕入価格]]="","",
  IF(tbl_明細[[#This Row],[仕入税区分]]="内税",
    ROUND(tbl_明細[[#This Row],[仕入価格]]/(1+tbl_明細[[#This Row],[税率]]),0),
    tbl_明細[[#This Row],[仕入価格]]
  )
)
```
※仕入税区分=内税のとき、仕入価格列に入っている値は税込とみなして税抜を逆算

#### AH列: 仕入価格（税込）
```excel
=IF(tbl_明細[[#This Row],[仕入価格]]="","",
  IF(tbl_明細[[#This Row],[仕入税区分]]="内税",
    tbl_明細[[#This Row],[仕入価格]],
    tbl_明細[[#This Row],[仕入価格]]*(1+tbl_明細[[#This Row],[税率]])
  )
)
```

#### AI列: 行種別
```
入力: データ入力規則でリスト（商品, 送料, 手数料, その他）
初期値: 商品
備考: 入力ルール用シートにリスト追加
```

### 1-3. 既存列の数式変更

#### 重要: 既存データの凍結手順（改修実施前に必ず実行）
1. 案件明細シートを全選択（Ctrl+A）
2. コピー（Ctrl+C）
3. 右クリック → 「値」で貼り付け（数式を値に変換）
4. **ただしヘッダー行（row 2）は数式を維持**
5. row 3～202が全て値になったことを確認

#### 凍結後に新数式を適用する列（row 203以降の新規入力行向け）

**F列（仕入先）— 現行数式を維持でOK**
```excel
（変更なし）
=IF(ISBLANK(tbl_明細[[#This Row],[仕入先（M)]]),
  _xlfn.XLOOKUP(tbl_明細[[#This Row],[商品ID]],商品マスタ[商品連番],商品マスタ[仕入先],"",0,1),
  tbl_明細[[#This Row],[仕入先（M)]])
```
※M列は物理的に残す（非表示）が、新規入力では使わない。
※マスタ外商品の場合: 商品ID欄を空欄にし、F列の数式が空文字を返すので直接上書き入力する。

**結論: 既存のF/G/H/I/L/N列の数式はそのまま維持し、新規入力時は「商品IDを空欄にして直接上書き」運用。**

これにより:
- M列の数式ロジック → 維持（壊さない）
- 新規入力時の運用 → 商品ID空欄 → 数式が空文字返す → 上書き入力
- 旧other行 → 凍結済みなのでそのまま動作

### 1-4. 集計列の変更

#### X列（単価×数（仕入））
**現行:**
```excel
=tbl_明細[[#This Row],[仕入価格]]*tbl_明細[[#This Row],[数量]]
  +tbl_明細[[#This Row],[仕入価格（M)]]*tbl_明細[[#This Row],[数量（M)]]
```

**新（row 203以降）:**
```excel
=tbl_明細[[#This Row],[仕入価格]]*tbl_明細[[#This Row],[数量]]
```
※M列加算を削除。統一入力方式では仕入価格と数量が本列に入るため。

#### Y列（単価×数（売値））
**新（row 203以降）:**
```excel
=tbl_明細[[#This Row],[販売価格（売値）]]*tbl_明細[[#This Row],[数量]]
```

#### AA列（（非表示）販売価格の和）
**新（row 203以降）:**
```excel
=tbl_明細[[#This Row],[販売価格（売値）]]
```

#### AB列（税込価格）
**現行:**
```excel
=tbl_明細[[#This Row],[販売価格（売値）]]*1.08
  +tbl_明細[[#This Row],[販売価格（M)]]*1.08
```

**新（row 203以降）:** 
```excel
=tbl_明細[[#This Row],[販売価格（売値）]]*(1+tbl_明細[[#This Row],[税率]])
```
※1.08ハードコードを修正。税率列を参照。

## Part 2: 証憑テンプレートの改修（税スイッチ統合＋FILTER刷新）

### 2-1. 税スイッチの仕組み（全テンプレート共通）

各証憑シートに「税表示」スイッチセルを追加。

| シート | スイッチセル | 制御方法 | 選択肢 |
|--------|-----------|---------|--------|
| 見積書 | 追加位置は既存レイアウトに合わせて調整 | 手動プルダウン | 外税 / 内税 |
| 請求書 | 同上 | 手動プルダウン | 外税 / 内税 |
| 請求書(前払) | 同上 | 手動プルダウン | 外税 / 内税 |
| 発注書 | 同上 | **仕入先マスタ自動連動** | 自動（上書き可） |
| 納品書 | なし | — | — |

#### 発注書の自動連動数式（スイッチセル）
```excel
=IFERROR(
  _xlfn.XLOOKUP($B$2, テーブル1[仕入先名], テーブル1[仕入先見積税区分], "外税", 0, 1),
  "外税"
)
```
※仕入先名セル（B2）変更で自動切替。手動で上書きも可。

### 2-2. FILTER数式の新パターン

#### 販売側テンプレート（見積書・請求書・請求書(前払)・納品書）

**現行パターン（M列分岐あり）:**
```excel
=FILTER(
  CHOOSE({1,2,3,4,5,6},
    tbl_明細[No],
    IF(LEFT(tbl_明細[商品ID],4)<>"PRD_", tbl_明細[商品名（M)], tbl_明細[商品名]),
    IF(LEFT(tbl_明細[商品ID],4)<>"PRD_", tbl_明細[数量（M)], tbl_明細[数量]),
    IF(LEFT(tbl_明細[商品ID],4)<>"PRD_", tbl_明細[単位（M)], tbl_明細[単位]),
    IF(LEFT(tbl_明細[商品ID],4)<>"PRD_", tbl_明細[販売価格（M)], tbl_明細[販売価格（売値）]),
    IF(LEFT(tbl_明細[商品ID],4)<>"PRD_", tbl_明細[税率（M）], tbl_明細[税率])
  ),
  (tbl_明細[案件番号]=$C$1)*(tbl_明細[(非表示）販売価格の和] > 0),
  "該当なし"
)
```

**新パターン（外税モード）:**
```excel
=FILTER(
  CHOOSE({1,2,3,4,5,6},
    tbl_明細[No],
    tbl_明細[商品名],
    tbl_明細[数量],
    tbl_明細[単位],
    tbl_明細[販売価格（売値）],
    tbl_明細[税率]
  ),
  (tbl_明細[案件番号]=$C$1)
    *(tbl_明細[版ステータス]="現行")
    *(tbl_明細[(非表示）販売価格の和] > 0),
  "該当なし"
)
```

**新パターン（税スイッチ対応版 — 見積書・請求書・請求書(前払)）:**
```excel
=FILTER(
  CHOOSE({1,2,3,4,5,6},
    tbl_明細[No],
    tbl_明細[商品名],
    tbl_明細[数量],
    tbl_明細[単位],
    IF(スイッチセル="内税",
      tbl_明細[販売価格（売値）]*(1+tbl_明細[税率]),
      tbl_明細[販売価格（売値）]),
    IF(スイッチセル="内税", "", tbl_明細[税率])
  ),
  (tbl_明細[案件番号]=$C$1)
    *(tbl_明細[版ステータス]="現行")
    *(tbl_明細[(非表示）販売価格の和] > 0),
  "該当なし"
)
```
※スイッチセル=実際のセル参照に置換（例: $H$1）
※内税モード時: 単価列に税込単価を表示、税率列は非表示（空文字）
※納品書はスイッチなし → 常に外税パターンを使用

#### フッター税計算セクションの切替

**外税モード（従来）:**
```
8%対象 小計: =SUMIF(税率列, 0.08, 金額列)  消費税: =ROUND(小計*0.08, 0)
10%対象 小計: =SUMIF(税率列, 0.1, 金額列)  消費税: =ROUND(小計*0.1, 0)
税込合計: =SUM(全小計+全消費税)
```

**内税モード:**
```
合計（税込）: =SUM(金額列)
※税率別小計・消費税行は非表示 or 空文字
```

実装方法:
```excel
=IF(スイッチセル="内税", "", SUMIF($F$17:$F$36, E40, $G$17:$G$36))
```

### 2-3. 発注書テンプレート（仕入側）

**新パターン（税スイッチ自動連動）:**
```excel
=FILTER(
  CHOOSE({1,2,3,4,5,6},
    tbl_明細[（非表示）仕入No.],
    tbl_明細[商品名],
    tbl_明細[数量],
    tbl_明細[単位],
    IF(スイッチセル="内税",
      tbl_明細[仕入価格（税込）],
      tbl_明細[仕入価格]),
    IF(スイッチセル="内税", "", tbl_明細[税率])
  ),
  (tbl_明細[案件番号]=$B$1)
    *(tbl_明細[仕入先]=$B$2)
    *(tbl_明細[版ステータス]="現行"),
  "該当なし"
)
```

発注書のスイッチは仕入先マスタ自動連動なので、仕入先名を入力するだけで内税/外税が自動判定される。

## Part 3: 案件収支シート（新設）

### 3-1. シート構造

```
案件収支シート
  B1: 案件番号入力セル（プルダウン）
  B2: 版選択（プルダウン: 全て / 現行 / 1 / 2 / ...）→ デフォルト「現行」

  ---- 売上セクション ----
  A5: 「売上」
  A6: 商品売上（税抜）
  B6: =SUMPRODUCT(...) 
  A7: 送料売上（税抜）
  B7: =SUMPRODUCT(...)
  A8: 売上合計
  B8: =B6+B7

  ---- 原価セクション ----
  A10: 「原価」
  A11: 商品仕入（税抜）
  B11: =SUMPRODUCT(...)
  A12: 送料原価
  B12: =SUMPRODUCT(...)
  A13: その他原価（IM手数料等）
  B13: =SUMPRODUCT(...)
  A14: 原価合計
  B14: =B11+B12+B13

  ---- 粗利セクション ----
  A16: 粗利額
  B16: =B8-B14
  A17: 粗利率
  B17: =IF(B8=0,"",B16/B8)

  ---- 販管費セクション（枠のみ） ----
  A19: 「販管費」
  A20: 人件費按分
  B20: （空欄・将来入力用）
  A21: 物流費按分
  B21: （空欄）
  A22: 販管費合計
  B22: =SUM(B20:B21)

  ---- 営業利益 ----
  A24: 営業利益
  B24: =B16-B22
```

### 3-2. 集計数式

#### B6: 商品売上
```excel
=SUMPRODUCT(
  (tbl_明細[案件番号]=$B$1)
  *(IF($B$2="現行",tbl_明細[版ステータス]="現行",IF($B$2="全て",1,tbl_明細[版（Ver）]=VALUE($B$2))))
  *(tbl_明細[行種別]="商品")
  *tbl_明細[販売価格（売値）]
  *tbl_明細[数量]
)
```

#### B7: 送料売上
```excel
=SUMPRODUCT(
  (tbl_明細[案件番号]=$B$1)
  *(IF($B$2="現行",tbl_明細[版ステータス]="現行",IF($B$2="全て",1,tbl_明細[版（Ver）]=VALUE($B$2))))
  *(tbl_明細[行種別]="送料")
  *tbl_明細[販売価格（売値）]
  *tbl_明細[数量]
)
```

#### B11: 商品仕入（税抜ベース）
```excel
=SUMPRODUCT(
  (tbl_明細[案件番号]=$B$1)
  *(IF($B$2="現行",tbl_明細[版ステータス]="現行",IF($B$2="全て",1,tbl_明細[版（Ver）]=VALUE($B$2))))
  *(tbl_明細[行種別]="商品")
  *tbl_明細[仕入価格（税抜）]
  *tbl_明細[数量]
)
```

#### B12: 送料原価
```excel
=SUMPRODUCT(
  (tbl_明細[案件番号]=$B$1)
  *(IF($B$2="現行",tbl_明細[版ステータス]="現行",IF($B$2="全て",1,tbl_明細[版（Ver）]=VALUE($B$2))))
  *(tbl_明細[行種別]="送料")
  *tbl_明細[仕入価格（税抜）]
  *tbl_明細[数量]
)
```

#### B13: その他原価
```excel
=SUMPRODUCT(
  (tbl_明細[案件番号]=$B$1)
  *(IF($B$2="現行",tbl_明細[版ステータス]="現行",IF($B$2="全て",1,tbl_明細[版（Ver）]=VALUE($B$2))))
  *(OR(tbl_明細[行種別]={"手数料","その他"}))
  *tbl_明細[仕入価格（税抜）]
  *tbl_明細[数量]
)
```
※SUMPRODUCTでOR条件は少し工夫が必要。実装時に調整。

## Part 4: 請求とりまとめシート（新設）

### 4-1. 入力エリア

| セル | 内容 | 入力方法 |
|------|------|---------|
| B1 | 請求先顧客名 | プルダウン（案件追跡表の顧客名から重複除去） |
| B2 | 対象年月 | YYYY-MM 手入力 |
| B3 | とりまとめ請求番号 | 自動: INV-SNJ-YYMM-C001 |

### 4-2. 対象案件一覧（自動表示）

```excel
A6: =FILTER(
  CHOOSE({1,2,3},
    tbl_案件追跡[案件番号],
    tbl_案件追跡[商材],
    tbl_案件追跡[売上計上]
  ),
  (tbl_案件追跡[顧客名]=$B$1)
    *(YEAR(tbl_案件追跡[売上計上])=LEFT($B$2,4)*1)
    *(MONTH(tbl_案件追跡[売上計上])=RIGHT($B$2,2)*1),
  "対象案件なし"
)
```

### 4-3. 金額集計

案件ごとの売上合計を集計:
```excel
=SUMPRODUCT(
  (tbl_明細[案件番号]=A6)
  *(tbl_明細[版ステータス]="現行")
  *tbl_明細[販売価格（売値）]
  *tbl_明細[数量]
)
```

### 4-4. とりまとめ請求書テンプレート

既存請求書テンプレートをベースに新設。
FILTER数式を「複数案件番号対応」に変更:

```excel
=FILTER(
  CHOOSE({1,2,3,4,5,6,7},
    tbl_明細[案件番号],   ← 案件番号も表示（どの案件の明細か識別）
    tbl_明細[No],
    tbl_明細[商品名],
    tbl_明細[数量],
    tbl_明細[単位],
    tbl_明細[販売価格（売値）],
    tbl_明細[税率]
  ),
  ISNUMBER(MATCH(tbl_明細[案件番号], 請求とりまとめ!$A$6:$A$25, 0))
    *(tbl_明細[版ステータス]="現行")
    *(tbl_明細[(非表示）販売価格の和] > 0),
  "該当なし"
)
```

## Part 6: 要約/明細分離

### 対応方針
- 現行証憑テンプレートのFILTER出力は20行固定
- 20行以内: 従来通り
- 20行超: 要約シートに案件番号入力 → 仕入先別サマリを表示

### 要約シート構造
```excel
=FILTER(
  CHOOSE({1,2},
    仕入先の一意リスト,
    仕入先ごとの合計金額
  ),
  条件
)
```

※98行案件のような極端なケースはv1.0でPDF対応する方が現実的。
v0.5では「20行以内に収まるように案件を分割する」運用ガイドラインで対処する手もある。

### v0.7: Sansan連携＋顧客情報統合

#### 顧客マスタの新設 or 顧客与信管理の拡張

現状の顧客与信管理シートは与信情報のみ。以下を統合:

| 追加情報 | ソース | 用途 |
|---------|--------|------|
| Sansan企業ID | Sansan CSV | 名寄せキー |
| 案件担当者 | 案件追跡表の担当列 | 営業責任の明確化 |
| 請求担当者 | 新設列 | 請求書送付先（案件担当者と異なる場合） |
| 経理連絡先 | 手動 or Sansan | 入金催促・問合せ先 |
| 業種・規模 | Sansan企業情報 | セグメント分析 |
| 取引開始日 | 手動 | 取引年数の可視化 |
| 累計取引額 | tbl_明細から自動集計 | 顧客ランク判定 |

#### 案件担当者と請求担当者の分離

**発生シーン:**
- 営業は杉田さんだが、請求書の宛先は顧客側経理部門
- 発注は門永さんだが、案件責任は杉田さん
- ホテル案件で料理長（営業先）と購買部（請求先）が異なる

**案件追跡表への列追加:**

| 列名 | 内容 | 自動/手動 |
|------|------|----------|
| 案件担当者 | 営業責任者（現行の「担当」列） | 既存 |
| 請求担当者名 | 請求書宛名の担当者 | 手動（空欄なら案件担当者と同一） |
| 請求先部署 | 経理部 等 | 手動 |
| 請求先メール | 請求書送付用メールアドレス | 手動 |

**証憑テンプレートへの反映:**
- 請求書の宛名: 請求担当者名が入力されていればそちらを優先
```excel
=IF(ISBLANK(XLOOKUP($C$1, tbl_案件追跡[案件番号], tbl_案件追跡[請求担当者名])),
  XLOOKUP($C$1, tbl_案件追跡[案件番号], tbl_案件追跡[顧客名]),
  XLOOKUP($C$1, tbl_案件追跡[案件番号], tbl_案件追跡[請求担当者名])
) & " 御中"
```

#### Sansan CSVインポートフロー

```
Sansan週次CSV出力
  ↓
顧客マスタとの名寄せ（企業名 or Sansan企業ID）
  ↓
新規顧客 → 顧客マスタに追加、与信調査トリガー
既存顧客 → 人事異動・連絡先更新の反映
  ↓
案件番号採番時に顧客マスタからプルダウン選択
```

※v0.7段階ではCSV手動インポート。v1.0でDWH経由の自動同期に移行。
