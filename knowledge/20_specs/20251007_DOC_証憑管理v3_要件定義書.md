## 🎯 システム概要

### 目的
案件管理から各種書類の自動生成までを一括で行うExcelベースの証憑管理システム

### 対象ユーザー
- **営業担当**: 杉田さん、野瀬さん（案件登録、見積作成）
- **事務担当**: 松本さん、黒田さん（発注、納品、請求書発行）
- **仕入担当**: 門永さん（商品マスタ管理）

### システムの特徴
✅ Excelベースで即座に運用開始可能  
✅ 16列に拡張した商品マスタで実務情報を完全管理  
✅ 商品カタログ機能で営業支援  
✅ 5種類の書類を自動生成  
✅ 豊富なサンプルデータで即座に動作確認可能

### 4. 案件マスタ（14列）
| 列 | 項目名 | データ型 | 必須 | 入力方法 | 備考 |
|----|--------|---------|------|---------|------|
| A | 案件番号 | 文字列 | ○ | 手入力 | SNJ-YYMM-NNNN-X-YY |
| B | 見積日 | 日付 | ○ | 手入力 | YYYY/MM/DD |
| C | 顧客コード | 文字列 | ○ | 手入力 | C001 等 |
| D | 顧客名 | 文字列 | - | 自動（VLOOKUP） | 顧客マスタから取得 |
| E | 担当者 | 文字列 | - | 自動（VLOOKUP） | 顧客マスタから取得 |
| F | 納品日 | 日付 | ○ | 手入力 | YYYY/MM/DD |
| G | 納品場所 | 文字列 | ○ | 手入力 | 住所 |
| H | 支払条件 | 文字列 | - | 自動（VLOOKUP） | 顧客マスタから取得 |
| I | 仕入額合計 | 数値 | - | 自動（SUMIF） | 案件明細から集計 |
| J | 販売額合計 | 数値 | - | 自動（SUMIF） | 案件明細から集計 |
| K | 粗利 | 数値 | - | 自動（J-I） | 販売額 - 仕入額 |
| L | 粗利率 | パーセント | - | 自動（K/J） | 粗利 ÷ 販売額 |
| M | ステータス | 文字列 | ○ | 手入力 | 見積済/受注済/失注 等 |
| N | 備考 | 文字列 | - | 手入力 | 自由記述 |

| 列 | 項目名 | データ型 | 必須 | 入力方法 | 備考 |
|----|--------|---------|------|---------|------|
| A | 案件番号 | 文字列 | ○ | 手入力 | 案件マスタと同じ |

| C | 商品コード | 文字列 | ○ | 手入力 | P001 等 |

| E | 単位 | 文字列 | - | 自動（VLOOKUP） | 商品マスタから取得 |
| F | 数量 | 数値 | ○ | 手入力 | 整数または小数 |
| G | 仕入先コード | 文字列 | ○ | 手入力 | S001 等 |
| H | 仕入先名 | 文字列 | - | 自動（VLOOKUP） | 仕入先マスタから取得 |
| I | 仕入単価 | 数値 | - | 自動（VLOOKUP） | 商品マスタから取得 |
| J | 仕入額 | 数値 | - | 自動（F×I） | 数量 × 仕入単価 |
| K | 販売単価 | 数値 | - | 自動（VLOOKUP） | 商品マスタから取得 |
| L | 販売額 | 数値 | - | 自動（F×K） | 数量 × 販売単価 |
| M | 備考 | 文字列 | - | 手入力 | 自由記述 |

## 📄 書類シート設計

### 共通仕様
- **入力**: G3セル（黄色）に案件番号を入力
- **自動生成**: 全情報が自動表示
- **書類番号**: プレフィックス + 案件番号

### 1. 見積書（EST-）
**色**: 青（#4472C4）  
**用途**: 顧客への見積提示

**表示項目**:
- 顧客情報（顧客名、担当者、納品日、納品場所）
- 商品明細（商品名、単位、数量、販売単価、販売額）
- 合計金額（小計、消費税10%、合計）
- 備考（有効期限30日）

### 2. 発注書（POC-）
**色**: オレンジ（#ED7D31）  
**用途**: 仕入先への発注

**表示項目**:
- 仕入先情報（仕入先名、納品希望日）
- 商品明細（商品名、単位、数量、仕入単価、仕入額）
- 合計金額

**特記事項**:
- B9セルに仕入先コード入力必須
- 該当仕入先の商品のみ表示

### 3. 納品書（DEL-）
**色**: 緑（#70AD47）  
**用途**: 顧客への納品確認

**表示項目**:
- 顧客情報（顧客名、納品日、納品場所）
- 商品明細（商品名、単位、数量のみ）

**特記事項**:
- 金額は表示しない

### 4. 請求書（INV-）
**色**: 赤（#C00000）  
**用途**: 顧客への代金請求

**表示項目**:
- 顧客情報（顧客名、担当者、支払条件）
- 商品明細（商品名、単位、数量、販売単価、販売額）
- 合計金額（小計、消費税10%、合計）

**特記事項**:
- インボイス制度対応
- 振込先情報明記（今後追加予定）

### 5. 受領発注書（RCV-）
**色**: 紫（#7030A0）  
**用途**: 顧客からの受注確認

**表示項目**:
- 顧客情報（顧客名、納品予定日）
- 商品明細（商品名、単位、数量、販売単価、販売額）
- 捺印欄（確認日、会社名、部署・役職、担当者名）

**特記事項**:
- 「ご捺印の上、ご返送ください」と赤字明記

## 🆕 商品カタログ機能（v3.0新機能）

### 目的
営業時に使用する仕入先別の商品紹介パンフレット

### 使い方
1. B4セルに仕入先コード入力（例: S003）
2. 仕入先情報が自動表示
3. B13セル以降に商品コードを手入力（例: P007, P008）
4. 商品情報が自動表示
5. 印刷して営業資料として活用

### 表示内容
- 仕入先情報（会社名、住所、電話番号）
- 商品詳細（14列）:
  - No、商品コード、商品名、JANコード
  - 単位、荷姿、入り数
  - 最小ロット、リードタイム、賞味期限
  - 温度帯、商品特徴
  - 参考卸価格、参考上代

### 注意事項
- 商品コードは現時点では手入力必須
- Phase 1で自動抽出機能を実装予定

## 💡 業務フロー

### 標準的な案件の流れ

```
【営業担当（杉田さん）】

1. 顧客からの引き合い
   ↓
2. 案件マスタに新規登録
   - 案件番号: SNJ-2510-1001-S-01
   - 見積日: 2025/10/01
   - 顧客コード: C001
   - 納品日: 2025/10/11
   ↓
3. 案件明細に商品登録
   - 商品コード: P001
   - 数量: 50
   - 仕入先コード: S004
   ↓
4. 見積書シートで自動生成
   - G3セルに案件番号入力
   - PDF保存・送付
   ↓
5. 顧客から受注連絡
   - ステータスを「受注済」に更新

【事務担当（松本さん）】

6. 受領発注書の発行
   - 顧客にメール送付
   ↓
7. 仕入先への発注
   - 発注書シートで自動生成
   - 仕入先ごとに発行
   ↓
8. 商品納品時
   - 納品書シートで自動生成
   ↓
9. 請求書発行
   - 請求書シートで自動生成
   ↓
10. 入金確認
    - ステータスを「完了」に更新
```

## 🔧 技術仕様

### 使用する主な関数

**VLOOKUP**: マスタからの情報取得
```excel
=VLOOKUP(検索値, 範囲, 列番号, FALSE)
```

**SUMIF**: 条件付き合計
```excel
=SUMIF(範囲, 条件, 合計範囲)
```

**INDEX-MATCH**: 複数条件での検索
```excel
=INDEX(戻り値の列, SMALL(IF(条件, ROW(列)), 行番号))
```

**IFERROR**: エラー処理
```excel
=IFERROR(数式, エラー時の値)
```

### スタイル定義

**ヘッダー**: 青背景、白文字、中央揃え  
**入力セル**: 黄色背景  
**自動計算セル**: 灰色背景  
**罫線**: 全セルに細線

## ⚠️ 制約事項

### 技術的制約
1. 同時編集不可（Excelファイルベース）
2. データ量上限約5,000件
3. INDEX-MATCH関数の配列数式が必要
4. 通し番号の手動リセット

### 運用上の注意点
1. 案件番号の一致必須
2. マスタの事前登録必須
3. 数式の保護
4. 日次バックアップ推奨
