# インフォマート商品登録 × SENDO連携設計

更新日: 2026-04-03
ステータス: 方針確定・実装待ち

---

## 1. 前提と方針

### SNJのインフォマート利用状況

- 利用形態: **売り手側**（BtoBプラットフォーム受発注）
- 現在の取引先: グループ内が中心
- 今後の展開: 外部見込客にも拡大予定
- 現在の商品登録: 一部商品を手動登録で運用中

### 確定した方針

- **全商品を商品マスタに一括登録し、取引先ごとの「発注マスタ（マイカタログ）」で表示制御する**
- SENDO商品マスタには手を加えず、**別シート（変換用中間Excel）** でIM用CSVを生成する（方式B）
- 自社管理商品コードは **PRD_SNJ_ プレフィックスを除去** して登録する（文字数削減）
  - 例: `PRD_SNJ_HOY_0001_00` → `HOY_0001_00`

---

## 2. インフォマートの商品管理構造

### 二層構造

| 層 | 名称 | 役割 | 取引先からの可視性 |
|----|------|------|-------------------|
| 第1層 | 商品マスタ | 自社の全商品台帳 | 見えない |
| 第2層 | 発注マスタ（マイカタログ） | 取引先別の公開カタログ | 発注画面に表示 |

商品マスタ＝「在庫」、マイカタログ＝「陳列」と考える。全商品を先に商品マスタへ一括登録しておけば、新規取引先の開設時はマイカタログの商品選択だけで済む。

### マイカタログ共有機能

グループ内利用では、本部でマイカタログを作成→グループ会員が共有依頼→承認のフローで取得可能。外部顧客拡大時は取引先ごとに個別マイカタログを作成し、取扱商品と単価を個別設定する。

## 3. CSV一括登録フォーマット仕様

### ファイル仕様

| 項目 | 仕様 |
|------|------|
| 文字コード | **Shift-JIS**（UTF-8不可） |
| 改行コード | CRLF |
| ファイルサイズ上限 | 200KB（超過時はファイル分割） |
| 1ファイルあたり最大件数 | 999件 |
| 区切り文字 | カンマ |

### 禁止文字

`% ^ * ( ) ' [ ] < > " ,` およびタブ・制御コード。

商品名に半角括弧を使用している場合は全角（）に置換する。数値項目では先頭ゼロ不可だが、商品コードの英数字型では意味あるゼロは維持。

### 14列のフォーマット定義

| # | 列名 | 必須 | 型 | 備考 |
|---|------|------|----|------|
| 1 | 自社管理商品コード | ○ | 半角英数 | PRD_SNJ_除去後のコードを使用 |
| 2 | 商品名 | ○ | テキスト | 禁止文字チェック必須 |
| 3 | 商品名フリガナ | | カタカナ | SENDO側にないため補完が必要 |
| 4 | 規格 | | テキスト | 荷姿・容量から生成 |
| 5 | 入数 | | 数値 | ケース入数など |
| 6 | 入数単位 | | テキスト | ケース/箱等 |
| 7 | 商品小分類コード | | 6桁数値 | 2,493分類から選択（別表参照） |
| 8 | 取引先コード | | | マイカタログ紐づけ用。空欄可 |
| 9 | 単価 | ○ | 数値 | 取引先別に変える場合はマイカタログ側で設定 |
| 10 | 単位 | ○ | テキスト | IM所定の単位コード（118種） |
| 11 | 利用開始日・変更適用日 | | 日付 | YYYY/MM/DD |
| 12 | コメント | | テキスト | 産地情報・商品特徴に活用 |
| 13 | 共有先取引先コード | | | グループ内共有用 |
| 14 | 自社担当者コード | | | IM上の担当者設定 |

## 4. SENDO商品マスタとの項目マッピング

### 変換ルール

| IM列 | SENDOマスタの対応項目 | 変換処理 |
|------|----------------------|----------|
| 自社管理商品コード | 商品コード | `SUBSTITUTE(商品コード,"PRD_SNJ_","")` |
| 商品名 | 商品名 | 半角禁止文字→全角変換 |
| 商品名フリガナ | **項目なし** | 手動補完 or PHONETIC関数（精度低） |
| 規格 | 荷姿 + 容量 | 結合して生成 |
| 入数 | 入り数 | そのまま |
| 入数単位 | **項目なし** | 「箱」「ケース」等を手動補完 |
| 商品小分類コード | **項目なし** | マッピングテーブルで変換（後述） |
| 取引先コード | （空欄） | マイカタログ側で管理 |
| 単価 | 販売単価 | そのまま（取引先別はマイカタログ側） |
| 単位 | 単位 | IM単位名に変換（kg→kg、本→本など） |
| 利用開始日 | **項目なし** | CSVアップロード日を入力 |
| コメント | 商品特徴 | 文字数上限に注意して転記 |
| 共有先取引先コード | （空欄） | 必要に応じて設定 |
| 自社担当者コード | （空欄） | 必要に応じて設定 |

### SENDOマスタに不足している項目（変換時に補完が必要）

1. **商品名フリガナ** — 初回は手動入力。以降はSENDOマスタ側にフリガナ列を追加することも検討
2. **入数単位** — 荷姿情報から類推可能だが確認が必要
3. **商品小分類コード** — マッピングテーブルで対応（次項参照）

## 6. 変換用中間Excelの設計

### シート構成

```
IM変換ツール.xlsx
├── 設定シート
│   ├── 小分類コードマッピング（SENDOカテゴリ→IM小分類コード）
│   ├── 単位コードマッピング（SENDO単位→IM単位名）
│   └── 禁止文字変換ルール
├── 変換シート
│   ├── SENDOマスタ貼付エリア（手動ペースト or IMPORTRANGE）
│   ├── IM用変換列（数式で自動変換）
│   └── CSV出力用整形列（14列に並び替え）
└── csv出力用シート（変換シートから転記、この状態でCSV保存）
```

### 変換シートの主要数式

```
商品コード変換:
=SUBSTITUTE([@商品コード], "PRD_SNJ_", "")

商品名サニタイズ:
=SUBSTITUTE(SUBSTITUTE(SUBSTITUTE([@商品名], "(", "（"), ")", "）"), "'", "'")

小分類コード:
=VLOOKUP([@SENDOカテゴリ], 設定!小分類マッピング, 2, FALSE)
```

### CSV出力手順

1. SENDOマスタから変換対象商品を変換シートに貼付
2. フリガナ・入数単位など不足項目を手動補完
3. csv出力用シートの14列が正しく表示されていることを確認
4. csv出力用シートを表示した状態で「名前を付けて保存」
5. 形式: **CSV（コンマ区切り）(.csv)**（「CSV UTF-8」は不可）
6. インフォマート管理画面 > 商品マスタ一括登録 > アップロード

## 7. 価格管理の運用ルール

### 基本方針

- **SENDOが正（Single Source of Truth）**
- 商品マスタには「標準販売単価」を登録
- 取引先別単価はマイカタログ側で個別設定
- 価格改定時はSENDO更新→IM CSV再アップロードの順で実施

### 取引先別単価の運用

| 取引先種別 | 単価設定場所 | 備考 |
|-----------|-------------|------|
| グループ内 | 商品マスタ（標準単価） | マイカタログ共有で展開 |
| 外部顧客 | マイカタログ（個別単価） | 取引先ごとに設定 |

## 8. 受注データのSENDO取り込み

### 手動ダウンロードフロー（現段階の推奨）

1. IM管理画面 > ダウンロード > 受注データCSV出力
2. 出力項目をSENDOフォーマットに合わせてカスタマイズ（初回のみ設定保存）
3. CSVをExcelで開き、IM商品コード→SENDO商品コードの逆引き
   - 逆引き数式: `="PRD_SNJ_" & [@IM商品コード]`
4. SENDO案件明細にコピペ

### 将来の拡張パス

| フェーズ | 方式 | 月額コスト | 条件 |
|---------|------|-----------|------|
| 現在 | 手動CSVダウンロード | 0円 | — |
| 拡張1 | タスクスケジュール（FTPS自動取得） | 30,000円 | 固定グローバルIP必要 |
| 拡張2 | API連携（OAuth2.0） | 要見積 | 販売管理システム導入時 |

## 9. 案件収支管理との紐づけ

案件収支管理システム設計書v2において、経費区分「手数料_インフォマート」は原価算入対象（国内・海外とも）として既に定義済み。IM経由の受注案件では、この経費区分にIMの従量手数料を計上する。
