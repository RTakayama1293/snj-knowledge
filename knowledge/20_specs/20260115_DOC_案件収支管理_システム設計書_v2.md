# 案件収支管理システム 設計書 v2

## 📋 概要

### 目的
- 案件ごとの収支を可視化し、粗利管理を徹底する
- 見積書作成と収支管理を一体化し、営業の入力負荷を軽減する
- 月次報告・ダッシュボードのデータ基盤とする

### 基本方針
- **1案件1ファイル**で管理し、営業のUXを最優先
- **入力は1シートに集約**（ヘッダー + 明細 + 経費）
- **共有マスタをIMPORTRANGEで参照**し、マスタ同期問題を解決
- 国内/海外で粗利計算ロジックを分離（蜂巣方針準拠）

## 🔗 IMPORTRANGE同期の仕組み

### 案件ファイル → マスタ参照

```
=IMPORTRANGE("マスタファイルのURL", "シート名!A:Z")
```

- 案件ファイル作成時に1回だけ承認操作が必要
- 以降はマスタ更新が自動反映
- 各案件ファイルの隠しシートにマスタをインポート

### ダッシュボード → 案件ファイル集計

```
=IMPORTRANGE("案件ファイルのURL", "入力!$B$3:$B$8")
```

- 案件追加のたびにダッシュボード側に行追加
- 案件一覧シートでURL管理

## 🗂️ 共有マスタ詳細

### 商品マスタ.gsheet

**設計思想**
- 商品コードでユニーク（1商品コード = 1仕入先の1商品）
- 異なる仕入先の同一商品は別コードとして管理
- **送料は汎用レコード**として登録、価格は案件ごとに手入力

|----|------|------|------|

| C | 仕入先名 | ○ | |
| D | 商品名 | ○ | 表記統一必須 |

| F | 単位 | ○ | kg/本/パック/式 等 |
| G | 容量 | | |
| H | ロット入数 | | |
| I | 荷姿 | | |
| J | 賞味期限 | | |
| K | 温度帯 | ○ | 冷凍/冷蔵/常温/- |

### 目標粗利率（固定テーブル）

案件ファイル内に固定値として保持

| 加工区分 | 国内（送料込） | 海外（送料別） |
|----------|----------------|----------------|
| 単純仕入 | 20% | 30% |
| 定型加工 | 25% | 35% |
| 特注加工 | 30% | 40% |
| 送料 | 0% | 0% |

**運用ルール**
- セールス裁量で5%まで値引き可能
- 5%を超える値引きは蜂巣相談
- 送料は基本的に利益ゼロで右から左へ流す

## 📄 案件ファイル 出力シート詳細

### 共通仕様

- 入力シートのヘッダー部・明細部から自動参照
- 帳票番号 = プレフィックス + 案件番号

| シート | プレフィックス | 用途 |
|--------|----------------|------|
| 見積書 | EST- | 顧客への見積提示 |
| 発注書 | POC- | 仕入先への発注 |
| 請求書 | INV- | 顧客への代金請求 |
| 収支表 | - | 案件別P/L |

---

### 見積書

**表示項目**
- 見積番号、見積日
- 顧客名、担当者名
- 明細（商品名、単位、数量、販売単価、売上額）
- 送料（明細に含まれる場合はそのまま表示）
- 小計、消費税、合計

---

### 発注書

**表示項目**
- 発注番号
- 仕入先名（明細から自動判定、複数仕入先の場合は分割出力）
- 明細（商品名、単位、数量、仕入単価、仕入額）
- 小計、消費税、合計

**複数仕入先対応**
- 仕入先コード入力欄を設け、該当仕入先の商品のみ表示
- 仕入先ごとに発注書を出力

---

### 請求書

**表示項目**
- 請求番号、請求日
- 顧客名、担当者名
- 明細（商品名、単位、数量、販売単価、売上額）
- 小計、消費税、合計
- 振込先情報

---

### 収支表

**P/L形式で表示**

| 科目 | 金額 | 率 |
|------|------|------|
| **売上高** | | 100.0% |
| **売上原価** | | |
| 　商品仕入 | | |
| 　物流費（原価算入分） | | |
| 　取引手数料・保険 | | |
| **売上総利益（粗利）** | | **%** |
| 　目標粗利率 | | % |
| 　目標との乖離 | | ±% |
| 輸出関連費用（原価外） | | |
| 営業経費 | | |
| **案件営業利益** | | **%** |

## 🔄 運用フロー

### 新規案件作成

```
1. テンプレートをコピー
   案件収支_テンプレート.gsheet → コピーを作成
       ↓
2. ファイル名変更
   [案件番号]_[案件名].gsheet
       ↓
3. マスタ参照承認（初回のみ）
   IMPORTRANGEの承認ダイアログで「アクセスを許可」
       ↓
4. 入力シートに案件情報入力
       ↓
5. ダッシュボードにURL追加
```

### 見積作成〜受注

```
1. 入力シート：ヘッダー部入力
       ↓
2. 入力シート：明細部入力
   商品選択 → 数量・販売単価入力
   送料がある場合 → 送料レコード選択、価格手入力
       ↓
3. 見積書シート → PDF出力 → 顧客へ送付
       ↓
4. 受注後：入力シートでステータス更新
       ↓
5. 発注書シート → 仕入先ごとにPDF出力
```

### 納品〜請求

```
6. 入力シート：経費明細入力（物流費・手数料等）
       ↓
7. 請求書シート → PDF出力 → 顧客へ送付
       ↓
8. 収支表シートで採算確認
       ↓
9. 入金確認後：ステータスを「回収完了」に更新
```

### 月次報告

```
ダッシュボード.gsheet を開く
       ↓
案件一覧が自動更新されている
       ↓
月次集計シートでピボット集計
       ↓
必要なグラフ・表を月次報告資料にコピー
```
