# EEZO 商品カタログ テンプレート仕様書

## 概要

BtoB営業用の商品カタログをExcelテンプレート＋Pythonスクリプトで自動生成するシステムの仕様。Shopifyの商品データを流し込み、1シート2商品のA4横カタログを量産する。

**設計方針**: Excel方眼紙でレイアウトを完全固定し、openpyxlでデータ差し替え＋画像挿入のみ行う。レイアウト調整はExcel上で手作業、データ流し込みはスクリプトで自動化、という役割分担。

## データソース

### Shopifyからの取得項目

商品データはShopify Admin API（GraphQL）の`products`クエリから取得する。

| カタログ項目 | Shopifyフィールド | 備考 |
|---|---|---|
| 商品名 | `title` | |
| 商品画像 | `featuredMedia.preview.image.url` | CDN URL |
| 商品説明 | `description` | HTML除去して使用 |
| 温度帯 | `tags` | "常温" / "冷凍" / "冷蔵" |
| 参考上代 | `variants.edges[0].node.price` | |

以下の項目はShopifyのメタフィールドまたは外部マスタから取得。メタフィールド未整備の場合はスクリプト側でマッピングテーブルを持つ。

産地、内容量、賞味期限、保存方法、最小ロット、リードタイム、JANコード、参考卸価格、アレルゲン


## 画像挿入仕様

### サイズ計算

openpyxlの`Image.width` / `Image.height`はピクセル単位。Excelの表示は96dpiベースのため、mm→px変換は以下の通り。

```
px = mm × (96 / 25.4) ≒ mm × 3.78
```

| 画像エリア | サイズ(mm) | サイズ(px) | アンカーセル |
|---|---|---|---|
| 左商品 | 132 × 79 | 498 × 298 | A29 |
| 右商品 | 131 × 79 | 495 × 298 | EQ29 |

### 画像取得フロー

```
Shopify CDN URL → requests.get() → Pillow.open()
  → thumbnail()でアスペクト比保持リサイズ
  → PNG保存 → openpyxl Image → ws.add_image(anchor)
```

### 注意事項

- openpyxlの画像はセルの左上隅にアンカーされるが、セルに「固定」はされない
- セルサイズ確定後に画像を挿入すること（順序厳守）
- ShopifyのCDN URLは`.webp`形式が多い。Pillowで読めるが、Excel互換のためPNGに変換して挿入する


## スクリプト処理フロー

```
1. テンプレートxlsx読み込み（load_workbook）
2. Shopifyから商品データ取得（API or CSV）
3. 2商品ずつペアにする
4. テンプレートシートをcopy_worksheet()で複製
5. プレースホルダーを実データに置換
6. 商品画像をダウンロード → リサイズ → 挿入
7. 全ペア処理後、保存
```

### シート複製の挙動

`copy_worksheet()`はセル結合・スタイル・印刷設定を引き継ぐ。方眼紙＋結合セル構造でも問題なくコピーされる。1シート = 1ページ（2商品）で運用する。
