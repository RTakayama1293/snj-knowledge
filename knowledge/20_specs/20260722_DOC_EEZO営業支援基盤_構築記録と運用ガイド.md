**作成日**: 2026-07-22
**精度ゾーン**: 実装記録は100%（Shopify反映済み・検算済み）／運用方針は70%

## 1. 目的と全体像

EEZOを「売る場」から「営業が武器として持ち歩く場」へ拡張する。Shopifyを営業支援ツール化し、仕入先別原価・粗利・商品スペックを管理画面で一覧できる基盤を構築した。

```
【データ層】 Shopifyネイティブ原価 ＋ メタオブジェクト/メタフィールド
【閲覧層】  Shopify管理画面（当面の方針。将来GAS同期シート）
【アクション層】 下書き注文（Draft Order）＝見積の正本（実行可能性確認済み・未運用）
```

## 2. 合意した方針・ルール

| # | 項目 | 内容 |
|---|------|------|
| 1 | 原価・粗利の開示範囲 | 社内スタッフに全部開示（田嶋・杉田含む） |
| 2 | 通常粗利率 | **toB=10% / toC=20%**（当初15%案はファイル準拠で10%に確定的整理）。限界粗利率は未設定 |
| 3 | 閲覧層 | 当面Shopify管理画面のみ。カスタムアプリ・外部ダッシュボードは保留 |
| 4 | SENDO移管 | EEZO系（受注・見積）はShopifyへ寄せ、非EC案件管理・SI計数・証憑はSENDO/Nareful残留の**部分移管**が現時点の方針 |
| 5 | 計算値は保存しない | 粗利販売価格は「原価÷(1−粗利率)」で都度算出。保存するのは原価と率のみ |
| 6 | 全項目ストアフロント非公開 | access.storefront=NONE。サイト・AIフード・Metaフィードに流れない |
| 7 | 出典主義 | 仕入条件レコードは全件出典付き（現行：鹿肉仕入価格順位表 20260722版） |

### 価格体系の3層モデル（エゾシカ精肉）

```
標準仕入価格（部位別・月次更新／高山が状況を見て統計ルールで決定）
  現行ルール：ヒレ・ランプ＝Q75、他10部位＝median（Q50）
    ↓ ÷(1−粗利率)  B=0.9 / C=0.8、100円単位丸め
標準販売価格（税抜）＝ 価格順位表Excelの標準価格行
    ↓ ×1.08（軽減税率）
店頭価格（税込）＝ Shopifyバリアント価格
```

### 不定貫の価格表示ルール（商品説明に明記済みの現行運用）

- 表示価格＝**重量目安の下限**分の金額（ロース・バラ=1.5kg建て、ウチモモ・ソトモモ・カタ・スネ=1.0kg建て）
- 出荷時に計量し、超過分を追加請求／下回れば返金
- チルドは冷凍+150円
- ネイティブ原価も同じ下限重量建てで入力（標準仕入単価×下限kg）

## 3. Shopify上に構築したもの（2026-07-22反映済み）

### 3-1. 定義（13件）

| 区分 | 内容 |
|------|------|
| メタオブジェクト | `supplier`（仕入先マスタ）、`supplier_offer`（仕入条件。仕入先参照・単価・単位・出典等） |
| バリアント定義（`snj_sales`） | offers（仕入条件一覧）／margin_normal_rate（通常粗利率%）／margin_floor_rate（限界粗利率%）。全てピン留め済み |
| 商品定義（`snj_sake`） | 銘柄・酒別・日本酒度・酸度・精米歩合・こだわり・既存NG国（ISOコード）・酒税額/本 |

### 3-2. データ（103レコード）

- **仕入先マスタ10社**：ユック／上田／あぷか／エゾモミジ／ソヴァージュ／食美樂／知床（猟銃）／エゾの杜／知床（養鹿）／阿寒。分類（認証/クリーンキル/熟成）・ABC評価・サンプル提供条件・所感をnotesに保存
- **仕入条件93件**：仕入先×部位の単価（円/kg・税抜）。管理画面 設定>カスタムデータ>仕入条件 で部位名検索すれば全社横並び比較が可能

### 3-3. 商品への接続（エゾシカ精肉9バリアント）

| 部位 | 税込価格（下限建て） | 標準原価 | 紐付け仕入条件 |
|------|---:|---:|:---:|
| ロース×4（冷凍/チルド×グリムキ/筋脂付き） | 9,558／9,708 | 7,130 | 10社 |
| ウチモモ | 4,644 | 3,450 | 9社 |
| ソトモモ | 3,888 | 2,930 | 8社 |

全バリアントに通常粗利率20%（toC）を投入済み。**ストア分析の粗利レポートが実データで稼働開始**。

## 4. 検算で検出した事故と対応

| # | 検出内容 | 対応 |
|---|---------|------|
| 1 | スネの価格・原価にバラ系の値が混入（価格4,374=バラと同一、原価3,285=バラ原価×1.5） | 高山が管理画面で修正→2,376円／1,836円。読み戻し検証済み |
| 2 | バラの原価がkg単価のまま（価格は1.5kg建てなのに原価2,190） | 3,285円（2,190×1.5）に修正済み |
| 3 | ロースの原価が未入力 | 7,130円（median 4,753×1.5）を入力済み |
| 4 | ソトモモの説明文冒頭が「ウチモモ ブロック」のまま | **未対応**（1ミューテーションで修正可能） |

教訓：突合表は「価格変更提案」でなく「検算」としても機能する。月次更新のたびに実施する。

## 5. 月次運用フロー（標準仕入価格の更新）

高山のアクションは太字の2つのみ。他はミナトが実行。

```
1. 【高山】最新の価格順位表Excelをミナトに渡す
2. 仕入条件93件を新出典で一括更新（約4コール）
3. 統計ルールで標準仕入を再計算（現行：ヒレ・ランプQ75／他median）
   ※ルール変更は口頭指示で反映可
4. 標準販売価格案（÷0.9／÷0.8→丸め→×1.08）＋現行価格との検算表を提示
5. 【高山】検算表を承認（価格が動く＝100%ゾーンのゲート）
6. バリアント価格・ネイティブ原価を一括反映＋読み戻し検証
```

補助ルール：
- 仕入先の追加・撤退はマスタの追加/notes追記で対応（レコード削除はしない。取引履歴の出典が残るため）
- 標準販売価格の丸め：B=÷0.9後100円単位切上げ／C=÷0.8後100円単位（現行表の実績準拠）

## 7. 技術メモ（ミナト向け引き継ぎ）

- namespace：営業支援=`snj_sales`（バリアント）／日本酒=`snj_sake`（商品）。既存`custom`は商品表示用で不変更
- `custom.supplier`（テキスト型仕入先）は併存中。正本は`supplier`メタオブジェクト、テキスト側は表示用スナップショット扱い
- 下書き注文の単価指定は`originalUnitPriceWithCurrency`を使用（`originalUnitPrice`は非推奨）
- ネイティブ原価はShopify側で整数丸め（7,129.5→7,130）
- エゾシカ商品の抽出クエリ：`tag:エゾシカ`（10商品。うち精肉6・適用外4）
- 投入済みGIDの一覧はミナトの過去チャット（2026-07-22）に記録あり
