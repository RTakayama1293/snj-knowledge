# 2025年末総括：答えが出た11の問い

**作成日**：2025年12月27日  
**更新日**：2026年1月5日  
**背景**：突発性難聴の発症を機に、働き方と認知のあり方を見直すための対話を実施。奥さんとの対話で得られた3つの知見（他人に好かれることを評価基準にしない / やらなくていい仕事をやらない / データサイエンティストとして事実を述べる）を出発点に、深掘りを行った。  
**2026/1/5追記**：病院にて聴力完全回復を確認。早期治療が奏功した。

## Q1. なぜこんなに忙しいのか？

### 答え

**構造的には正しい。COOポジションだから。**

蜂巣さんの方針で、杉田さんを営業に集中させるためにオペレーションを引き上げている。9人組織でその役割を担えるのは自分しかいない。蜂巣さんも「COOが一番忙しいのと同じ」と言っている。

**量的な忙しさは仕方ない。問題は別のところにあった。**

## Q2. 自分の役割は何なのか？

### 答え

**「データサイエンティスト」ではなく「経営企画」。分析もできる何でも屋。**

| 入社時の想定 | 実態 |
|--------------|------|
| データサイエンティスト | 分析 + オペレーション + 仕組み化 |
| 分析で価値を出す | 分析「も」含めて組織を回す |

蜂巣さんからも言外に、実際にも、経営企画的な志向を求められている。この認識で合っている。

## Q3. どう評価されるのか？

### 答え

**明文化された評価基準はない。だから自分で決める。**

経営企画の成果として測れるもの：

**アウトプット指標**
- 作った仕組みの数
- 意思決定に使われた分析の数
- ドキュメント化した業務の数
- 引き継ぎ可能な状態になった業務の数

**プロセス指標**
- 「気づき」を提供した回数
- 問題を早期発見した件数
- 無駄な施策を止めた件数

**売上は入れない。売上は営業の仕事。自分は支援者。**

## Q4. 本社は商事をどう見ているのか？

### 答え

**わからない。蜂巣さんに聞いてもわからない。**

社長は投資姿勢。谷崎専務・管理部は「いつ黒字化するんだ」という目で見ている可能性がある。経理からの圧は感じるが、実態なのかポーズなのか不明。

**「わからない」は解消できない。わからないまま、持続可能に働く設計をするしかない。**

## Q5. 黒字化しなかったらどうなるのか？

### 答え

**わからない。でも前職とは違う。**

| 前職（外資） | 今（新日本海商事） |
|--------------|-------------------|
| 結果未達 = 退場 | 上場日系、首にはならない |
| 選択権なし | 自分で選べる |

最悪のシナリオを具体化すると：
- 本社への異動？
- 商事の縮小・統合？
- 給与カット？

**どれも「死ぬわけじゃない」。前職で見た「首」とは違う。**

そして、いつまでここにいるか、どこまでやるかを決めるのは本社ではなく自分。

## Q6. データ分析の成果はどう測るのか？

### 答え

**売上ではなく「何ができるようになったか」で測る。**

測れるもの：

1. **意思決定の前倒し**
   - 例：CS-cartの問題を3ヶ月で発見し、移行判断を前倒しできた

2. **避けた損失**
   - 例：A級リード9件を特定し、営業リソースの分散を防いだ

3. **仕組み化による工数削減**
   - 例：JIRA PIPE、Sansan連携、SENDO構想 → 再現可能・引き継ぎ可能に

**悪い分析結果も成果。「ダメだと気づけた」のは発見。医者が「がんです」と診断するのと同じ。早く見つけたから治療できる。**

## Q7. 強迫的傾向・ADHD・他者評価敏感さとどう付き合うか？

### 答え

**意志力で抗うのは無理。環境設計で迂回する。**

### 即答禁止ルール

依頼が来たら「確認して明日返事します」をデフォルトに。ADHDの衝動的YESを遅延させる。

### 「誰がやるべきか」チェックリスト

| 質問 | YES→自分 | NO→他の人 |
|------|----------|-----------|
| 分析・仮説構築が必要？ | ○ | |
| 自分しか持ってない情報が必要？ | ○ | |
| 戦略的判断が必要？ | ○ | |
| 実行・作業がメイン？ | | ○ |
| テンプレ化・ルール化で済む？ | | ○ |

### タスクの分類

| 種類 | 例 | 対応 |
|------|-----|------|
| A種：杉田さんから引き上げたオペ | 受発注処理、見積作成 | やる（組織方針） |
| B種：なんとなく回ってきたもの | メールレビュー、稟議書作成 | 断る or 80点 |

### 80点ルール

納品前に「これ以上やったら過剰」ラインを宣言してから作業開始。超えたら強制終了。

### 週次「やらなかったことリスト」

毎週金曜に記録：
- 今週断った依頼
- 今週他の人に振った仕事
- 今週80点で出したもの

**「やらなかったこと」を成果としてカウントする。**

## Q8. どういう気持ちで仕事に臨めばいいか？

### 答え

**「負けないように打つ。勝ちは後からついてくる。」**

### 基本姿勢

仕事はゲーム。ただし「勝つぞ」ではなく「崩れないように打つ」。

麻雀で言えば：
- 配牌悪くても丁寧に打つ
- 降りるべき時は降りる
- 自分の手だけじゃなく場を見る
- 半荘単位じゃなく100半荘で見る

仕事で言えば：
- 売上悪くても丁寧にやる
- 撤退すべき施策は撤退する
- 自分だけじゃなく組織全体を見る
- 月単位じゃなく年単位で見る

### 五条悟モード

「最強だから勝つ」ではなく「余裕があるから崩れない」。

飄々としているのは、勝ちに執着してないから。負けても死なないと知ってるから。

### 日常のセルフトーク

| 場面 | セルフトーク |
|------|-------------|
| 朝 | 「今日も丁寧に打つ」 |
| 焦りを感じた時 | 「あ、あったまってる。一回止まろう」 |
| 悪い結果が出た時 | 「降りる局面。丁寧に降りる」 |
| プレッシャー感じた時 | 「100半荘で見たら誤差」 |
| うまくいった時 | 「してやったり」（ちゃんと味わう） |

## Q9. なぜ追い込まれていたのか？

### 答え

**自縄自縛。自分で自分に縄を巻いていた。**

### 巻いていた縄のリスト

| 縄 | 実態 |
|-----|------|
| 売上が上がらないのは俺のせい | 売上は営業の仕事。俺は支援者 |
| 悪い分析結果を出したのは俺の失敗 | 事実を発見したのは俺の成果 |
| 本社にどう思われてるか不安 | わからないものはわからない。コントロール外 |
| 前職みたいに切られるかも | ここは外資じゃない。首にはならない |
| もっとやらないと認められない | 蜂巣さんは「やってもらうしかない」と言ってる＝すでに認めてる |

### 構造

評価基準が不透明 → 「いつ、どう判断されるかわからない」 → 最悪のシナリオを想像（前職の記憶が増幅）→ 「とにかく成果を出さないと」 → 過剰労働

**ゴールラインが見えないマラソンを走っていた。**

### 「縄解き」のセルフトーク

「またバグってるな」と気づいたら：

> **「これは俺の縄か？」**

- 売上が足りない → 俺の縄じゃない
- 分析結果が望ましくない → 俺の縄じゃない（発見の成果）
- 本社の評価が不安 → 俺の縄じゃない（コントロール外）

## Q10. 勝ち好きを抜け出すにはどうしたらいいか？

### 答え

**「勝ち好き」から「崩れない」へシフトする。**

### 構造の違い

**負けず嫌い**：負ける → 悔しい → 「次は絶対勝つ」 → 燃料になる

**勝ち好き**：勝つ → 嬉しい → 燃料になる / 負ける → 嫌 → 燃料にならない

**自分のパターン**：負ける → あったまる → 勝ち方しか見えない → フォーム崩れる → また負ける

### 悪いループの切り方

**Step 1**：あったまってることに気づく
> 「あ、今あったまってる」

**Step 2**：一度離れる
> 「今日はここまで。明日考える」

**Step 3**：フォームを確認
> 「俺、今何に囚われてる？」
> 「場全体見えてる？」
> 「負け筋潰しに執着してない？」

**Step 4**：落ち着いてから戻る

### 新しいフレーム

| 古いフレーム | 新しいフレーム |
|-------------|---------------|
| 勝ちたい | 崩れない |
| 勝ち方を探す | 負けないように打つ |
| 勝てば嬉しい、負けたら嫌 | 丁寧に打てたらOK |

**勝てる時は最初から落ち着いている。だから「落ち着いている状態を維持すること」が最優先。**

## Q11. 草案を作ってひっくり返される役割を、どうポジティブに続けるか？

### 答え

**認知の書き換えではなく、測れる勝利条件を設定する。**

「叩き台職人としての価値」は頭では理解できる。でも腹落ちしない。ADHDの特性として長期的な報酬に対する感度が鈍いので、精神的勝利では意味がない。

### 勝利条件（測れるもの）

**カウントするもの**：

1. **叩き台から何かが「決まった」件数**（内容が変わっても、決まったら勝ち）
2. **当初の自分の想定に着地した件数**（揉んだ結果戻ってきた）

2番目は「俺が先に見えてた」の証拠。純粋に勝ち。

### 蜂巣さんの特性を理解する

```
高山：叩き台出す（方向性Aがいいと思ってる）
    ↓
蜂巣さん：せっかち、ひっくり返す
    ↓
揉む、議論する
    ↓
着地：結局、方向性Aになる
```

蜂巣さんは「揉むプロセス」が必要な人。最初から「Aでいきましょう」と言っても納得しない。自分で揉んで、自分で辿り着きたいタイプ。

**ひっくり返されるのは否定ではなく、蜂巣さんのプロセスが始まった合図。**

### セルフトーク

| 場面 | セルフトーク |
|------|-------------|
| 叩き台出す時 | 「投入。さあ揉もう」 |
| ひっくり返された時 | 「蜂巣さんのプロセス開始」 |
| 最終的に当初案に戻った時 | 「やっぱりな。先に見えてた」（これを味わう） |

### 週次で数える

> 「今週、俺の叩き台から決まったこと：○件」
> 「うち、当初の想定通りに着地：○件」

## 奥さんの3つの知見（実装版）

### 1. 他人に好かれることを評価基準にしない
→ 自分で決めた指標で自分を測る
→ 仕組みの数、意思決定の数、「してやったり」の回数

### 2. やらなくていい仕事をやらない
→ A種（杉田さんから引き上げたオペ）はやる。B種（なんとなく来たもの）は断る
→ 即答禁止ルールで衝動的YESを防ぐ

### 3. データサイエンティストとして事実を述べる
→ 「悪い事実」も成果。発見は価値
→ 結果は俺の責任ではない
