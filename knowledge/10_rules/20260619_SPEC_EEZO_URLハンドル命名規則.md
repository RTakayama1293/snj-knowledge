# EEZO Shopify URLハンドル命名規則

**作成日**: 2026-06-19
**対象**: eezo.club（Shopify Advanced）の商品・コレクション・ページ全般
**根拠**: きょうの日本酒 / 赤坂柿山 / MODERNCA / TAKANOME / 養老ミート 等の高級食品EC調査に基づく

---

## 基本原則

1. **日本語ハンドル禁止**。すべてローマ字（ヘボン式）または英語
2. 区切りは**ハイフン**のみ。アンダースコア・大文字・スペース不可（Shopify仕様準拠）
3. 英訳はしない。日本語の商品名を**ローマ字でそのまま転写**する（業界標準）
4. ハンドル変更時は**必ずリダイレクトを作成**する（Shopify管理画面のチェックボックス）

---

## 商品ハンドル

### 構造

```
[仕入先名]-[商品名ローマ字]-[規格]
```

- 仕入先名: ローマ字短縮形（後述の仕入先辞書を使用）
- 商品名: タイトルから主要な名詞をローマ字化。助詞（の・と・を）は省略
- 規格: 数量・重量がある場合のみ末尾に付与

### 規格の書き方

| 種類 | 書き方 | 例 |
|------|--------|-----|
| セット個数 | `{数字}-set` | `7-set`, `3-set` |
| パック数 | `{数字}-pack` | `3-pack`, `6-pack` |
| 重量 | `{数字}{単位}` | `200g`, `1kg` |
| 容量 | `{数字}{単位}` | `720ml`, `1800ml` |
| サイズ違い | `large` / `small` | `large`, `small` |

### 日本酒の場合

```
[蔵元短縮]-[銘柄ローマ字]-[特定名称]-[容量]
```

| 例 | ハンドル |
|----|---------|
| 大和川酒造 弥右衛門 純米辛口 720ml | `yamatogawa-yaemon-junmai-karakuchi-720ml` |
| ほまれ酒造 会津ほまれ 純米大吟醸 極 720ml | `homare-aizu-homare-junmai-daiginjo-kiwami-720ml` |

### ローマ字化の判断基準

- 助詞（の・と・を・に・で）: **省略**。ただし商品名の一部として不可分な場合（「ごはんのお供」等）は残す
- 長音: 無視（おう→o、えい→ei）。ヘボン式準拠
- 「っ」: 子音重ね（`hokke`等）
- 外来語・英語由来: そのまま英語で（カレー→curry、グラタン→gratin、チーズ→cheese）
- ブランド固有名詞: 公式英語表記があればそれを使用（Nao-buns等）

### 命名ルール

- 英語を基本とする。英語に適切な訳がない場合のみローマ字（`ochugen`, `oseibo`等）
- トップページ掲出用は本体ハンドルに`-featured`を付与
- テスト用コレクションはタイトルに【試験用】、ハンドルに`test-`接頭辞を付与

## 運用ルール

### 新規登録時

1. 商品名（title）を日本語で入力
2. Shopifyが自動生成する日本語ハンドルを**必ず手動で上書き**
3. 本規則に従いローマ字ハンドルを入力
4. 仕入先辞書に該当がなければ辞書に追記してから設定

### 既存商品の変更時

1. 管理画面 > 商品 > 検索エンジンのリスティング > URLとハンドル
2. 新ハンドルを入力
3. **「URLリダイレクトを作成する」に必ずチェック**
4. 保存

### 一括変更の進め方（Cowork想定）

1. 全商品のcurrent handle一覧をCSVで取得（GraphQL `products` query）
2. 本規則に基づき新handleを対応表として作成
3. GraphQL `productUpdate` mutationで一括変更
4. リダイレクト作成を確認（Shopify管理画面 > オンラインストア > メニュー > URLリダイレクト）
5. 変更後にサイトマップ再送信（Google Search Console）
