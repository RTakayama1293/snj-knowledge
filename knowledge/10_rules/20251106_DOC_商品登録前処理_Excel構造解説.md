## 概要

### 目的

EEZO（CS-Cart）への商品登録を効率化するため、商品データの入力から最終的なCSVファイル生成までを一貫して処理するExcelシステムです。

### 処理フロー

```
【入力】
このエクセルファイルに入力してください.xlsx
  └ 入力用シート（50列）
        ↓ データ入力
        ↓
【前処理・変換】
CS-Cartへバッチ処理をするために_前処理用のエクセルを用意した.xlsx
  ├ 処理用シート（58列）← A~AX列をコピー、AY・AZ列をBC・BD列にコピー
  │   ├ 自動採番（BE列）
  │   ├ SEO name生成（AY列）
  │   └ データ検証
  └ csv変換用シート（47列）← 表示状態でUTF-8保存
        ↓
【出力】
product_batch.csv
  └ CS-Cart管理画面からバッチ登録
```

## 重要列の解説

### BE列: 型番自動生成（最重要）

#### 現在の採番ルール（旧体系）

**フォーマット**: `カテゴリ-ブランド-連番-固定値`

**数式**:
```excel
=LET(
   _xlpm._cat, BC3,
   _xlpm._br, BD3,
   _xlpm._seq, COUNTIFS(BC$2:BC2,_xlpm._cat, BD$2:BD2,_xlpm._br)+1,
   _xlfn.TEXTJOIN("-",, _xlpm._cat, _xlpm._br, TEXT(_xlpm._seq,"0000"), "000")
)
```

**生成例**:
```
BE-HOY-0001-000  ← カテゴリBE（飲料）× ブランドHOY（北王よいち）の1番目
BE-HOY-0002-000  ← 同じ組み合わせの2番目
MP-HOY-0001-000  ← カテゴリMP（畜産）× ブランドHOYの1番目（別カテゴリで0001リセット）
```

**特徴**:
- カテゴリ×ブランドの組み合わせごとに連番をリセット
- 末尾000は固定値（バリエーション用だが未使用）
- 区切り文字はハイフン（-）

#### 新採番ルール（2025年10月21日定義）

**フォーマット**: `PRD_SNJ_仕入先_連番_バリエーション`

**更新後の数式**:
```excel
=LET(
   _supplier, BD3,
   _seq, COUNTIFS(BD$2:BD2, _supplier) + 1,
   TEXTJOIN("_",, "PRD", "SNJ", _supplier, TEXT(_seq,"0000"), "00")
)
```

**生成例**:
```
PRD_SNJ_HOY_0001_00  ← 仕入先HOY（北王よいち）の1番目
PRD_SNJ_HOY_0002_00  ← 同じ仕入先の2番目
PRD_SNJ_NKH_0001_00  ← 仕入先NKH（NIKI HILLS）の1番目（仕入先ごとに0001リセット）
```

**変更点**:
- カテゴリコード廃止（BC列不要）
- 事業体SNJ追加（将来のEEZO対応のため）
- プレフィックスPRD追加
- 区切り文字をアンダースコア（_）に変更
- バリエーションを2桁に変更（00, 01, 02...対応可能）

**注意事項**:
- COUNTIFSが相対参照（BD$2:BD2）のため、行を並び替えると連番が再計算される
- データは常に下に追加（並び替え禁止）
- 同じ仕入先でも行が離れている場合、連番は続きから採番

### AY列（51列目）: SEO name自動生成

#### 現在の生成ルール（旧体系）

**数式**:
```excel
=LOWER(SUBSTITUTE(TRIM(処理用[[#This Row],[型番]]), "-", ""))
```

**処理の流れ**:
```
BE-HOY-0001-000
    ↓ TRIM（前後空白削除）
BE-HOY-0001-000
    ↓ SUBSTITUTE（ハイフン削除）
BEHOY0001000
    ↓ LOWER（小文字化）
behoy0001000
```

**用途**: CS-Cart商品ページのURL生成
```
https://eezo.club/カテゴリ/behoy0001000/
```

#### 新採番ルール対応版

**数式**:
```excel
=LOWER(SUBSTITUTE(SUBSTITUTE(処理用[[#This Row],[型番]], "PRD_", ""), "_", ""))
```

**処理の流れ**:
```
PRD_SNJ_HOY_0001_00
    ↓ "PRD_"削除
SNJ_HOY_0001_00
    ↓ "_"削除
SNJHOY000100
    ↓ 小文字化
snjhoy000100
```

**生成例**:
```
PRD_SNJ_HOY_0001_00 → snjhoy000100
PRD_SNJ_NKH_0052_00 → snjnkh005200
PRD_SNJ_YSS_0103_00 → snjyss010300
```

**特徴**:
- 12文字（既存より+3文字、SNJ分）
- 全て小文字、区切りなし（既存形式と統一）
- PRDは削除（自明のため）
- SNJは残す（将来のEEZO対応のため）

## 前処理手順

### ステップ1: 入力用Excelでのデータ入力

**使用ファイル**: `このエクセルファイルに入力してください.xlsx`

#### 作業内容

1. **入力方法について Ver1.1シート**で入力ルールを確認
2. **入力用シート**にデータを順次追加
   - 必須項目（黄色セル）を優先的に入力
   - カテゴリ名、ブランド名は正確に入力（XLOOKUP参照のため）
   - 画像URLは完全なURLを入力

#### 注意点

- **カテゴリ追加・ブランド追加が発生した場合はエディ（松永さん）に連絡**
- 複数人で作業する場合は入力用シートをコピーして別ファイルで作業
- 最後に1つのシートにまとめる

### ステップ2: 処理用Excelへのデータ転記

**使用ファイル**: `CS-Cartへバッチ処理をするために_前処理用のエクセルを用意した.xlsx`

#### 2-1. 処理用シートへのコピー

1. **入力用シート**のA列～AX列（1-50列）を全選択してコピー
2. **処理用シート**のA列にペースト（上書き）

#### 2-2. カテゴリ・ブランド情報のコピー

1. **入力用シート**のAY列（カテゴリ名）をコピー
2. **処理用シート**のBA列にペースト
3. **入力用シート**のAZ列（ブランド名）をコピー
4. **処理用シート**のBB列にペースト

※この時点で自動的に以下が生成されます：
- BC列: カテゴリコード（XLOOKUP数式）
- BD列: ブランドコード（XLOOKUP数式）
- BE列: 型番（LET数式）
- AY列: SEO name（SUBSTITUTE数式）

#### 2-3. データ検証

以下の項目を確認：

**必須項目チェック**:
- [ ] Product code（BE列）が正しく生成されているか
- [ ] Category（BA列）が正しく入力されているか
- [ ] Price（価格）が数値で入力されているか
- [ ] Product name（商品名）が入力されているか
- [ ] Thumbnail / Detailed image（画像URL）が正しいか

**データ品質チェック**:
- [ ] 欠損値（空白セル）がないか
- [ ] 無効値（エラー値）がないか
- [ ] BC列・BD列のXLOOKUPエラーがないか
  - エラーの場合、カテゴリ名・ブランド名が正確かチェック
  - マスタに存在しない場合はエディに連絡

**画像ファイルチェック**:
- [ ] 画像ファイルが用意されているか
- [ ] webp変換済みか（拡張子が.webpになっているか）
- [ ] URLが正しく入力されているか（https://から始まる完全なURL）

### ステップ3: CSV変換と出力

#### 3-1. csv変換用シートの確認

1. **csv変換用シート**を選択（タブをクリック）
2. データが正しく転記されているか目視確認
3. 特に以下を確認：
   - Product code列に型番が表示されているか
   - SEO name列にURL用文字列が表示されているか

#### 3-2. CSVファイルとして保存

1. 「ファイル」→「名前を付けて保存」
2. ファイル形式: **CSV UTF-8（コンマ区切り）(.csv)**
3. ファイル名: `product_batch.csv` または日付入り `product_batch_20251106.csv`
4. 保存

#### 注意事項

- **必ず「csv変換用シート」を表示した状態で保存**
- エンコーディングは必ずUTF-8
- Excel終了時に「保存しますか？」と聞かれた場合、Excelブック自体は保存しない（CSVのみ必要）

### ステップ4: CS-Cartへのバッチ登録

1. CS-Cart管理画面にログイン
2. 「商品」→「インポート」
3. `product_batch.csv`をアップロード
4. バッチ処理を実行
5. エラーがないか確認

```excel
=LET(
   _xlpm._cat, BC3,

   _xlpm._seq, COUNTIFS(BC$2:BC2,_xlpm._cat, BD$2:BD2,_xlpm._br)+1,
```

   - テスト結果の共有

2. **仕入担当（門永さん）への説明**
   - カテゴリコード不要になった旨を説明
   - 新型番フォーマットの説明
   - 入力方法は変わらないことを強調

3. **営業担当への通知**
   - 商品コード形式が変わることを通知
   - 既存商品は旧コードのまま継続
   - 新規登録分のみ新コードを使用

## トラブルシューティング

### エラー1: BE列でXLOOKUPエラー

**症状**: BE列に`#N/A`エラーが表示される

**原因**:
- BC列またはBD列のXLOOKUPがエラー
- カテゴリ名またはブランド名がマスタに存在しない

**解決方法**:
1. BA列（カテゴリ名）が正確か確認
   - スペースの有無
   - 全角・半角の違い
   - 表記ゆれ（例: 「飲料・アルコール」vs「飲料」）
2. BB列（ブランド名）が正確か確認
3. カテゴリコード表・ブランドコード表を確認
4. 新しいカテゴリ・ブランドの場合はエディに連絡

### エラー2: SEO nameが正しく生成されない

**症状**: AY列が空白または期待と違う値

**原因**:
- BE列の型番が生成されていない
- 数式エラー

**解決方法**:
1. BE列の値を確認
2. AY列の数式を確認
3. 数式を再コピー

### エラー3: CSV保存時に文字化け

**症状**: CSV保存後、テキストエディタで開くと文字化けしている

**原因**:
- エンコーディングがUTF-8ではない
- 保存形式が間違っている

**解決方法**:
1. 「CSV UTF-8（コンマ区切り）」を選択
2. 通常の「CSV（コンマ区切り）」は使用しない
3. Excelの設定を確認

### エラー4: CS-Cartアップロード時のエラー

**症状**: CS-Cartでバッチ処理がエラーになる

**原因**:
- 必須項目の欠損
- データ型の不一致
- 画像URLが無効

**解決方法**:
1. 必須項目（黄色セル）を全て確認
2. 数値項目に文字列が入っていないか確認
3. 画像URLがアクセス可能か確認（ブラウザで開いてみる）
4. CS-Cartのエラーログを確認

### エラー5: 連番が意図しない値になる

**症状**: 連番が飛んでいる、または重複している

**原因**:
- データを並び替えた
- 行を削除した
- 数式の範囲が間違っている

**解決方法**:
1. **データは並び替えない**（最重要）
2. 行を削除した場合、連番は詰まらない（仕様）
3. 数式を確認: `COUNTIFS(BD$2:BD2, _supplier)`
   - 開始行が$2（固定）
   - 終了行が2（相対参照）になっているか
