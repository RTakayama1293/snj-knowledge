# 正規化ルール

## 価格の正規化

### 税込 → 税抜変換
- 税込10%表記 → ÷ 1.10
- 税込8%表記（軽減税率） → ÷ 1.08
- 明記なしの場合、食品は8%と推定

### 有効桁数（重要）
税抜変換時は**小数点以下を保持**する。大量発注（10,000個等）でも誤差が問題にならない程度の精度を確保。

```
例: 税込715円（8%） → 715 ÷ 1.08 = 662.037037...
  → 662.037037 （小数点以下6桁程度を保持）
  
例: 税込1,188円（8%） → 1188 ÷ 1.08 = 1100.000000
  → 1100 （割り切れる場合は整数でOK）
```

**丸め処理：**
- 仕入単価：小数点以下保持（丸めない）
- 送料・定価・粗利の計算はSENDO0.5側で実施

### 除去対象
- 通貨記号: 円、¥、￥
- 桁区切り: カンマ
- スペース

### 特殊ケース
| 入力 | 処理 |
|------|------|
| オープン価格 | 空欄 + 要確認フラグ |
| 時価 | 空欄 + 要確認フラグ |
| 要相談 | 空欄 + 要確認フラグ |
| ○○円〜 | 最低価格を採用 + 要確認フラグ |
| (500)、（500）等の括弧付き価格 | 数値として採用 + 申し送りに「参考価格（括弧表記）」 |

## 単位の正規化

単位列は**取引単位**（仕入単価が「何あたり」かを示す）を指す。見積書の「数量」「単位」列から取引単位を抽出し、以下に正規化する。

商品名に含まれる内容量表記（120g、180ml等）は単位列ではなく**容量列**に入れる。

| 入力例 | 正規化後 | 補足 |
|--------|----------|------|
| キログラム、㎏、KG | kg | |
| グラム、㌘、g | g | |
| リットル、ℓ、L | L | |
| ミリリットル、㎖、ml | ml | |
| 個、ケ、コ | 個 | |
| 本、ボトル、瓶 | 本 | |
| パック、P/K、pk | パック | |
| 箱、ケース、C/S、cs | 箱 | |
| 枚、シート | 枚 | |
| 尾、匹 | 尾 | |
| 玉 | 玉 | |
| 束 | 束 | |
| 袋 | 袋 | |
| 缶 | 缶 | |
| pc、ピース | pc | レトルト等の個包装 |

## 温度帯の判定

| キーワード | 温度帯 |
|------------|--------|
| -18℃、F、フローズン、冷凍 | 冷凍 |
| 0〜10℃、C、チルド、冷蔵、要冷蔵 | 冷蔵 |
| 常温、ドライ、D、室温 | 常温 |

### 商品特性からの推定（明記なし時）

| 商品カテゴリ | 推定温度帯 |
|--------------|------------|
| 鮮魚/刺身 | 冷蔵 |
| 冷凍魚/むきエビ | 冷凍 |
| 生肉 | 冷凍 or 冷蔵 |
| ハム/ソーセージ | 冷蔵 |
| 日本酒/ワイン/焼酎 | 常温 |
| 乾物/缶詰 | 常温 |
| チーズ | 冷蔵 |
| 野菜 | 冷蔵 |
| 菓子（焼き菓子） | 常温 |
| 生菓子 | 冷蔵 |

## 賞味期限の記載

### 形式統一
- 「製造日より○日」
- 「製造から○ヶ月」（日数換算不要）

### 変換例
| 入力 | 出力 |
|------|------|
| 90日 | 製造日より90日 |
| 3ヶ月 | 製造から3ヶ月 |
| 要冷蔵で14日 | 製造日より14日（要冷蔵） |
| 冷凍1年、解凍後3日 | 冷凍で1年、解凍後3日 |
