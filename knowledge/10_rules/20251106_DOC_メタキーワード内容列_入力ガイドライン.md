## 「内容」列とは

### 定義

**「内容」列（Features1）**: 商品の具体的な内容・種類・タイプを表すキーワード

### 役割

メタキーワード生成の**核心要素**として使用され、検索エンジン最適化（SEO）において重要な役割を果たします。

### 位置づけ

入力用Excelの**Features1列**（37列目）に該当します。

---

## メタキーワード生成の仕組み

### 生成数式

```excel
=LET(
   keyword1, [@カテゴリー],
   keyword2, [@産地],
   keyword3, [@ブランド],
   keyword4, [@内容],          ← Features1列
   keyword5, "EEZO,エエゾ",
   TEXTJOIN(",", TRUE, keyword1, keyword2, keyword3, keyword4, keyword5)
)
```

### 5つのキーワード要素

| 順序 | 要素 | 例 | 役割 |
|-----|------|-----|------|
| 1 | カテゴリー | 飲料・アルコール | 大分類 |
| 2 | 産地 | 北海道 | 地域性 |
| 3 | ブランド | 北王よいち | 製造者・ブランド |
| 4 | **内容** | **りんごジュース ブレンド** | **商品の具体的内容** |
| 5 | 固定値 | EEZO,エエゾ | サイト識別 |

### 生成例

**入力**:
```
カテゴリー: 飲料・アルコール
産地: 北海道
ブランド: 北王よいち
内容: りんごジュース ブレンド
```

**生成されるメタキーワード**:
```
飲料・アルコール,北海道,北王よいち,りんごジュース ブレンド,EEZO,エエゾ
```

**このメタキーワードが効果を発揮する検索**:
- 「北海道 りんごジュース」
- 「北王よいち ブレンド」
- 「飲料 北海道 EEZO」

## 入力ガイドライン

### 基本原則

1. **商品の具体的な内容を表すキーワード**
   - 何の商品か一目でわかる
   - 検索されそうなワード

2. **商品名の中核部分を抽出**
   - 商品名: 【送料無料】北王よいち りんごジュース ブレンド 180ml×30本/箱
   - 内容: りんごジュース ブレンド
   - 抽出: 装飾語（【送料無料】）、ブランド名、容量・規格を除く

3. **2-5単語程度**
   - 短すぎず、長すぎず
   - 複数キーワードの場合はスペース区切り

4. **検索意図を想像**
   - 顧客が検索しそうなワード
   - 競合との差別化要素

### 入力のコツ

#### ✅ 含めるべき要素

- **商品の種類**: ジュース、ミンチ、ロース、じゃがいも
- **具体的な品種・タイプ**: ブレンド、バッファロー、メークイン
- **特徴的な加工方法**: ストレート、無添加、熟成
- **形状・サイズ**: スライス、ブロック、ホール
- **用途**: ギフト用、業務用、家庭用

#### ❌ 含めない要素

- **ブランド名**: すでにkeyword3で含まれる
- **産地**: すでにkeyword2で含まれる
- **容量・規格**: 180ml、30本、500g など
- **価格**: 送料無料、割引 など
- **装飾語**: 【】で囲まれた部分、驚きの、絶品 など

## NG例とOK例

### ❌ NG例1: ブランド名を含めている

**NG**: 北王よいち りんごジュース ブレンド  
**理由**: ブランド名（北王よいち）は既にkeyword3で含まれるため重複  
**OK**: りんごジュース ブレンド

### ❌ NG例2: 容量・規格を含めている

**NG**: りんごジュース 180ml×30本  
**理由**: 容量・規格は検索キーワードとして効果が薄い  
**OK**: りんごジュース ブレンド

### ❌ NG例3: 装飾語を含めている

**NG**: 【送料無料】絶品りんごジュース  
**理由**: 装飾語はメタキーワードに不適切  
**OK**: りんごジュース ブレンド

### ❌ NG例4: 産地を含めている

**NG**: 北海道産 りんごジュース  
**理由**: 産地（北海道）は既にkeyword2で含まれる  
**OK**: りんごジュース ブレンド

### ❌ NG例5: 単語が長すぎる

**NG**: 北海道産りんごを使用した甘みと酸味のバランスが良いブレンドジュース  
**理由**: 長すぎて検索キーワードとして機能しない  
**OK**: りんごジュース ブレンド

### ✅ OK例1: 品種名を含む

**OK**: ぶどうジュース バッファロー  
**理由**: 品種名は差別化要素として有効

### ✅ OK例2: 加工方法を含む

**OK**: トマトジュース 食塩無添加  
**理由**: 「無添加」は検索される重要キーワード

### ✅ OK例3: 形状を含む

**OK**: あか牛ロース スライス  
**理由**: 形状は購入判断に重要

### ✅ OK例4: 用途を含む

**OK**: びえい和牛 すき焼き用  
**理由**: 用途は検索意図に直結

### ✅ OK例5: 特徴を含む

**OK**: エゾシカミンチ 低脂肪  
**理由**: 特徴は差別化要素

## SEO効果を高めるコツ

### 1. ロングテールキーワードを意識

**ロングテールキーワード**: 複数単語の組み合わせで構成される、検索ボリュームは少ないが購買意欲が高い検索語

**例**:
- 単一ワード: 「りんご」（競合多、購買意欲低）
- ロングテール: 「りんごジュース ブレンド 無添加」（競合少、購買意欲高）

**内容列での実践**:
```
りんごジュース ブレンド
ぶどうジュース バッファロー 
エゾシカミンチ 低脂肪
```

### 2. 競合との差別化要素を含める

**差別化要素の例**:
- 品種名: バッファロー、メークイン、ゴールドラッシュ
- 製法: 無添加、天日干し、手作り、熟成
- 特徴: 低脂肪、高タンパク、オーガニック
- 用途: ギフト用、業務用、家庭用

**効果**: 他社商品と明確に区別され、検索上位に表示されやすい

### 3. 検索意図を理解する

**購入検討段階の検索例**:
```
情報収集段階: 「エゾシカ 栄養」「エゾシカ 味」
比較検討段階: 「エゾシカミンチ おすすめ」「エゾシカ ロース 違い」
購入直前段階: 「エゾシカミンチ 通販」「エゾシカ 北海道 購入」
```

**内容列での対応**:
```
エゾシカミンチ 低脂肪  ← 栄養・健康志向の検索に対応
エゾシカロース スライス ← 部位・形状の比較検索に対応
```

### 4. シーズンキーワードも考慮

**季節性のある商品の場合**:
```
冬: 鍋用、すき焼き用、おせち用
夏: BBQ用、ギフト用、お中元
秋: 新米、新物、旬
```

**内容列での実践**:
```
あか牛 すき焼き用
ホタテ BBQ用
いくら お正月用
```

### 5. カタカナ表記の統一

**表記ゆれに注意**:
```
NG: ジュース、ジュウス、じゅーす
OK: ジュース（カタカナ統一）
```

**理由**: 検索エンジンは表記ゆれを吸収するが、統一した方が安全

## よくある質問（FAQ）

### Q1. 商品名と同じ内容を入力してもいいですか？

**A.** 基本的にはOKですが、装飾語や容量・規格は除いてください。

**例**:
```
商品名: 【送料無料】北王よいち りんごジュース ブレンド 180ml×30本/箱
内容: りんごジュース ブレンド
```

### Q2. 複数の特徴がある場合、どれを優先すべきですか？

**A.** 以下の優先順位で選択してください：

1. 商品の種類（必須）: りんごジュース、エゾシカミンチ
2. 差別化要素: ブレンド、低脂肪、無添加
3. 形状・用途: スライス、すき焼き用

**例**:
```
OK: エゾシカミンチ 低脂肪
OK: あか牛ロース すき焼き用
```

### Q3. スペース区切りとカンマ区切り、どちらを使うべきですか？

**A.** **スペース区切り**を使用してください。

**理由**: カンマはメタキーワード全体の区切り文字として使用されるため

```
OK: りんごジュース ブレンド
NG: りんごジュース,ブレンド
```

### Q4. 英語表記とカタカナ表記、どちらがいいですか？

**A.** **カタカナ表記を推奨**します。

**理由**: 日本の検索ユーザーはカタカナで検索することが多い

```
推奨: ジュース、チーズ、ワイン
非推奨: Juice、Cheese、Wine
```

ただし、商品の特性上英語表記が一般的な場合（例: BBQ、LED）は英語でもOK。

### Q5. 内容列を空欄にするとどうなりますか？

**A.** メタキーワードは生成されますが、**商品固有の検索キーワードが含まれない**ため、SEO効果が大幅に低下します。

**生成例（空欄の場合）**:
```
飲料・アルコール,北海道,北王よいち,EEZO,エエゾ
```

**問題点**: 「りんごジュース」で検索しても出てこない

**必ず入力してください！**

## まとめ

### 「内容」列（Features1）の3つのポイント

1. **商品の具体的な内容を2-5単語で**
   - 何の商品か一目でわかるキーワード
   
2. **重複を避ける**
   - ブランド名、産地名、カテゴリ名は既に含まれる
   
3. **検索されそうなワードを意識**
   - 購入を検討する人が検索しそうな言葉

### 入力の基本フロー

```
1. 商品名を確認
   ↓
2. 装飾語・ブランド名・容量を除く
   ↓
3. 商品の種類 + 特徴を抽出
   ↓
4. 2-5単語にまとめる
   ↓
5. Features1列に入力
```
