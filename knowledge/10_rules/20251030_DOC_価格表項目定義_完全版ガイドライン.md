# 価格表フォーマット - 項目定義ガイドライン

**作成日**: 2025年10月30日  
**作成者**: ミナト（港）  
**対象**: 新日本海商事株式会社 客先向け価格表  
**バージョン**: 1.0

---

## 📋 標準フォーマット（8項目）

```
商品コード | 商品名 | 規格 | 容量 | 単位 | 単価（税抜） | 最小注文量 | 温度帯
```

---

## 📖 各項目の定義

### 1. 商品コード

**定義**: 社内管理用の一意識別子

**形式**: `PRD_SNJ_XXX_NNNN_VV`

**構成要素**:
```
PRD_SNJ_AUT_0002_00
├─ PRD（プレフィックス - 商品コードであることを示す）
├─ SNJ（事業体コード - 新日本海商事）
├─ AUT（仕入先コード - 3文字の仕入先識別子）
├─ 0002（シリアル番号 - 仕入先ごとに4桁連番）
└─ 00（バリエーション - 2桁、規格違い等に使用）
```

**特殊ルール**:
- 送料商品は `9999` をシリアル番号とする
- バリエーションで地域・温度帯等を管理（例：00=関東冷蔵、01=関西冷蔵）

**記入例**:
```
PRD_SNJ_AUT_0001_00  エゾシカ セロース（標準規格）
PRD_SNJ_AUT_0001_01  エゾシカ セロース（大型規格）
PRD_SNJ_KDN_0023_00  きびだんご（10個入り箱）
PRD_SNJ_SNJ_9999_00  送料（関東・冷蔵）
```

---

### 2. 商品名

**定義**: 客先に表示する商品の名称

**記入ルール**:
- 部位・品種名を明確に
- 分かりやすい日本語表記
- ブランド名がある場合は含める

**記入例**:
```
○ エゾシカ セロース
○ タラバガニ（ボイル）
○ じゃがいも（きたあかり）
○ 大七 純米生酛
× HDR1010
× 鹿肉
```

---

### 3. 規格

**定義**: 商品の仕様・状態・加工度合い

**記入内容**:
- 部位の状態：ぐり身（脂なし）、骨付き、皮なし
- 加工状態：ブロック、スライス、ミンチ、カット
- 品質グレード：特選、A5ランク
- 製法：ボイル、生、熟成
- その他：真空パック、化粧箱入り

**記入例**:
```
ぐり身（脂なし）ブロック
骨付き1本
10個入り化粧箱
720ml瓶
スライス3mm厚
```

**注意**:
- 物流用語（段ボール、パレット）は記載しない
- 客先が商品の状態をイメージできる情報を記載

---

### 4. 容量

**定義**: 1販売単位あたりの内容量

**記入ルール**:
- 定貫商品：固定重量を明記（例：1kg、500g）
- 不定貫商品：重量範囲を明記（例：約1.5-2.3kg）
- 個数がある場合：併記（例：10kg（L玉約60個））

**記入例**:
```
【定貫商品】
1kg/パック
720ml/本
10kg/箱
500g（5切入り）/パック

【不定貫商品】
約1.5-2.3kg/本
約0.4-0.8kg/本
5-8kg/本

【階層構造商品】
10個入り×10箱/ケース
720ml×6本/ケース
```

**単位の書き方**:
- 「/本」「/箱」「/パック」など、何1つあたりかを明記
- 不定貫は「約」を付ける

---

### 5. 単位

**定義**: 単価を何で掛けるか（単価の計算単位）

**記入内容**:
```
kg      重量ベース（不定貫の精肉・水産物）
本      瓶・ボトル・ブロック1本
箱      段ボール箱・化粧箱
ケース   複数箱・複数本のまとまり
パック   真空パック・トレイパック
折      ウニなどの容器
尾      カニ・エビなど個体
束      野菜などの束ね
ホール   チーズ・ケーキなど丸ごと
セット   詰め合わせ・ギフトセット
缶      一斗缶など
```

**重要ルール**:
- この単位と単価を掛け合わせて価格を計算
- 必ず「容量」欄の単位と対応させる

**記入例**:
```
単位: kg  容量: 約1.5-2.3kg/本  → kg単価で実重量精算
単位: 本  容量: 720ml/本        → 本単価で固定価格
単位: 箱  容量: 10kg/箱         → 箱単価で固定価格
```

---

### 6. 単価（税抜）

**定義**: 1単位あたりの価格（税抜）

**記入形式**: `○,○○○円/単位`

**記入例**:
```
6,300円/kg
1,880円/パック
2,500円/箱
16,800円/ケース
```

**注意**:
- 必ず「/単位」まで記載
- 3桁カンマ区切り
- 税抜であることを明記

---

### 7. 最小注文量

**定義**: 最小注文可能な数量と販売単位

**記入形式**: `○○から（刻み情報）`

**記入パターン**:

#### パターンA：1単位からOK
```
1本から
1箱から
1パックから
```

#### パターンB：複数単位から
```
5本から
10箱から
3kgから
```

#### パターンC：刻みがある場合
```
3kgから（0.5kg刻み）
10箱から（5箱刻み）
5本から（1本刻み）
```

#### パターンD：ケース単位のみ
```
1ケース（10本入り）から
6本（1ケース単位）から
1ケースから（バラ売り不可）
```

#### パターンE：バラ売り可能を明示
```
5箱から（1箱刻み、ケース未満可）
```

**記入例**:
```
1本から                          → 1本単位で売る、1本から注文可
5kgから                          → kg単位で売る、最低5kg
1ケース（10本入り）から            → ケース単位のみ、バラ売り不可
3kgから（0.5kg刻み）               → 0.5kg刻みで売る、最低3kg
6本（1ケース単位）から              → ケース推奨、最低6本
```

---

### 8. 温度帯

**定義**: 保管・配送時の温度管理区分

**記入内容**:
```
常温    室温での保管可能
冷蔵    0-10℃での保管
冷凍    -18℃以下での保管
```

**注意**:
- 温度帯により配送料が異なる場合がある
- 同一注文内で温度帯混在時の扱いを注釈に記載

## 🔄 バリエーション管理の例

### **規格違いでバリエーション番号を使う**

```
PRD_SNJ_QGI_0001_00  エゾシカ セロース（標準：1.5-2.3kg）
PRD_SNJ_QGI_0001_01  エゾシカ セロース（大型：2.5-3.5kg）
PRD_SNJ_QGI_0001_02  エゾシカ セロース（小型：0.8-1.2kg）
```

### **包装違いでバリエーション番号を使う**

```
PRD_SNJ_TND_0003_00  きびだんご（10個入り化粧箱）
PRD_SNJ_TND_0003_01  きびだんご（業務用ケース）
PRD_SNJ_TND_0003_02  きびだんご（バラ・簡易包装）
```

PRD_SNJ_DSH_0012_01  大七 純米生酛（1800ml）

## ⚠️ よくある間違いと対策

### **間違い1：単位と容量の不一致**

❌ **間違い**
```
単位: 本
容量: 約1.5-2.3kg
```
→ 容量に「/本」が抜けている

✅ **正しい**
```
単位: kg
容量: 約1.5-2.3kg/本
```

---

### **間違い2：規格に物流情報を入れる**

❌ **間違い**
```
規格: 段ボール箱入り
```
→ 価格表では不要な情報

✅ **正しい**
```
規格: 10個入り化粧箱
```

---

### **間違い3：最小注文量が曖昧**

❌ **間違い**
```
最小注文量: 応相談
```
→ 客先が判断できない

✅ **正しい**
```
最小注文量: 5本から（1本刻み）
```

---

### **間違い4：単価の単位が抜けている**

❌ **間違い**
```
単価: 6,300円
```
→ 何の単価か不明

✅ **正しい**
```
単価: 6,300円/kg
```
