## 💡 翻訳ガイドライン

### 🎨 ニュアンス保持の鉄則
- **感嘆符は必ず保持**: 「！」→ "!"
- **親しみやすさ維持**: 「実は〜」→ "Actually"
- **語りかけ感**: 「〜ですね」→ "~ is also~"
- **興奮・推奨感**: 「〜も美味しい！」→ "~ is also delicious!"
- **驚き・発見感**: 「〜だそうです」→ "there's also ~"

### 📈 LinkedIn向け調整ポイント
- **ややビジネス調**: 専門用語は説明的に記述
- **論理的説明**: メカニズムは科学的根拠で説明
- **価値提案明確化**: 商品特徴・差別化ポイントを強調
- **ストーリー性活用**: 自然現象や文化的背景でブランド価値向上

### 🌸 日本らしさの英語表現法
```
風物詩 → iconic seasonal scenes
旬 → peak season / seasonal specialty
雪室 → snow storage rooms（+ 説明）
ちゃんちゃんこ → chanchanko (traditional vest)
〜さん → our producers / our dedicated farmers
〜だそうです → there's also ~ / people say that ~
珍しい → unique / special
```

## 🚨 よくある翻訳ミス

### ❌ 避けるべき表現
```
✗ 直訳しすぎ：「〜が詰まっています」→ "is stuffed with"
✗ 敬語失敗：「生産者さん」→ "Mr. Producer"  
✗ ハッシュタグ重複：同じ意味のタグを複数
✗ 文化説明不足：「ちゃんちゃんこ」→ "chanchanko"（説明なし）
✗ 感嘆符削除：「旬！」→ "seasonal"（感情削除）
```

### ✅ 推奨表現
```
✓ 自然な英語：「〜が詰まって」→ "is packed with"
✓ 適切な敬意：「生産者さん」→ "our dedicated producers"
✓ タグ使い分け：#HanasakiCrab #FlowerCrab（関連性あり）
✓ 文化説明：「ちゃんちゃんこ」→ "chanchanko (traditional vest)"
✓ 感情保持：「旬！」→ "peak season!"
```
