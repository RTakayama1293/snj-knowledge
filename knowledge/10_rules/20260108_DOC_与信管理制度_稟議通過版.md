# 与信管理制度（稟議通過版）

**作成日**: 2026年1月8日  
**起案**: 蜂巣常務  
**決裁**: 2026年1月8日

---

## 経緯

### 発端
ホロニック（ガーデンシティクラブ大阪）との新規取引において、与信申請を行おうとしたところ、谷崎専務より「個別案件ではなく、与信の仕組みがないなら全部作れ」との指示。

### 検討プロセス
1. **2025/12/17**: ホロニック案件発生（鹿肉ロース5kg、約27,000円）
2. **2026/01/07**: 蜂巣常務が与信管理制度案を作成、梶原経理部長へ上申
3. **2026/01/07**: 梶原経理部長よりフィードバック
   - 方針として問題なし
   - 制度を稟議で通し、個別案件は都度稟議（マリネックス方式）
   - 掛売期間は基準に張り付かず、極力短期での交渉を推奨
4. **2026/01/08**: 稟議通過

### 主な修正点（当初案→最終版）
- 許容掛売期間：65点以上「3ヶ月」→ 削除（50点以上は1ヶ月に統一）
- 49点以下・業績不詳先：前金のみ → 前金または**債権保証サービス利用**を追加
- 運用フロー：個別案件ごとに稟議を起案するフローを明確化

---

## 制度内容

### 1. 基本方針

- 与信限度額は、倒産等により回収不能となった場合でも、当社の経営に致命的な影響を与えない金額を上限とする
- 新規取引先については、第三者による信用調査および定量的な財務指標を基に初期与信を設定する
- 取引開始後は、実際の回収状況や取引実績に応じて、与信限度額を見直す
- 与信限度残高は、見積提出可能金額として社内に周知する

---

### 2. 海外販売

#### 基本方針
- 原則として、**日本貿易保険（NEXI）**を活用する
  - https://www.nexi.go.jp/
  - 商事は「中小企業・農林水産業輸出代金保険」が適用
- **保険未付保での掛売取引は行わない**

#### 新規取引先の与信判断
1. まず格付を取得する
2. 格付およびカントリーリスクに応じて保険引受限度額が設定される

| 格付 | 対応 |
|------|------|
| EE（優良）| 保険引受限度額の範囲内で取引 |
| EA（良）| 保険引受限度額の範囲内で取引 |
| EF（可）| 保険引受限度額の範囲内で取引 |
| EC（注意）| **前金取引** |

#### 保険契約の運用
- 船積前日までの個別保険契約の締結を必須とする
- 取引件数が増加の場合は、包括保険契約への移行を検討する

#### 例外および見直し
- 戦略的取引等について例外対応を行う場合は、稟議書を起案し、決裁を仰ぐ
- 保険金支払有無にかかわらず、以下の場合は都度見直しを行う
  - 支払遅延の発生
  - 財務状況の悪化
  - 取引金額の急増

---

### 3. 国内販売における与信管理

#### 信用調査
- 新規取引先については、**帝国データバンク**または**東京商工リサーチ**の信用調査をもれなく実施する

#### 信用評点による区分

| 評点 | 区分 | 許容掛売期間 |
|------|------|-------------|
| 65点以上 | 無難 | 1ヶ月 |
| 50〜64点 | 多少注意 | 1ヶ月 |
| 49点以下 | 警戒 | **前金または債権保証サービス** |
| 業績不詳 | - | **前金または債権保証サービス** |

※債権保証サービス例：マネーフォワードケッサイ https://mfkessai.co.jp/

#### 与信限度額算定

**Step 1: 基礎与信限度額**（以下2つのうち低い金額）

**売上高ベース**
```
年間売上高 × 係数
├─ 評点65点以上：係数 5%
└─ 評点50点以上：係数 2%
```

**利益金ベース**
```
年間利益金 × 0.5
```

**Step 2: 自己資本率による抑制**
```
基礎与信限度額 × 抑制係数
├─ 自己資本率 20%未満：係数 0.4
├─ 自己資本率 20%以上：係数 0.7
└─ 自己資本率 40%以上：係数 1.0
```

**Step 3: 取引開始時の上限**
```
取引開始初期（3ヶ月間）は、想定月商の1ヶ月分を上限とする
```

#### 運用およびモニタリング

1. **与信限度額を自主的に算定後、個別に稟議書を起案し、決裁を仰ぐ**
2. 毎月末に、経理部より売掛金残高表を入手する
3. 商事は、決裁済みの与信限度額を踏まえ、現在の売掛金残高および残与信枠（見積提出可能金額）を自主的に算定し、関係者へ周知する
4. 支払遅延、取引条件の変更、信用状況の悪化が確認された場合は、速やかに与信限度額の見直しを行う

---

## 運用フロー

```
【制度稟議】
  与信管理制度 → 稟議通過（本件）
       ↓
【個別案件】
  新規取引先発生
       ↓
  信用調査実施（TDB/TSR）
       ↓
  与信限度額算定
       ↓
  個別稟議起案 → 決裁
       ↓
  取引開始
       ↓
  月次モニタリング（売掛金残高確認・周知）
```

---

## 備考

- 掛売期間の基準は「上限」であり、営業は極力短期（翌月末）での受取条件を交渉すること
- マリネックスは「末締め翌末受取」を標準としている
- 戦略的取引、紹介案件等で例外対応が必要な場合は、個別稟議にて判断を仰ぐ
