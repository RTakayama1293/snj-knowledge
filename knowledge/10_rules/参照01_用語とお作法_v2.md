## 1. 社内用語

| 用語 | 意味 |
|------|------|
| SI（セリングアイデア） | 「誰が×何を×どれくらい（単価・頻度）買うか」が共通する売上予測の最小単位 |
| BU | ボトムアップSIの暫定番号（BU-xx）。実案件を起点に定義された検証中のSI。検証が済むと正式SIに昇格する |
| SENDO | 受発注管理Excel台帳。案件管理を統合 |
| EEZO | 自社EC（Shopify）。北海道食材ギフト。eezo.club |
| 案件No | ANK-xxx形式の採番 |
| 進捗メモ | 台帳の1セル。/区切り・改行なし・左が新しい |
| ドロップシップ | EC注文を仕入先から直送する方式 |
| NISSHA予約販売 | 法人向け予約販売企画（トワヴェール等の商品）。BU-03の起点案件 |
| はまなす | フェリー「はまなす」関連の催事・一般公開販売 |
| DENBA | 鮮度保持・健康機器の商材 |
| 待避 | 実案件の裏付けを失ったSIを一覧から外した状態。廃止ではなく、案件が再発生したらBU化して復帰する |

## 3. 商材用語（エゾシカ関連）

- 部位名: ロース、ヒレ、シンタマ、ウチモモ（内モモ）、ソトモモ（外モモ）、ランプ、カタ、ネック、バラ、スネ、ミンチ、レバー、ハツ（心臓）、タン
- グリムキ: 銀皮・筋膜を除去した状態。「グリムキではない＝筋付き」を希望する顧客もいる
- 肉の区分: 熟成 / フレッシュ（非熟成）/ 養鹿（飼育）/ 狩猟（野生捕獲）
- 狩猟シーズン: 10〜3月。夏場は欠品リスクが高い

## 4. お作法（整理時のルール）

1. **推測で埋めない**。書かれていない金額・日付・数量は「不明」と記載する
2. 金額・価格・条件は、必ず出典（コンタクト日・発言者）を添える
3. 進捗メモは「MMDD 何があったか →何が変わったか」の形式に要約する
4. 断定語を避ける。「決定」ではなく「方針案」「合意」「意向」など、原文のニュアンスを保つ
5. 社名・人名は入力の表記のまま使う（勝手に変換しない）
6. 1つのコンタクトから複数の案件・商材が読み取れる場合は、行を分ける
7. BU一覧の単価・頻度は仮説を含む。台帳の実績がBUの値と乖離していても、BU側に合わせて実績を書き換えない（乖離はそのまま【BU改訂候補】として報告する）
