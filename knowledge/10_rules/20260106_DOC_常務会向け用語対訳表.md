## 7. 稟議書での使用例

### 推奨表現

| 避けるべき表現 | 推奨表現 |
|----------------|----------|
| 高品質なUXが不可欠 | 良質な購買体験の提供が不可欠 |
| UX/UIの改善 | 顧客体験・画面設計の改善 |
| Shopifyへの移行 | 通販基盤の刷新（Shopify採用） |
| 既存業務用MP | 既存の法人向け電子市場 |
| toCフォーカス | 対個人取引への注力 |
| コンバージョン率が低い | 成約率が低い |
| SNSで発見 | 情報発信媒体を通じて認知 |
| ストーリー訴求 | 背景・物語の訴求 |

### 文例

**原文（専門用語多用）**:
> BtoC向けECで整備したUXは、toB展開においても有効である。

**推奨（対訳適用）**:
> 対個人取引向け通販基盤で整備した購買体験は、法人間取引の展開においても有効である。

---

## 8. 運用上の留意点

1. **初出時は併記**: 専門用語を初めて使う際は「購買体験（UX）」のように併記
2. **略語は避ける**: 「UI/UX」ではなく「顧客体験・画面設計」と展開
3. **外来語は最小限**: カタカナ語より漢語を優先
4. **固有名詞は括弧書き**: 「通販基盤構築サービス（Shopify）」
