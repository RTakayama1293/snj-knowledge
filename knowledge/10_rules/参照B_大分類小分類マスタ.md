# 大分類・小分類マスタ

## 選択肢一覧

| 大分類 | 小分類（選択肢） |
|--------|------------------|
| 飲料アルコール | 日本酒, リキュール, ワイン, 蒸留酒, 茶, その他飲料 |
| 水産 | 水産物 |
| 精肉 | 和牛, エゾシカ, ヒグマ |
| 青果 | 野菜, みかん |
| チーズ | チーズ |
| 食品加工機械 | DENBA, スライサー |
| 加工品 | 水産加工品, 肉加工品, その他 |
| 菓子 | 洋菓子, 和菓子 |
| その他 | 胡蝶蘭, 備長炭, 調味料, 化粧品 |

## 判定ガイド

### 飲料アルコール
- 日本酒/純米酒/大吟醸 → 日本酒
- 焼酎/ウイスキー/ブランデー/泡盛 → 蒸留酒
- ワイン/スパークリング → ワイン
- 梅酒/果実酒/柚子酒 → リキュール
- 緑茶/番茶/紅茶 → 茶
- ジュース/水/炭酸 → その他飲料

### 水産
- 鮮魚/貝類/海藻/甲殻類 → 水産物

### 精肉
- 牛肉（黒毛和牛、あか牛等） → 和牛
- 鹿肉/エゾシカ → エゾシカ
- 熊肉/ヒグマ → ヒグマ

### 青果
- 野菜全般（じゃがいも、アスパラ、ゆり根等） → 野菜
- 柑橘類（みかん、デコポン等） → みかん
- メロン/りんご等の果物 → 野菜（※現行マスタ上）

### 加工品
- 干物/明太子/塩辛/かまぼこ → 水産加工品
- ハム/ソーセージ/ベーコン/ジャーキー → 肉加工品
- 上記以外の加工食品 → その他

### 食品加工機械
- 鮮度保持機器/電解水機器 → DENBA
- スライサー/カッター → スライサー

### 菓子
- ケーキ/クッキー/チョコレート → 洋菓子
- 餅/羊羹/大福 → 和菓子

### その他
- 花/観葉植物 → 胡蝶蘭
- 炭/燃料 → 備長炭
- 醤油/味噌/ドレッシング → 調味料
- 美容品 → 化粧品
