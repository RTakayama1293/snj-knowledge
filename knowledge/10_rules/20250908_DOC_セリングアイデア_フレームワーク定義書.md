# セリングアイデア・フレームワーク定義書

## 📋 **基本定義**

### **セリングアイデアとは**
**「誰が（顧客プロファイル）」×「何を（単価）」×「どれくらい（数量・頻度）」の組み合わせ**

- **目的**: 売上を予測する最小単位として活用
- **戦略的価値**: 類似プロファイルのスケール可能性を判断する基準
- **抽象度**: 具体的すぎず抽象的すぎない、実行可能なレベルで設定

### **PFSI（ポートフォリオ＆セリングアイデア）**
- **定義**: 単価×頻度×数で売上計算できる最小単位
- **目的**: 年間目標に対する売上配分を戦略的に決定
- **活用**: 営業リソースの最適配分と優先順位決定

## 🎯 **セリングアイデア設計の3要素**

### 1. **誰が（顧客プロファイル）**
- **具体性レベル**: 業界→企業規模→部門→担当者レベル
- **決裁権限**: 実際に購買決定できる人物・部門を特定
- **例**: 「百貨店」× → 「チェーン百貨店の催事担当」○

### 2. **何を（商品・単価）**
- **商品構成**: 単品 / セット商品 / サービス込み
- **価格帯**: 顧客の予算レンジに適合した設定
- **例**: 「北海道食材」× → 「50万円の北海道フェア商品セット」○

### 3. **どれくらい（数量・頻度）**
- **購買パターン**: 季節性・周期性・突発性
- **数量予測**: 過去実績ベースでの合理的な想定
- **例**: 「時々」× → 「年2回、月40セット」○

## 📊 **実践的な活用例**

### **Case 1: 百貨店事業戦略**

#### **催事型セリングアイデア**
```
誰が：チェーン百貨店の催事担当
何を：50万円の北海道フェア商品セット
どれくらい：年2回（春・秋催事）

年間売上予測：100万円/店
スケール対象：全国チェーン店舗数
課題：人的リソース（売り場対応）
```

#### **ギフト型セリングアイデア**
```
誰が：チェーン百貨店のギフト担当
何を：8,000円の北海道ギフトセット
どれくらい：月40セット（通年）

年間売上予測：384万円/店
スケール対象：全国チェーン店舗数
利点：人的リソース不要
```

### **Case 2: ホテル事業戦略**

#### **高級ホテル型セリングアイデア**
```
誰が：高級ホテルの料飲部門バイヤー
何を：20万円/月の北海道食材定期納品
どれくらい：月1回（年間契約）

年間売上予測：240万円/軒
スケール対象：全国高級ホテル数
差別化：ストーリー性＋安定供給
```

## 🔄 **セリングアイデア最適化プロセス**

### **Step 1: 初期設定**
1. 過去実績の分析（成功事例の要因分解）
2. 顧客ヒアリング（購買パターンの確認）
3. 競合分析（市場ポジションの確認）

### **Step 2: 仮説設定**
1. 3要素の組み合わせパターン作成
2. 売上予測計算（単価×数量×頻度）
3. スケール可能性の評価

### **Step 3: 検証・改善**
1. 実際の営業活動での検証
2. 成約率・リピート率の測定
3. フィードバックによる要素調整

## 📈 **分析・管理指標**

### **セリングアイデア別KPI**
- **成約率**: 提案件数に対する成約件数
- **平均単価**: 想定単価との乖離
- **リピート率**: 継続購買の割合
- **営業効率**: 1案件あたりの営業工数

### **ポートフォリオ管理指標**
- **売上構成比**: 各セリングアイデアの貢献度
- **成長性**: 前年同期比での拡大率
- **安定性**: 売上の変動係数
- **収益性**: 粗利率・営業利益率

## 🎪 **戦略会議での活用方法**

### **討議フォーマット**
1. **現状セリングアイデアの評価**
   - 各アイデアの実績・課題
   - スケール阻害要因の特定
   
2. **新規セリングアイデアの検討**
   - 市場機会の分析
   - 実現可能性の評価
   
3. **リソース配分の決定**
   - 優先順位の設定
   - 営業担当の役割分担

### **意思決定基準**
- **市場規模**: アドレサブルマーケットの大きさ
- **競争優位性**: 独自の価値提案の強さ
- **実行可能性**: 現有リソースでの対応可能性
- **収益性**: 目標ROIとの整合性

## 📝 **更新・管理ルール**

### **定期見直し**
- **月次**: 実績データの更新
- **四半期**: セリングアイデアの効果検証
- **年次**: ポートフォリオ全体の戦略見直し

### **文書管理**
- **マスターデータ**: セリングアイデア一覧
- **実績データ**: 営業活動記録との紐付け
- **分析レポート**: 定期的な効果測定結果
