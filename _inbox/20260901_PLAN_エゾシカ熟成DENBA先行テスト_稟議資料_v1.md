## 稟議本文（案）

```
稟議内容
エゾシカ肉の熟成条件に関する先行テストの実施（費用500千円以内・予算外）について承認をいただきたい。
当社はエゾシカをEEZO事業の柱としているが、熟成という主要な付加価値工程について自社の実測データを一件も持っていない。本テストにより、旨味成分の経時変化と21日間の安全性のデータを自社で確保する。

　記

１．不作為のコスト（実施しない場合に生じること）
１-１．熟成の条件と品質の根拠を、仕入先に依存したままになる。
　　　　　　　仕入価格の交渉でも、料理長への売り込みでも、当社が自ら示せる根拠を持てない。
１-２．基準線がないため、今後どの熟成条件を試しても良否を判定できない。
　　　　　　　「良くなった」と言うための比較対象が作れない。
１-３．検体の入手はエゾシカの捕獲時期に左右される。26年内に着手できない場合、
　　　　　　　次の機会は27年の同時期まで待つことになる。

２．本テストで得るもの　詳細は添付資料参照
２-１．旨味成分の基準線
　　　　　　　現行の標準温度である2℃で21日間熟成し、遊離グルタミン酸とイノシン酸の
　　　　　　　経時変化を実測する。
２-２．安全性のデータ
　　　　　　　21日間を通じた一般生菌数の推移を確認する。
２-３．運用の実証
　　　　　　　検体の分取・保管・外部検査の発注・装置の運用を一通り通し、
　　　　　　　実務上の詰まりを先に洗い出す。

３．実施内容
３-１．条件：2℃・DENBA稼働の1条件
３-２．期間・測定時点：21日間。0日目・6日目・11日目・16日目・21日目の5時点
３-３．検体：エゾシカのウチモモ。計5点（各時点200g）
３-４．検査：遊離アミノ酸（旨味）成分分析、一般生菌数
　　　　　　　このほか重量・pH・外観およびにおいの所見・定点撮影を自社で全時点実施する。
３-５．実施場所：オーセントホテル小樽。冷蔵庫およびDENBA装置を借用する。

４．費用内訳
　合計：500千円以内（予算外）※現在3社から相見積を取得中であり、下振れの見込み
　（旨味成分の分析412千円、一般生菌検査10千円、原料20千円、予備費58千円）
　※DENBA装置・冷蔵庫は借用のため費用は発生しない。
　※予備費は検体の輸送費および輸送資材を見込む。

５．スケジュール
　26年9月　　見積確定、設備・実施場所・許可区分の調整
　26年10月　試験開始（21日間）
　26年11月　分析結果の受領

６．リスクと対策
　想定されるリスク：21日を待たずに一般生菌数が規格を超え、試験が途中で終了する。
　対策：中間の測定時点（6日目・11日目・16日目）で都度確認し、超過が見えた時点で打ち切る。
　残存リスク：打ち切り時点までに実施した分析費（最大500千円）が残る。ただし
　　　　　　　「2℃・DENBAでも21日はもたない」という結果自体が、以後の条件設定の前提になる。

７．撤退基準
　一般生菌数が規格を超える、または明確な腐敗所見が出た時点で本テストを終了し、
　以後の検討を取り下げる。

８．補遺
　本テストは当社および借用先の施設内で完結し、親会社ならびに他部門のリソース・費用の
　負担は生じない。
　企画の概要は2026年7月31日に社長へ説明済み。
　DENBAは水分子を振動させて細菌の増殖を抑える装置。エゾシカ肉の熟成は0〜2℃が業界標準で
　あり、温度を上げれば酵素の働きが強まり旨味の向上が見込める一方、細菌の増殖が問題になる。

以上

　添付資料

　　別紙1　先行テスト設計書
　　別紙2　分析機関の見積書
```

## この構成にした理由

`knowledge/50_skills/20260302_SKILL_上申テクニック_蜂巣経由社長決裁.md` の指示に沿って組んだ。

| 使ったテクニック | 本稟議での適用 |
|---|---|
| 損失回避フレーム（テクニック3。「期待効果」の直前に「不作為のコスト」を置く） | 「１．不作為のコスト」を効果より先に置き、冒頭2文目にも「自社の実測データを一件も持っていない」を入れた |
| 反論と横槍を事前に潰す（テクニック5。谷崎専務は「手続きが不備」「本社への影響は」を言いやすい） | 稟議フォーマットを Sansan 稟議通過版に合わせた。「８．補遺」の冒頭で親会社・他部門への影響がないことを明示した |
| リスクと対策をセットで書く（テクニック5） | 「６．リスクと対策」を「想定されるリスク／対策／残存リスク」の3段で書いた |
| 撤退基準を明示（テクニック4の「武器」チェックリスト） | 「７．撤退基準」を独立の項に立てた |
| Sansan 稟議通過版の型 | 冒頭2文で金額と要点を出し切る。算出根拠は添付に逃がす。本題に算入しないものは補遺に置く |

### 本格実施（フル設計）に触れていない理由

高山さんの判断（2026-09-01）。本格実施をやるかどうかが未定であるため、本稟議では言及しない。第2段階（温度を上げた条件）についても記載しない。

### 社長への説明済みであることの書き方

「８．補遺」に事実として1行だけ置いた。前面に出すと稟議経路上の常務会参加者を飛び越える形になり、逆に一切書かないと「聞いていない」という反応を招く。補遺に置くことで、読めば分かるが押し付けにはならない位置に収めている。

## 確定していない事項

| # | 事項 | 状況 |
|---|---|---|
| 1 | 分析費412千円 | 3社に相見積を依頼中（`_inbox/20260901_MEMO_エゾシカ熟成DENBA_分析委託先問い合わせ記録.md` 参照）。イノシン酸が遊離アミノ酸のメニューに含まれる機関を選べる場合、1検体82.5千円が45千円まで下がり、分析費は225千円程度になる。上記は含まれない場合の上限で計上した |
| 2 | 検体5点の前提 | 8月27日に確定した「ウチモモ2頭分」のうち、1頭を本試験に使い、もう1頭は予備および凍結アーカイブに回す前提。2頭とも本試験に使う場合は10点となり、費用は倍になる |
| 3 | 1検体あたりの必要量 | 検査機関によっては項目ごとに100g以上を求める。各時点200gの取り出しで足りるかは見積の返信待ち。足りない場合は測定時点を減らす判断が要る |
| 4 | オーセントホテル小樽の設備の借用条件 | 調整中。借用に費用が発生する場合、本稟議の費用内訳を修正する必要がある |
| 5 | 実施場所の営業許可区分 | 実施場所を所管する保健所への確認が未了 |
