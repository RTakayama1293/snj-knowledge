## 稟議本文

```
　稟議内容

エゾシカ肉の熟成実験に係る分析業務を株式会社AHCへ委託すること、および費用500千円以内（税抜・予算外）について承認をいただきたい。

　記

１．委託先
　株式会社AHC（群馬県前橋市）。食品の成分分析および微生物検査の受託機関。
　3社から相見積を取得し、比較のうえ選定した（別紙2）。選定の理由は次の3点。
　　・必要な検査項目を1社で受託でき、価格が最も低い
　　・1標本あたりの必要量が150gと最も少なく、当社の分取計画に収まる
　　・納期が10営業日と最短

２．委託内容と費用
　エゾシカ肉の標本について、旨味成分（遊離アミノ酸20種、イノシン酸、グアニル酸）と
　一般生菌数の計23項目を分析する。2段階に分けて実施し、各段階の標本は5点。
　費用は合計500千円以内（税抜・予算外）。各段階250千円。
　内訳は分析委託468千円、標本用エゾシカ肉20千円、予備費12千円。
　第1段階の結果により第2段階を行わない場合は、250千円で終了する。

３．背景と目的
　エゾシカ肉は、低温で数週間寝かせる「熟成」で旨味が増すというのが業界での共通認識である。
　当社が取り扱うDENBA（細菌の増殖を抑える装置）を熟成に組み合わせれば、細菌の増殖を抑えながら熟成できる見込みがある。
　熟成は温度が高いほど早く進むが細菌も増殖するため、温度を上げる選択肢は他の生産者には取れない。
　細菌を抑えて熟成する独自の手法を確立できれば、他社にない付加価値となり、単価や利益率アップが期待される。
　本委託は、この見込みを確かめるための分析である。

４．実施計画
　　第1段階　熟成（2℃）＋DENBA。旨味の向上を検証する。250千円
　　第2段階　熟成（6℃）＋DENBA。第1段階で向上が十分でない場合に実施する。250千円
　26年10月　第1段階（21日間）　　　　26年11月　第1段階の結果受領、第2段階の可否判断
　26年12月　第2段階（21日間）　　　　27年01月　第2段階の結果受領、最終報告

以上

　添付資料　　別紙1　実験設計書　　別紙2　分析委託先の費用比較
```

## 差し戻しの記録（2026-09-03）

v6の本文を提出したところ、谷崎専務から差し戻された。指摘は次のとおり。

> 本件の背景・目的や計画内容・費用等については縷々詳細に記載されていますが、本稟議の趣旨は「分析を㈱AHCに外部委託すること、そしてその費用が500千円以内」の２点に尽きると思います。稟議中にポイントである外部委託先についての記載が全くありません。今後稟議はポイントを絞って記載願います。

**何が起きたか**：v6は背景と目的を5行、実験計画を3段構成で書き、費用内訳とスケジュールを添えた。委託先の社名は費用内訳の注記に「分析は株式会社AHCに委託する（3社の相見積のうえ選定）」と1行あるだけで、独立した項がなかった。

**学び**：金が社外に出る稟議では、決裁者が判断するのは「誰と、いくらで取引するか」である。背景・目的・計画はその材料にすぎない。この稟議を「実験をやってよいか」を問う文書と考えて組んだのが誤りで、実務上は「AHCと500千円の取引を結んでよいか」を問う文書だった。詳しくは `knowledge/50_skills/20260302_SKILL_上申テクニック_蜂巣経由社長決裁.md` のテクニック4.5に記録した。

**次の版（v7）で直すこと**：

1. 稟議内容の1文に「株式会社AHCへの外部委託」と「500千円以内」を入れる
2. 「１．委託先」を新設し、社名・所在地・3社相見積からの選定・選定理由を本文に置く
3. 背景と目的を後ろに送り、行数を削る
4. 実験計画は、第1段階と第2段階でそれぞれいくらかかるかが分かる粒度にとどめる
