## 稟議内容

営業管理システム「Sansan」の継続利用（年間利用料690千円・税抜）について承認をいただきたい。

1年目の効果は年間930時間（1,545千円相当）であり、年間利用料を855千円上回っている。2年目は年間1,032時間（1,698千円相当）を見込む。

記

## １．効果（当初計画 → 1年目実績 → 2年目計画）

- **名刺取り込み**　240時間・360千円 → 234時間・351千円 → 210時間・315千円
　1時間当たりの処理枚数を、実測に基づき16.7枚から12枚に修正した
- **営業管理・データ分析**　180時間・360千円 → 198時間・447千円 → 204時間・456千円
　おおむね計画どおり推移している
- **その他（メールマガジン配信）**　120時間・180千円 → 0時間・0千円 → 120時間・180千円
　1年目は配信対象の分類整備に注力したため未実施。2年目に実施する
- **企業リスト作成**　該当なし → 498時間・747千円 → 498時間・747千円
　当初計画外。法人見込客の開拓のためのべ10,000社分を作成。2年目も同量を継続する
- **合計**　540時間・900千円 → 930時間・1,545千円 → 1,032時間・1,698千円
　年間利用料690千円との差分は +210千円 → +855千円 → +1,008千円

## ２．費用

年間利用料690千円（アカウント利用料510千円・5ID、スキャナ利用料180千円）。初期費用400千円は初年度限りであり2年目は発生しない。自動更新のため契約時の見積を添付。
